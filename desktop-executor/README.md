# 一战晟铭本地执行器

Windows x64 本地客户端。它用于把用户自行登录、已获授权的视频生成环境留在本机，平台仅通过一次性配对码识别设备，并接收任务状态和产物。

## 当前能力

- 平台设置页生成一次性配对码；
- 客户端配对后每 30 秒上报在线状态；
- 设备令牌仅保存在本机系统加密存储中，平台只保存哈希；
- 可解除本机配对。

## 尚未交付

视频任务领取、豆包用户授权流程、生成进度、视频上传回传仍在实现，当前版本不会伪装成已能自动生成视频。

## 本地打包

```bash
cd desktop-executor
npm install
npm run pack:win
```

输出：`release/一战晟铭本地执行器-<version>-win-x64.exe`。

配对时，填写部署后端地址（当前内网环境为 `http://10.0.100.183:14000`），再输入平台“设置 → 豆包本地执行器”生成的配对码。
