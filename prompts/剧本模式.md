# 剧本模式输出格式

按以下专业短剧剧本格式输出，严格遵循格式。

## 一、场次定义（铁律）

一场 = 同一连续空间 + 同一段连续时间。镜头切换（△）不是新场次。

一场内可以有任意多个 △（镜头）。镜头之间可以切镜、跳轴、人物进出、平行事件——只要空间没变且时间连续，仍然是一场。

换场次的唯一条件：空间变了，或者时间线发生了不可跳过的事件段落断裂（跳到另一个时刻/另一天）。

## 二、场次防拆禁止项

| 错误做法 | 正确做法 |
|---------|---------|
| 同一空间内因切镜而建新场次 | 用"切镜"标注在△段落内过渡 |
| 同一空间内因人物进出而建新场次 | 人物进出是同一场内的调度 |
| 同一空间内因情绪转折而建新场次 | 情绪转折用△段落衔接 |
| 同一空间内因快闪/OS/VO而建新场次 | 快闪、OS、VO 都是△段落内的元素 |

反例：
```
❌ 1-7 厨房 △小姨拿手机 → 1-8 门口 △修理工按门铃（同一连续事件）
✅ 全部在 X-1 内，两个△段落之间自然衔接
```

## 三、输出前场次自检（强制）

输出完成后，对每个 `X-N → X-(N+1)` 的边界逐一回答：

> "新建这一场，是因为空间变了，还是时间线发生了不可跳过的事件段落断裂？"

答"否" → 必须合并回前一场。然后重新输出。

## 四、对白括号 A/B/C 分级

人物括号不是每句都写满，按台词功能分级：

**A级：关键爆点，必须写具体括号**
适用：主角反击、反派施压、亮证据、打脸、拒绝、崩溃、结尾卡点
格式：人物（关键动作 + 表情/眼神 + 声音状态）：台词

**B级：普通推进，简写括号**
适用：报数、问话、承接信息、日常对话
格式：人物（一个动作或声音状态）：台词

**C级：背景/群戏，不写括号**
适用：群众口号、短促附和、电话音、录音、背景议论
格式：人物：台词 或 人物（声音状态）：台词

## 五、△ 画面描述规则

- 只写镜头能看到的：动作、表情、道具、站位、互动
- 不写心理描写、环境描写、抽象形容
- 每个△段落是一个独立的画面单元
- 电影语法呈现

## 六、输出格式模板

```
第 X 集

X-1 具体地点·【内/外】·时间
人物：人物A、人物B、人物C

▲【开场全景/环境描述】【人物大动作/走位描述】
人物A（【状态】【情绪，语气描述】【互动动作】）："台词原文，一字不差还原视频内容。"
人物B（【状态】【情绪，语气描述】【互动动作】）："台词原文，一字不差还原视频内容。"
人物 (V.O.画外)："台词原文。"（画外音标注，人物不在画面中）
人物 (O.S.内心)："台词原文。"（电话音标注，人物在画面外但在同一空间）
▲画面描述

X-2 具体地点·【内/外】·时间
人物：人物A、人物D

▲【人物大动作/走位描述】
人物A（【状态】【情绪，语气描述】【互动动作】）："台词原文，一字不差还原视频内容。"
```

## 标注规则
- V.O. = Voice Over，画外音（人物不在画面中）
- O.S. = Off Screen，画面外音（人物在画面外但在同一空间）
- ▲ 表示画面描述 / 动作描写
- 人物括号内用中文顿号「、」分隔状态、情绪、互动动作
- 台词必须一字不差还原视频中人物会说出的原文内容
