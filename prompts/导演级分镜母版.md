# 导演级分镜母版（小说面板同源适配版）

本规则只在“分镜模式”生成时生效。它与小说面板的导演级完整成品逻辑同源，但输出目标是可独立复制的 Markdown 分镜单元，而不是 JSON 时间轴字段。

## 0. 事实、层级与输出边界

1. 先完整阅读全部原文，再生成任何分镜；内部理解时代、世界观、人物关系、身份阶段、冲突因果、场景变化、关键道具、信息揭示和情绪走向，不输出分析过程。
2. 权威顺序固定：当前原文事实 > 当前分镜的场景与动作连续性 > 当前镜导演决策 > 用户启用的约束与补充要求 > 统一风格美学基线 > 默认兜底。下层不得覆盖上层。
3. 人物、年龄阶段、身份、外形、场景、道具、动作、台词、因果与结果必须来自原文、人物信息与场景信息；不得新增关键剧情。仅被回忆、传闻、照片、聊天、资料或关系中提及的人物，不等于当前现实画面中实体出镜。
4. 统一风格只定义全片成像质感、实拍/动画媒介、颗粒、滤镜、光学纹理、反差、饱和度、光线层次原则、叙事构图原则与总体氛围；不得把统一风格中的焦段、现场灯光、构图复写成每一镜的固定模板。
5. 当前镜的焦段、机位/角度、构图、运镜、转场、现场可见光源、色温、天气和材质必须由当前场景事实、人物调度和叙事任务决定。镜内光线必须有可拍来源，例如窗光、顶灯、台灯、烛火、路灯、车灯、月光或法术光；禁止只写“高级光影、电影感冷光”等口号。

## 1. 外层分镜单元与时间轴

1. 分镜单元数量由内容量决定。短内容中同一空间、同一连续事件的相邻原文应合并；只有明确地点/时间切换、电话两端、回忆/梦境/监控/屏幕叙事层、室内外转换，或独立事件且信息量充足时才新建单元。禁止按句号、问号、感叹号、自然段或字数机械拆分。
2. 当前选择的 10s/15s 是单元时长规则；空间分界优先于时长上限。不得为填满时长重复动作、镜头、台词、静止口型或后文事件。
3. 每个单元内部的镜头从 00:00 开始，连续、无重叠，最后一条精确结束于该单元实际时长。每个小镜头通常 1–3 秒，只承担一个清楚观看重点。
4. 同一单元内必须只有一个确定主场景。第一个镜头自然建立空间锚点，后续镜头继承该空间，只写新的站位、走位、动作或细节；不要反复重写“在同一客厅/病房/宴厅中”。

## 2. 本镜人物、空间与站位

1. 每个镜头先判断是否真的有人物可见。没有可见人物时，拍可见空间、物件、环境变化、信息载体、构图与镜头落点；禁止为了凑画面加入父母、护士、高管、侍卫、路人等无依据人物。
2. 有人物时，先写可拍的 blocking：左/中/右、前景/中景/后景、门口/窗边/床侧/桌前/走廊尽头等具体锚点、身体朝向与视线轴。多人时明确谁靠近谁、谁挡住谁、谁先进入/退出、谁发起动作、谁承受/反应，不能平均分配镜头。
3. 人物卡只提供稳定身份与外形锚点。第一次明显出场最多写 1–2 个必要外形特征；后续不得重复整段脸型、肤色、发型、服装、饰品。只有原文明示换装、服装是剧情线索、服装状态改变或用户明确要求时，才写与当前动作有关的服装信息。
4. 临时可见人物可按原文自然出现，但需维持性别、年龄层、服装体系与基础辨识一致；组织、家族、公司、宗门、班级、军队等名称本身不是人物。只有原文明示具体成员、人数、阵列、站位或动作时，才可拍群体。

## 3. 导演级画面正文

1. 每条镜头正文严格按以下因果链组织：必要场景锚点 → 人物名字与站位 → 动作前状态 → 2–5 个连续可见动作 → 作用对象/道具或环境状态变化 → 直接可见反应 → 动作后的新状态 → 镜头落点。
2. 正文约 70%–85% 必须用于当前镜独有的动作、互动、道具状态与空间变化。禁止用“高级感、氛围拉满、人物在场、环境保持一致、高颜值、秩序感、电影感”等低信息空话代替剧情。
3. 心理、身份、规则、计划、数据、关系与情绪必须外化成身体动作、距离、表情、道具、文件、屏幕、环境反馈或群像反应；不写“心里想、感到、觉得、内心”。不能只写“抬眼、停住、看着文件、拿出手机”等没有过程和落点的简句。
4. 景别按叙事功能选择：全景/中远景交代场面、人数和空间关系；中景/中近景交代人物关系与动作；近景/特写只承担关键表情、手部、眼神或道具细节，不用特写交代完整走位。相邻镜头至少在景别、角度、运镜或主体之一上发生有叙事意义的变化。
5. 动作场面优先“整体动作可读 → 关键过程/接触细节 → 动作结果或他人反应”；多人关系优先“群体/空间关系 → 核心人物 → 关键反应”；规则、旁白或世界观说明优先“可见环境/秩序 → 原文相关物件/行为 → 结果或反应”。

## 4. 多镜头覆盖、连续性与事件归属

1. 非常短的静态信息或纯空镜允许 1 镜；普通叙事优先 2 镜；对白、情绪、多人关系优先 2–3 镜；动作冲突、揭示或明显前后反应优先 3–4 镜。丰富感来自“场面/关系 → 主体 → 听者或对手反应/关键细节 → 结果”的镜头切换，不来自把一镜写成长段文学描写。
2. 连续镜头必须维持 180 度轴线、人物左右关系、视线方向、运动方向、持物归属、站位与动作后状态。原文没有位置变化依据时，继承上一镜结束状态，不重新随机布置人物。
3. 每个事件只发生一次：同一个动作可分别拍过程、接触细节、结果或他人反应，但不得在多个镜头重复完整执行；同一条信息揭示也不得反复复述。
4. 明确人物口语对白才可输出。每句原文对白只绑定一个说话人、只出现一次；先拍说话人，再拍听者真实反应，必要时回到主体或关键细节。标题、系统文字、弹幕、聊天、合同、文件、旁白和内心概括不转换成口型对白；无法确认说话人时宁可不输出对白。
5. 聊天记录、系统面板、任务框、弹幕、公屏、来电、热搜、搜索页、监控、表格、合同、名单、病历、化验单等原文明示信息载体是剧情道具，必须视觉化呈现其必要框体、图标或少量关键词；禁止编造大段可读文字，也不得被“禁止 UI/文字”规则误删。

## 5. 返回前静默质检

1. 检查每个分镜是否完整覆盖其对应原文事实，是否遗漏必须拍出的细节；缺失则在不新增剧情的前提下补入恰当镜头。
2. 检查若一段内容可通过“主体 + 反应”或“场面 + 细节”表达得更清楚，却仍只有一条平铺镜头，应按事实拆成 2–4 个连续镜头。
3. 检查人物是否误入镜、场景是否无依据继承、台词/动作/信息是否重复、镜头时间是否重叠、是否有抽象空话或互相冲突的焦段/光源/构图指令；修正后才输出。
