# 通用规则

## 核心任务

- 基于用户提供的小说原文，以及已经提取并确认的人物信息、场景信息，将内容转化为连续、可生成的视频分镜。
- 原文负责提供剧情事实；人物信息与场景信息负责提供已经确认的视觉设定。生成阶段不得再次设计、猜测或改写人物外形与场景设定。
- 每个画面必须可直接被视频模型理解，包含明确空间、人物站位、动作、可见反应、关键道具或环境变化，以及镜头落点。
- 不输出分析过程、规则复述、JSON 或与最终分镜无关的说明。

## 人物与场景事实源

- 用户消息中的“人物信息”和“场景信息”来自前置提取并允许用户修改确认，是生成阶段的人物与场景唯一事实源。
- 人物姓名、身份、外形、服装、年龄阶段、核心辨识特征不得自行改写或补造。
- 场景名称、地点、时段、氛围和已确认视觉信息不得自行改写或补造。
- 原文明确出现、但前置提取结果暂未建立卡片的临时人物或临时空间，只能按原文事实最低限度呈现，不得借机重新设计主要人物或主要场景。

## 10s / 15s 动态拆分规则

先根据原文实际可视化内容判断故事总画面时长，再按当前选择的“10s 模式”或“15s 模式”拆成 N 个完整独立分镜单元。10s / 15s 是拆分模式，不代表每个分镜都必须刚好等于 10s 或 15s。

### 10s 模式

- 单个完整分镜总时长必须 `≤ 10s`，无最低时长限制。
- 拆分数量不固定，由故事实际总画面时长与空间切换共同决定。
- 同一连续空间超过 10s 时，在该空间内部继续按每段 `≤ 10s` 顺序切分。

### 15s 模式

- 原则上单个完整分镜满足 `10s < 总时长 ≤ 15s`。
- 遇到空间切换、剧情自然断点或最终收尾段时，允许单个完整分镜低于 10s。
- 拆分数量不固定，由故事实际总画面时长与空间切换共同决定。
- 同一连续空间超过 15s 时，在该空间内部继续按每段 `≤ 15s` 顺序切分。

### 拆分优先级

1. **空间分界优先级最高。** 场景 / 空间发生切换时，必须结束当前完整分镜；切换后的画面开启新的完整分镜。不得把两个不同空间强行合并到同一完整分镜。
2. **时长上限第二优先。** 同一空间的连续画面超过当前模式上限时，再在空间内部按上限继续拆分。
3. **内容完整度优先于凑满时长。** 不得复制动作、镜头、对白、构图或提前搬运后文事件，只为把分镜补到 10s 或 15s。

### 每个完整分镜的时间轴

- 每个完整分镜都必须独立从 `00:00` 开始。
- 标题必须写明该分镜自己的真实总时长，例如：`### 分镜一（总时长：8s）`。
- 最后一条内部时间码必须精确结束于该分镜标题声明的真实总时长，例如 8s 分镜结束于 `00:08`，13s 分镜结束于 `00:13`。
- `00:00-00:03` 等时间码只表示当前完整分镜内部镜头，不是新的分镜卡片边界。
- 所有完整分镜的实际时长之和必须等于本次故事被可视化后的总画面时长，不得多算、少算或重复内容。
- 每个完整分镜都必须保留当前模式要求的完整四段式镜头结构，不得因为该分镜较短而省略结构。

## 场景数量原则

- 场景数量由原文实际内容决定，不设机械固定配额。
- 短篇开头应优先提高单一空间承载力，避免为了“丰富画面”无依据地频繁换景。
- 15s 短视频通常应尽量控制在少量主场景内；“15s 约 2 个场景”只能作为防止场景爆炸的倾向约束，不得覆盖原文真实空间切换。
- 同一建筑内的门口、走廊、客厅、书房、餐桌旁等，如果叙事上仍属于同一连续空间，可作为子场景调度，不必机械新增主场景。

## 情节保真与表演强化

- 禁止编造原文不存在的人物关系、关键因果、核心事件、剧情结果、关键证据或关键对白。
- 允许为了视频表现，把原文已经存在的情绪转化为更像真人的明显动作、身体反应和场景互动。
- 情绪强化不应只停留在“脸红、咬牙、皱眉、瞪眼”等静态表情标签；人物可以推开椅子、拍桌、摔普通物件、逼近或后退、抓住身边物体、扫落无关键剧情属性的杂物等，以动作体现情绪。
- 表演动作可以增强情绪，但不得改变剧情事实。例如可以用摔普通水杯表现愤怒，但不得把原文中的关键证据、关键道具或关键人物关系通过新增动作破坏掉。
- 所有新增的表演动作都必须服务于原文已有情绪和当前空间，不能产生新的剧情因果。

## 心理描写视觉化

心理活动必须转化为视频可见的动作与状态，不得直接写“心里想”“感到”“觉得”“内心”等不可见描述。

优先使用：

- 身体姿态变化与明显肢体动作
- 与当前场景、家具、门窗、桌椅、普通物件的自然互动
- 明显面部表情变化
- 可见生理反应，例如指节发白、青筋暴起、脸色发白/涨红、眼眶泛红、嘴唇发抖

避免只依赖微观且视频难以稳定表现的动作，例如瞳孔变化、睫毛颤动、极细微手指动作。

## 连续性

- 相邻内部镜头必须承接前一镜形成的站位、朝向、道具归属、动作后状态、视线轴和空间关系。
- 下一完整分镜如果延续同一空间，首帧必须承接上一完整分镜末帧已经形成的状态。
- 如果发生空间切换，新分镜必须重新建立新空间，不得继承上一空间中已经失效的站位和环境关系。

## 对白与剧情信息

- 只有原文存在且可以确认说话人的口语对白才能作为人物对白输出。
- 每句对白只出现一次，不得为凑时长重复。
- 聊天记录、系统界面、合同、名单、文件、监控、弹幕等原文明示的信息载体，应作为剧情内道具或界面视觉化，不得擅自改成人物口播。

## 结尾卡点

- 最后一个完整分镜应停在原文当前范围内最有继续观看欲望的位置。
- 可以停在动作即将完成、信息刚揭示、关系或情绪明显转折的位置，但不得补造答案、秘密、反转或后续结果。

**小说写结果，视频拍过程。允许把原文已有情绪与动作拍得更有生命力，但不改变原文真正发生了什么。**
