# 前贴 qiantie 迁移启动说明

## 已包含

- Express 服务、小说面板 V77 工作台、CM、剧本、配音、Agent 和已构建前端资源。
- 内置提示词、宠物资源、默认预设和示例运行所需的非敏感文件。

## 未包含

- `node_modules/`：在新电脑安装依赖后生成。
- `data/`：包含账号、草稿、历史、会话和可能已保存的 API Key，不随包迁移。
- 本机日志、缓存、Go 后端产物和环境文件。

## 在新电脑启动

1. 安装 Node.js 20 或更新版本。
2. 解压压缩包，打开终端并进入解压后的 `qiantie` 目录。
3. 执行：

```bash
npm install
npm start
```

4. 打开 `http://127.0.0.1:3000`。
5. 首次使用在设置页填写模型地址、模型名和 API Key。

## 额外说明

- 小说面板、剧本、CM、配音和 Agent 可由 Node 服务运行。
- 水货生产的完整生成链路还需要单独部署 Go 后端及其 Redis、MySQL、存储和模型服务依赖。
