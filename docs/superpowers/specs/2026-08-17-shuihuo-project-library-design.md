# 水货生产项目库视觉对齐设计

## 目标

将 `/shuihuo-production` 的项目库入口按用户提供的“洛水2026”项目库截图重构，同时保留现有项目创建、TXT/SRT/DOCX 导入、打开、删除和后端数据接口。

## 视觉结构

- 页面采用深蓝灰桌面应用背景，顶部使用 38px 高的应用工具栏。
- 主内容从左侧 24px 开始，不使用居中的网页卡片容器。
- 标题为“漫剧解说”，副标题为“管理和创建您的漫剧解说作品”。
- 标题右侧固定“创建漫剧”按钮；生产依赖诊断不占用参考图主内容区，改为可收起的状态提示。
- “个人作品”位于标题下方，搜索、合集筛选、时间排序和网格视图位于同一行右侧。
- 项目卡片固定 200px 宽、200px 高左右，顶部为封面/分镜数量，底部为作品名和更新时间；打开和删除仅在悬停时出现。
- 空白区域保持深色留白，不添加营销式说明区或大面积装饰。

## 行为与边界

- 点击卡片进入现有漫剧解说工作台。
- 创建漫剧继续支持粘贴正文或上传 TXT、SRT、DOCX。
- 搜索按项目名称过滤；合集保留“全部合集”占位并为后续合集功能预留；排序支持时间正序/倒序。
- 网格视图按钮保留可见状态，当前仅提供参考图所示网格模式。
- 依赖诊断改为顶部窄条，可关闭，不改变后端健康检查和按钮禁用逻辑。
- 深浅主题仅替换颜色变量，桌面端尺寸和布局不改变。

## 不在本次范围

- 不修改项目、资产、任务和媒体 API。
- 不修改进入项目后的七列表格和人物场景预设弹窗。
- 不删除现有后端能力，不接入第三方源码、账号、密钥或接口。

## 验证

- 页面合同测试必须覆盖标题、筛选控件、创建入口、卡片数量信息和悬停操作。
- 前端构建必须通过。
- 在 1920x1080 和 390x844 视口检查无横向溢出、文字重叠和卡片变形。
