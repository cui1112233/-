# 批量工厂统一资产提示词入口设计

## 目标

单书“资产设置”仅保留一个“人物场景道具提示词”下拉框。用户选择的是完整资产方案，而不是分别选择人物、场景和道具规则。

## 方案

每个可选方案都占用 `script.asset-extraction` 槽位并一次选择。普通方案按原有统一提取规则执行；H3 方案在服务端识别其预设 ID 后，使用该预设正文中自带的两段 H3 指令完成事实提取和全人物外形编译，并产出场景与道具结果。

`batch.character-meta` 和 `batch.scene-meta` 仅保留为旧批次的兼容读取槽位；新建或重新生成的 V12 资产链不在浏览器展示、更不允许用户单独选择它们。

## 后台提示词库

批量工厂后台只显示一个“人物场景道具提取”分区，列出所有完整资产方案（普通与 H3）。不再将 H3 放到“人物与场景输出提示词”或“其他批量工厂提示词”。旧人物/场景元提示词归入“兼容旧版资产规则”，不作为新建提示词入口。

## 数据与兼容

保存时新配置只写 `assets.extraction`；保留已有 `assets.character` 和 `assets.scene` 内容以便旧批次只读/重试。读旧配置时，如果没有新的完整方案，继续按旧快照执行，绝不悄悄替换为 H3。

## 验收

1. 单书资产设置只有一个资产方案下拉框，且 H3 与普通方案均出现。
2. 选择 H3 后，后端仅使用该 H3 方案的两段内部指令，普通人物/场景元提示词不参与。
3. 选择普通方案后，不触发 H3 两段调用。
4. 管理后台的 H3 预设归入“人物场景道具提取”。
5. 旧配置可读取，现有资产、重试和手动编辑不丢失。
