# 批量工厂 V11：入口、小说列表与制作区设计

日期：2026-09-13
状态：用户已确认，待审阅后编写实现计划
范围：新建批量入口、小说获取导入、小说列表与水货式制作区的业务边界。

## 目标

批量工厂复用水货生产的个人作品和制作区视觉结构，但生产单位从“一个分镜”切换为“一本小说”。它不是第二套小说生产链：手动新建与小说获取导入只在正文来源不同，之后进入同一作品、同一小说生产、同一上传网络链路。

## 两个入口

### 手动新建批量

水货生产个人作品页的“批量工厂”按钮直接弹出“新建批量”，不跳转到独立页面。弹窗复用最新小说获取的完整书单输入协议：

- 作品名称。
- 书城/平台。
- 输入格式。
- 列顺序预设。
- 自定义列顺序。
- 多行书籍清单。

解析器支持书籍 ID、书名、男女频、标签、评级、推荐理由及其他列；它保留原始输入行和解析元数据。手动入口不接受用户粘贴或上传小说正文：创建后根据书城和书籍 ID 取得原始正文。

默认“自动”关闭。点击“确认创建”只创建一个批量工厂作品和其中所有书籍，不开始生产。开启“自动”后必须填写定时执行时间；作品和书籍立即入库，状态为“定时待执行”，到点才进入完整自动生产链。

### 小说获取导入

小说获取传入已选择的完整内容版本、来源任务、书籍 ID、书名、平台和元数据。批量工厂直接保存传入的完整内容，不再次抓取原文。其后的制作、批量操作、合并和上传网络与手动入口相同。

## 作品与小说列表

一次创建或导入的全部书籍属于同一个批量工厂作品，不能按数量拆分为多个作品。

顶部“小说列表”是上传书籍信息的展开视图，显示当前作品中全部书籍的：书名、bookId、书城、男女频、类型和来源。它只负责查看与选择上传书籍，不承载内容制作卡。

## 制作区：外层一行一本小说

退出/关闭小说列表后回到水货式制作区：

```text
水货生产：外层一行 = 一个分镜
批量工厂：外层一行 = 一本小说
```

外层序号 1、2、3 分别对应作品中的第 1、2、3 本小说。每本书的外层行承载该书全部内容与制作状态；本书内部生成的分镜和 VIDEO 只是该书的内部结果，不能成为外层小说序号。

每本小说行包含：

- 书籍元数据和主状态/当前阶段。
- `sourceContentFull` 完整来源正文。
- 按有效正文行数得到的内容范围、`sourceFrontContent`、`sourceRemainder`。
- 可编辑的 `workingFrontContent`；它不覆盖来源全文。
- 人物、场景、道具预设及图片。
- 书内分镜、VIDEO 主框与候选版本、最终合并视频。
- 单书或单分镜覆盖配置、任务和真实发布状态。

## 生产、取消与发布

手动创建后，用户从小说行或批量操作明确启动生产。定时创建到点后，对每本小说走：内容准备 → 内容范围 → AI 推理 → 图片/VIDEO → 严格合并 → 上传网络 → 121 真实回读。

批量操作作用于用户勾选的外层小说行；取消操作只取消当前 operation，保留此前完成结果。合并只使用每个书内分镜当前主框，缺失或失败的有效 VIDEO 阻止合并。

上传网络提供“提交选中”和“提交全部”。每本书须独立通过 bookId、当前最终视频、发布正文和 121 配置/通道校验；未就绪的书显示原因，不能阻塞其它就绪书。请求返回、任务排队或处理中都不是“已完成”；只有 121 对相应 bookId 的真实回读确认后才标记为已完成。

## 文档一致性变更

V11 基线中旧的“手动入口只填写 bookId + 书名 + 书城”描述，替换为“复用小说获取书单输入协议，但不接受手工正文”。“小说列表”明确为上传元数据展开视图；水货式制作区的外层行明确为一本小说。
