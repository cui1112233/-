# 批量工厂统一配置与自动化预设设计

## 目标

批量工厂以一份批量级“统一配置”作为默认生产配置。它覆盖模型配置、AI 推理和发布统一；自动化预设是这份配置的可命名、可版本化快照，不是另一张配置卡。

## 工作台入口

- 顶部合并现有“引擎配置”“AI 推理”“发布”入口为“统一配置”。
- 统一配置编辑现有的模型配置、AI 推理和视频管理系统发布配置；不再把 AI 推理作为独立顶部入口。
- 自动化预设齿轮位于统一配置入口左上角。

## 统一配置内容

统一配置保持一个统一生效范围，作为当前批量所有书的默认值：

- 模型配置：文本、图片、视频、配音模型；跟随配音；10/15 秒分段；相关 TTS 参数。
- AI 推理：资产设置、约束设置、衍生开篇、视频设置、画面设置。
- 发布统一：视频管理系统的上传映射与规则。

单书配置仍可独立设置。单书显式字段优先于统一配置；载入、保存或删除自动化预设均不得修改单书覆盖。

## 自动化预设

- 自动化预设为账号级资源，保存完整批量统一配置、名称、版本、创建时间和更新时间。
- 在统一配置已编辑的状态下，用户输入名称并“保存为预设”。
- 齿轮面板列出历史预设，提供选择、载入、重命名和删除。
- 载入历史预设先要求确认；确认后仅替换当前批量统一配置编辑态。用户点击统一配置“保存”后才写回当前批量。
- 预设的创建、更新和删除不修改已有自动化任务。

## 定时自动化

- “自动生产 → 开始定时”只选择已保存预设、执行模式和执行时间。
- 启动时保存预设 ID、版本和完整快照；每本书使用该快照叠加自己的单书覆盖。
- 三种模式保持不变：只生成分镜、生成视频不提交、全自动生成并提交。
- 任务内不保存或接收批次级并发数；服务端统一调度容量负责并行控制。

## 测试与验收

- 失败测试：载入预设只替换批量统一配置编辑态；单书覆盖保持不变；未确认不写回。
- 失败测试：自动化预设包含模型、AI 推理、配音/分段和发布设置；旧预设版本不影响已排期任务。
- UI 验收：顶部不再出现独立 AI 推理入口；统一配置齿轮可以命名保存、载入、重命名和删除预设；开始定时只保留预设、模式、时间。
- 回归：资产、导演、逐行实测、最终 Prompt、VIDEO、合并和视频管理系统上传继续读取同一有效配置。
