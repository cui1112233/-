# 批量工厂“分镜规划跟随配音”开关设计

## 目标

用户打开并保存“分镜规划跟随配音”后，系统立即为适用小说生成临时配音、读取真实时长，并保存可复用的时长与指纹；该动作不得开始分镜、图片、视频、合成或上传。

## 流程

1. 用户在批量统一配置中打开开关并点击“应用到当前全部小说”。
2. 批量设置先保存。仅当开关由关闭变为开启、且未开启固定开头时，页面逐书生成临时 TTS 并读取音频元数据时长。
3. 每本成功后以当前书最新 revision 保存 `audioDurationSeconds`、`audioDurationFingerprint` 与非手填标记；失败仅记录并展示该书错误，其他书继续。
4. 这次准备不调用 Director、资产、图片、视频、合并或视频管理系统上传接口。
5. 后续手动或自动 Director 读取这份保存的时长。本次不在服务端自动化控制器中伪造或补测时长；旧批次若尚无有效时长，仍保留明确失败提示，用户重新关闭并保存、再开启并保存后会触发上述准备。

## 边界

- 固定开头开启时，两个跟随配音选项无效，不能触发配音准备。
- 关闭开关、普通保存和仅修改其它统一设置均不能触发配音准备。
- 已保存且指纹相同的时长不重复合成；正文或 TTS 参数变化后重新开启或启动时需要重新读取。
- 临时音频仅用于测量，不能写入作品库或触发上传。

## 验证

- 前端源码测试证明：统一配置保存后只会在“从关到开”时调用音频准备，且不会调用生产阶段。
