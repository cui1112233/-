# 批量工厂统一组织归属

## 目标

在“统一配置 → 发布统一 → 发布映射”中选择视频管理系统组织归属。该值是当前批量作品的默认发布组织，而不是男女频、风格或标签的别名。

## 数据与继承

- 统一配置把选中的组织 ID 写入 `publishSettings.organization`，并保存到批量作品设置。
- 单书发布设置可显式覆盖该值；未覆盖的书继承批量设置。
- 自动化任务启动时冻结完整 `publishSettings`，因此冻结的组织归属不会被之后的统一配置修改。
- 历史批量若没有组织归属，保持空值；不会擅自选择任何组织。

## 界面与提交

- 发布统一从视频管理系统读取组织目录，并显示“组织归属”下拉框。
- 未登录、目录读取失败或尚未选择时，保存其他统一配置仍可进行；但上传清单和全自动提交会明确提示缺少组织归属并拒绝提交。
- 上传确认弹窗默认使用书级覆盖值，否则使用批量统一值。用户可在本次确认单临时改选；该改选仅用于此次提交，不反写批量或单书配置。
- 单书发布统一页面显示书级组织覆盖入口和“继承批量组织归属”状态。

## 兼容与验证

- 既有男女频、风格、标签的 AI 识别与保存逻辑不变；它们不再占用“组织归属”展示区域。
- 测试覆盖：统一选择持久化、单书覆盖优先、上传弹窗默认回填、临时改选不落库、自动化使用冻结值、无组织时阻断提交。
- 发布后以公网上传确认弹窗和实际请求体中的 `organization` 复核，不提交真实作品。
