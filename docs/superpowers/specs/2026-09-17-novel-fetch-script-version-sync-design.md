# 小说获取提交脚本版本同步设计

## 根因

公网 V2 页面注入了新版 V2 脚本，但保留了 HTML 中旧的 `app.js` 查询参数。浏览器因此继续加载旧提交桥，V2 选择的书籍 ID没有传入提交请求。

## 方案

服务端 V2 页面中间件统一替换已有 `app.js` script 标签，使用当前提交桥版本号；静态页面仍由同一中间件注入其他 V2 脚本。提交按钮继续由 V2 传递明确的书籍 ID，旧任务列表提交路径保持兼容。

## 验证

- 页面返回的 `app.js` 查询参数与提交桥版本一致。
- V2 选择同步测试通过。
- 公网 `/api/build-info` 与页面脚本版本可回读。
