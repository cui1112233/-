# 深色剧本工作台 UI 改造设计

## 目标

为 React 用户端恢复稳定、可长期使用的深色创作工作台。修复导航折叠后图标被裁切的问题，并提供持久化的明暗主题切换。首页视频英雄区不纳入本次改造。

## 范围

- 影响 React 用户端的共享壳层：`/script`、`/history`、`/tts`、`/settings`。
- 重点优化 `/script` 的双栏创作工作台。
- 保留 Express 多页面 URL 和现有登录、生成、历史、设置接口。
- 不修改旧 HTML 页面、后端 API、提示词或数据存储。

## 视觉规则

### 默认深色主题

- 深色蓝黑作为页面和内容区底色，低对比面板区分层级。
- 珊瑚色 `#f07167` 只用于主操作、当前导航和焦点状态。
- 内容卡片、输入区域和浮层使用 8px 圆角，减少大圆角堆叠。
- 文字使用明确的主、次、弱三级对比，避免截图中工具栏与输入区边界不清。

### 浅色主题

- 以冷白页面和白色面板为底，采用浅灰边界和柔和阴影。
- 保持同一珊瑚色作为关键操作色，使两种主题的任务层级一致。
- 不改变布局尺寸、路由、表单状态或用户数据。

## 交互设计

### 导航

- 展开宽度为 220px，折叠宽度为 60px。
- 折叠态的品牌文字和菜单文字隐藏，但每个图标保持居中、完整可见、最小 32px 点击区。
- 导航切换按钮始终位于左上角，携带“收起导航”或“展开导航”的无障碍标签。
- 当前页面使用背景与左侧细线共同提示，不能只依赖颜色。

### 顶部工具栏

- 左侧显示页面标题；右侧依次显示主题切换、账号和退出。
- 主题切换为图标按钮并具有提示文案，切换结果存入 `localStorage`。
- 初始主题读取用户上次选择；未选择时使用深色主题。

### 剧本工作台

- 保持原有左侧输入和实体信息、右侧模式控制和输出区域。
- 分隔条维持 8px 宽，可拖动，悬停与拖动时给出可见反馈。
- 左侧最小宽度 320px，右侧最小宽度 460px；窄屏切换为纵向布局，隐藏拖动条。
- 空状态保持可见的下一步提示，但使用克制图标和文字，不遮挡输出区。

## 组件与状态

- `UserLayout` 管理导航折叠状态和主题状态；主题状态同步至 `document.documentElement.dataset.theme`。
- 全局 CSS 使用主题变量，`[data-theme='light']` 覆盖色彩变量，业务页面不写独立主题分支。
- `ScriptPage` 仅保留现有表单和分栏尺寸状态；本次不改变生成请求与历史保存逻辑。

## 验收标准

1. 折叠和展开导航时，五个导航图标完整可见且可点击。
2. 在 `/script` 拖动分隔条后，左右宽度改变且均不小于约定最小值。
3. 主题按钮能在深色和浅色间切换，刷新页面后保持当前选择。
4. 深色和浅色主题下，`/script`、`/history`、`/tts`、`/settings` 的文字、边界、输入控件和按钮均可辨识。
5. Express 多页面校验、React 架构校验和前端构建通过。

## 非目标

- 不重做首页视频英雄区。
- 不替换 Ant Design、React 或 Express 架构。
- 不引入新的图标库或外部视觉资源。
