# 剧本空状态光效卡片设计

## 目标

将剧本页的空状态提示升级为主题自适应的光效引导卡片，在不改变空状态业务逻辑的前提下提升视觉引导性。

## 范围

- 仅修改剧本生成区域的 `.script-empty` 空状态展示。
- 保留既有图标与“先提取人物与场景，确认后再生成剧本”提示。
- 增加短标题“准备创作”、边缘移动光点、柔光射线和装饰分隔线。
- 不修改剧本生成流程、状态判断、接口或数据结构。

## 主题行为

- 深色主题使用黑灰底、白色移动光点和柔光射线，接近用户提供的 Uiverse 视觉语言。
- 浅色主题使用浅蓝灰底、主题蓝光点和柔和蓝紫射线，与主软件浅色风格保持一致。
- 卡片色彩通过现有主题选择器或语义变量提供，不固定为单一深色外观。

## 布局与可访问性

- 卡片宽度使用 `min(100%, 420px)`，最小高度为 220px，适配窄屏。
- 原始 SVG 图标和说明文案保留；新增标题不替代说明文案。
- `prefers-reduced-motion: reduce` 时停用移动光点动画。
- 装饰元素标记为 `aria-hidden="true"`，不影响读屏顺序。

## 验证

- 浅色和深色主题下检查空状态色彩、文字对比度及边框。
- 检查 320px 窄屏无水平溢出。
- 检查减少动态效果偏好下光点动画停用。
- 运行现有剧本页前端测试与构建命令。
