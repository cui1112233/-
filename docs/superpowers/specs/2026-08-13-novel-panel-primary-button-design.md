# 小说面板主按钮渐变样式设计

## 目标

将小说面板中承担提交、生成、保存、复制等主要操作的 `.btn.primary` 统一替换为紫蓝渐变的圆角按钮风格；不改变既有按钮事件、接口、页面布局或状态逻辑。

## 范围

- 修改 `public/novel-panel/workbench/style.css` 中 `.btn`、`.btn.primary` 和对应交互状态。
- 保持 `.btn.secondary` 为轻量描边按钮。
- 保持 `.btn.danger`、`.btn.danger-outline` 为红色危险操作语义。
- 保持 `.icon-btn`、`.instruction-nav-button`、`.small-btn` 的尺寸和用途不变。
- 不修改 `index.html` 和 `app.js`，现有 `primary` class 即为样式入口。

## 样式行为

### 主按钮

`.btn.primary` 使用从深靛蓝到柔和蓝紫的渐变背景、白色粗体文字和 30px 圆角。保留工作台的紧凑最小高度与内边距，避免在表单工具条和移动端产生布局溢出。

默认状态提供低强度阴影与缓慢 shimmer。悬停时渐变提亮、按钮上移 2px，并使用轻微背景流动效果。按下时缩放至 0.95 并缩短阴影距离。

### 其他按钮

`.btn.secondary` 维持现有表面色和描边，仅延续已有的轻微上移反馈。危险按钮继续使用警示色，关闭、删除和恢复默认等操作不会被误标为主操作。

### 可访问性与主题

保留既有禁用状态、焦点轮廓及移动端规则。对于系统开启“减少动态效果”的用户，关闭 shimmer 和 hover 粒子动画，并移除过渡效果。主按钮渐变使用现有主题语义令牌，以适配工作台的浅色与深色主题。

## 实现边界

- 不更改按钮 HTML、按钮文本、ID、`data-*` 属性或 JavaScript 监听器。
- 不新增第三方依赖。
- 不将 Uiverse 的 CSS 注释写入工作台源码。
- 不修改独立 V77 EXE；仅修改一战晟铭小说面板静态资源。

## 验证

1. 运行小说面板资源合约测试，确认工作台资源仍可加载。
2. 检查主按钮、次要按钮、危险按钮、禁用按钮和键盘焦点状态。
3. 检查浅色与深色主题及移动端布局，不出现文字溢出或按钮重叠。
