# 批量工厂发布统一设置规格

## 目标

把“版本配置 + 同步批量后台配置”从生产统一设置移动到发布统一设置，并把发布页收敛成清晰的批次级发布控制。

## 生产统一设置

生产统一设置不再展示版本配置、后台同步状态或同步按钮。它只负责生产行为：生产方式、剧本提示词、人物/场景提示词、视频模型、画幅、VIDEO 时长/固定单 VIDEO，以及约束设置。

约束设置继续直接内联在生产统一设置 Drawer 中，包含：基础设定（人物 / 场景）、画面前缀词、画质约束、画面限制、负面提示词。

## 发布统一设置

发布统一设置使用右侧 Drawer。顶部展示当前批次范围，随后依次为：

1. 版本配置
   - 选择已发布的“批量发布配置 Vn”。
   - 显示当前批次已同步的发布版本。
   - 后台存在新发布版本时只提示，不自动覆盖当前批次。
   - 用户点击“同步最新配置”后把最新发布配置载入当前 Drawer 草稿；用户点击“保存发布统一设置”后才写入当前批次快照。

2. 视频管理系统账号状态
   - 打开 Drawer 时自动校验账号。
   - 在线：显示蓝色状态点 + 账号名字 + “账号在线”。
   - 校验中：显示“正在验证账号状态...”。
   - 登录异常/失效：显示“登录异常”“账号登录状态已失效”和“重新登录”按钮。
   - 重新登录成功后自动再次校验。
   - 登录态、Cookie、账号名和运行时账号状态不得进入版本配置快照。

3. 发布设置
   - 素材复用：下拉选项“ 不复用 / 复用 ”。
   - 水平翻转：下拉选项“ 不翻转 / 翻转 ”。
   - 不再展示或新写入“解压视频数量”。
   - 不再展示或新写入“AI头部”。

## 版本配置数据

批量发布版本配置只保存发布参数，不保存生产参数。当前确认的可版本化参数仅为：

- `materialReuse: boolean`
- `horizontalFlip: boolean`

批次发布设置同时保存配置快照元数据：

- `configProfileKey`
- `configProfileName`
- `configProfileVersion`
- `configProfileSyncedAt`

历史批次中存在旧 `jieyaVideoCount` / `aiHead` 字段时允许读取，但新的发布统一设置保存动作不再主动写入这两个字段。

## 视频管理系统集成边界

优先复用小说获取现有的视频管理系统登录/校验能力。若仓库中无法定位可复用接口，不伪造在线状态、不硬编码外部地址、不保存凭据；为批量工厂暴露一个受认证的适配接口，只有在实际视频管理系统适配器可用时返回 online，否则明确返回 login_required/unavailable，并由前端展示重新登录入口。
