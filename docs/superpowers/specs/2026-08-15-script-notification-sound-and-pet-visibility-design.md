# 剧本通知音与 CM 显示开关设计

## 目标

为剧本工作流提供简短的任务结果提示音，并让用户能按账号关闭提示音或隐藏 CM 宠物。

## 范围

### 提示音

仅在剧本页面以下结果发生时播放：

- 人物与场景提取完成、重新提取完成：成功音。
- 剧本生成完成：成功音。
- 人物与场景提取失败、重新提取失败、剧本生成失败：警示音。

网络错误、404、鉴权失败和上游错误只要最终进入上述失败分支，均播放同一警示音。复制、保存、删除、切换设置等操作不播放声音。

### 设置

“设置 → 模型与助手”增加两个默认开启、按账号保存的开关：

- `提示音`：控制上述剧本任务的成功音与警示音。
- `显示 CM 宠物`：控制登录后工作页右下角 CM 的显示。

关闭提示音后，页面不会创建或播放声音。关闭宠物后，布局不挂载 CM 组件；重新开启并保存后，刷新或重新进入工作页恢复显示。

## 技术设计

### 配置数据

用户配置增加：

```json
{
  "notifications": {
    "soundEnabled": true,
    "petVisible": true
  }
}
```

服务端为旧配置补齐默认值。公开配置接口返回这两个布尔值，但继续不返回 API Key。

### 声音模块

新增前端纯函数模块，使用浏览器 `AudioContext` 合成两类短音效：

- 成功音：两段短促上行音。
- 警示音：两段短促下行音。

模块读取当前账号配置；配置关闭、浏览器不支持 Web Audio、音频上下文被浏览器策略阻止时直接静默返回，绝不影响提示消息、宠物状态或请求结果。

### 页面集成

剧本页在既有 `message.success` 与 `message.error` 的对应提取、重新提取和生成分支中调用声音模块。成功和失败仍保留现有宠物状态事件。

共享布局读取账号配置并仅在 `petVisible` 为真时挂载 `StackyPet`。设置保存后通过浏览器自定义事件通知布局即时更新显示状态，无需重新登录。

## 验证

- 配置接口对旧用户返回两个默认开启的设置，并保存用户更改。
- 设置页显示两个开关且保存请求带上设置值。
- 声音模块分别覆盖成功音、警示音、关闭状态和不支持音频的静默回退。
- 剧本页的提取、重新提取、生成成功/失败分支调用正确的提示音。
- 宠物关闭时共享布局不挂载 `StackyPet`，开启时正常挂载。
- 运行相关 Node 测试、前端生产构建和浏览器验收。
