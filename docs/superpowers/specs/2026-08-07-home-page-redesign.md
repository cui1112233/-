# 一战晟铭 首页简约动态重设计规约

## 1. 核心理念与定位
- **定位**：小说转可视化剧本的高效、简约、玻璃态创作控制台。
- **视觉风格**：承袭已有的暗色（为主）/亮色玻璃态风格（Glassmorphism），移除任何与“积分/额度”相关的展示，突出“即时创作”的效率感。
- **动态交互**：引入流畅、自然的微动效（如：流光边框、浮动卡片、淡入淡出、文字打字机或脉冲微光），使整个首页显得富有生命力和现代科技感。

## 2. 界面版块布局（PC 端与移动端适配）

### 2.1 动态欢迎面板 (Dynamic Welcome Banner)
- **视觉**：极简高雅的排版。
  - 主标题：`一战晟铭` 或 `探索文字的视觉边界`。
  - 副标题：动态变换的引导短句（例如：“将小说章节转化为可视化剧本...”），伴有渐显与轻微的上下浮动效果。
- **流光背景**：横幅背景引入极其淡雅的 Canvas 或 CSS 渐变流光（Gradient Glow），在暗色下如极光般缓慢变幻。

### 2.2 极简快捷入口组 (Dynamic Quick Actions Grid)
提供 3 个高质感、高动态反馈的卡片入口，均匀排列（移动端自动变为横向滑轨或紧凑的双列网格）：
1. **新建剧本项目 📝**
   - *动作*：点击直接激活左侧侧边栏的“剧本生成”并打开输入界面。
   - *动态*：Hover 时产生主色调（`#f07167`）的流光边缘和轻微 3D 浮动感，图标有微弱的旋转或弹跳。
2. **AI 智能 Agent 🤖**
   - *动作*：一键直达“Agent 工作区”。
   - *动态*：Hover 时伴有蓝/紫色脉冲外发光，突显科技感。
3. **声音工坊 🎙️**
   - *动作*：跳转至“配音”功能。
   - *动态*：Hover 时声音波形图标会有轻微起伏的动画。

### 2.3 最近剧本画廊 (Recent Projects Gallery)
- **布局**：简约的多列网格，自动拉取 `localStorage` 或后端提供的历史生成记录。
- **极简设计**：卡片不再包含复杂的表格，只保留：
  - 代表生成类型的精致 Pill 标签（“爆款开头” / “连续脚本”）。
  - 小说片段的淡雅遮罩预览（Preview Text）。
  - 创建时间与时长信息。
- **无 Hover 适配（移动端）**：
  - PC 端：Hover 卡片时浮现“继续编辑 ➔”与“删除 ✕”图标，并伴有 Scale(1.02) 的缩放和阴影提升。
  - 移动端：直接展示卡片，卡片右上角有简洁的 `···` 更多操作按钮，点击拉起底部操作面板。

## 3. 动态效果与 CSS 微交互实现
为确保整体“简约而不单调，炫酷而不刺眼”，所有动效控制在极短且舒缓的缓动曲线内：

```css
/* 1. 浮动动画 - 用于图标或卡片 */
@keyframes floatUp {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-6px); }
}

/* 2. 背景渐变极光流光 - 用于 Banner */
@keyframes auroraGlow {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

/* 3. 卡片悬浮主缓动 */
.quick-action-card {
  transition: transform 0.3s cubic-bezier(0.34, 1.56, 0.64, 1),
              box-shadow 0.3s var(--transition),
              border-color 0.3s var(--transition);
}
```

## 4. 移动端自适应优化
- **大屏（>= 1024px）**：网格三列排版，欢迎面板完全展开，最近作品大卡片展示。
- **平板（768px - 1023px）**：快捷卡片转换为双列网格，最近作品两列排版，折叠部分次要文字。
- **手机（< 768px）**：
  - 欢迎横幅高度缩减，背景极光流光变静止，保留文字渐入。
  - 3 个快捷卡片转为支持左右触控滑动的轨道，或极其精致的小网格。
  - 移除所有 Hover 触发效果，将高频点击范围扩大至整张卡片。
