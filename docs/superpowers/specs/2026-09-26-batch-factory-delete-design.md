# 水货批量工厂：单书与项目删除设计

## 目标

用户可删除当前账号下的一本小说，或删除整个批量项目。删除应清理该范围内的本地批量工厂数据，且不会改动任何已经提交到 121 的外部内容。

## 范围与边界

- 单书删除：仅删除指定 `batchId` 内的指定 `bookId`，保留同批量的其它书。
- 项目删除：删除整个批量及其中全部书。
- 两类删除均只允许资源所属账号发起；越权或不存在统一返回未找到。
- 不主动取消或删除第三方供应商、121 已提交内容；其本地引用和本地任务记录会被删除。
- 本地合成文件的物理回收不在本次范围内，避免删除仍可能被其它任务引用的产物；数据库引用被清理后由既有存储清理策略处理。

## API 与服务

V12 公开入口新增：

- `DELETE /api/batch-factory/v12/batches/:batchId/books/:bookId`
- `DELETE /api/batch-factory/v12/batches/:batchId`

Node V12 适配层将只读/删除请求转发到 Go V11 存储服务。Go 的批量工厂存储接口新增删除批量与删除单书操作，并在一个数据库事务中完成。

## 事务删除顺序

先校验批量及书的归属，然后自叶子向父级删除：

1. 自动化状态（Node 本地持久化）在 API 成功后移除对应书或批量的运行记录。
2. 生产任务关联的隐藏记录、事件、任务与任务组。
3. 合成任务的关联数据与合成任务。
4. 视频关联、导演关联、钩子修订、草稿、资产图片与资产。
5. 书记录、书行；项目删除时继续删除批量设置/快照/记录与批量行。

数据库任一删除失败时事务回滚，调用端仍可继续使用原数据。服务端不接受客户端提供的删除关联 ID，全部依据受保护的 `owner + batchId + bookId` 进行范围限定。

## 前端交互

- 项目库：批量工厂卡片显示删除图标，确认文案说明会删除其中所有书及本地生产记录。
- 批量工作台：每本书的操作区提供“删除本书”，确认文案说明仅影响该书。
- 删除成功后刷新项目列表或当前批量；如果删除了最后一本书，保留空批量以便用户继续添加书。删除整个项目后回到项目列表。
- 失败时显示后端错误，页面不预先移除任何条目。

## 验证

- 存储测试：单书删除只移除目标书，跨账号不可删除；批量删除清理所有书并不可再读取。
- HTTP 测试：签名账号可删除，错误账号得到未找到。
- 前端源契约测试：两个确认入口调用相应 API，成功后刷新/返回。
- 前端生产构建与 Go 专项测试。
