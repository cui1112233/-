# 剧本动态提取预设同步设计

## 目标

让剧本生成页的“提取指令”完全由管理后台已发布的提取预设驱动。管理员发布、改名、更新正文、添加或隐藏预设后，用户刷新剧本页即可看到最新可用选项；生成请求使用用户选中的预设 ID 对应的当前线上正文。

## 管理后台发布规则

- 预设状态为 `published`：出现在用户“提取指令”选择框。
- 状态为 `draft` 或 `archived`：不出现在用户选择框。
- 新建预设只有满足剧本提取协议才可进入该选择框：`module: script`、`kind: base`、`protocolLock.format: extract`。
- 已发布预设改名后，用户框显示新名称。
- 已发布预设更新正文并发布新版本后，用户下一次提取立即使用新正文。
- 归档当前线上版本或发布替代版本后，用户框以最新目录为准。

## 标识与目录

- 后台预设 ID 是稳定业务标识，用户选择值直接使用该 ID，例如 `script-extract`。
- 不再使用前端写死的 `standard`、`novelPanel` 映射和显示文案。
- 用户目录接口只返回已发布预设的安全元数据：ID、名称、说明、版本、协议锁；不返回正文。
- 后端提取接口仅接受目录中符合提取协议且处于已发布状态的 ID；非法、草稿、归档、非提取预设均回退到当前可用的默认提取预设。

## 用户端行为

- 页面加载时读取剧本预设目录并筛选提取预设。
- “切换指令”弹窗以目录动态渲染单选项，显示管理员名称、说明和版本。
- “当前提取指令”显示选中项的最新管理员名称。
- 已保存草稿中的旧 `standard` 映射为 `script-extract`，`novelPanel` 映射为 `script-extract-novel-panel`。
- 若草稿已选 ID 被后台隐藏，页面自动切换为目录首个可用预设并保存草稿。
- 没有任何已发布提取预设时，提取按钮禁用并显示明确原因；不发送无效请求。
- 目录加载失败时保持当前草稿选择不可用，提示用户刷新或联系管理员，不用旧写死名称伪造可用状态。

## 服务端行为

- 提取预设白名单由 `presetStore.listCatalog('script')` 或等价已发布数据实时计算。
- `buildExtractMessages` 根据请求的预设 ID 获取当前已发布预设正文。
- 不存在或不符合提取协议的 ID 统一选择第一个可用提取预设；无可用预设时返回业务错误，避免以未知固定正文运行。
- 每个请求实时读取预设存储，不需要重启服务。

## 测试

- 目录仅包含已发布且 `protocolLock.format === 'extract'` 的剧本基础预设。
- 改名后的目录名称在用户选择框和当前状态中显示。
- 已隐藏的草稿选项自动回退到首个可用项。
- 旧草稿值兼容映射。
- 服务端拒绝或回退草稿、归档、非提取 ID。
- 新增已发布提取预设可在用户选择框出现并用于生成。
- 前端生产构建与 Node 测试通过。
