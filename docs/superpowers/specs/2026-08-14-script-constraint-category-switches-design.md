# 剧本约束分类开关与预设可见设计

## 目标

将剧本生成的“约束设置”改为总开关加四个独立分类开关。每个分类只有开启后才展示预设选择、系统预设提示词和台词添加词；用户可查看但不能改写系统预设，台词添加词仅追加到系统预设之后。

## 范围

适用输出模式：画布模式、剧情模式、分镜模式。

剧本模式继续禁用约束设置，后端继续忽略所有约束数据。

涉及分类：

1. 画面前缀词（`prefix`）
2. 画质约束（`quality`）
3. 画面限制（`restriction`）
4. 负面提示词（`negative`）

## 状态模型

约束对象保留总开关 `enabled`，每个分类新增 `enabled`：

```json
{
  "enabled": true,
  "prefix": {
    "enabled": true,
    "presetId": "script-constraint-prefix-2d",
    "customText": "少女向、柔和暖色、日系校园氛围"
  },
  "quality": { "enabled": false, "presetId": "", "customText": "" },
  "restriction": { "enabled": false, "presetId": "", "customText": "" },
  "negative": { "enabled": false, "presetId": "", "customText": "" }
}
```

旧草稿缺失分类 `enabled` 时：如果该分类存在 `presetId` 或非空 `customText`，迁移归一化为 `enabled: true`；否则为 `false`。该规则保持已保存的旧约束效果。

总开关关闭时保留四类配置与开关状态，但后续生成不注入约束文本。

## 前端交互

约束设置弹窗顶部保留“启用本次及后续剧本输出约束”总开关。

总开关开启后显示四个分类行，每行包括名称和开关：

```text
画面前缀词    [开关]
画质约束      [开关]
画面限制      [开关]
负面提示词    [开关]
```

分类关闭时不显示其下方配置，并且不参与生成。

分类打开后显示：

1. 系统预设下拉框，允许清空；
2. “系统预设提示词”只读区域：已选择预设时展示其当前系统正文，未选择时显示“尚未选择系统预设”；
3. “台词添加词”可编辑文本区：输入内容只追加，不能替换系统预设；
4. 若未选预设，用户仍可只填写台词添加词。

每个系统预设均从服务器返回的已发布目录读取 `body`，不能让前端硬编码预设正文。只读区域不提供编辑入口。

保存按钮维持“保存并启用”；实际保存总开关与四个分类开关。保存后写入当前用户的剧本草稿。

## 提示词组装

后端仅在以下条件同时满足时使用一个分类：

- 当前格式不是 `shortdrama`；
- 总开关 `constraints.enabled === true`；
- 分类开关 `constraints[category].enabled === true`。

分类文本的组装不再采用“自定义优先覆盖预设”。规则为：

```text
系统预设正文（若选择且有效）
台词添加词（若非空）
```

用单个换行拼接非空部分。`customText` 语义改为“台词添加词”，其保存字段名不变以兼容既有草稿和 API。

系统预设无效、未发布、类型不匹配或分类不匹配时，忽略预设正文；台词添加词仍可独立生效。

输出包裹顺序不变：

```text
【画面前缀】
已启用 prefix 的组合文本

【画质约束】
已启用 quality 与 restriction 的组合文本

当前模式主体

【负面提示词】
已启用 negative 的组合文本
```

空分类不输出标题。画质约束与画面限制继续合并到同一 `【画质约束】` 区块。

## 安全与数据边界

- 系统预设正文仅由已发布、协议锁定为 `constraint` 且类别匹配的 addon 预设提供。
- 用户无法通过 `presetId` 引用任意非约束预设。
- 台词添加词只保存在用户浏览器剧本草稿中，不修改全局预设、管理后台数据或其他用户草稿。
- 后端永远以服务端预设正文为准，浏览器展示文本不能作为可信系统预设输入。

## 测试与验收

### 前端

1. 默认四类开关关闭，分类配置区域不显示。
2. 总开关开启不会自动打开四类。
3. 仅打开画面前缀词并选择 2D 动漫时，可见其只读系统提示词。
4. 填写台词添加词时，预设展示文本不改变。
5. 未选择预设但打开分类并填写台词添加词时允许保存。
6. 旧草稿中已有预设或自定义文本的分类会自动打开。

### 后端

1. 关闭分类开关时即使有 presetId/customText 也不注入。
2. 开启分类并选择预设、填写添加词时，生成系统提示词含“预设正文 + 添加词”。
3. 开启分类但仅有添加词时只注入添加词。
4. 画质约束和画面限制仍在同一个区块。
5. `shortdrama` 无论任何开关状态均不注入约束。
6. 无效或错误分类的 presetId 不注入其正文，也不影响用户添加词。
