# 水货生产完整迁入设计

## 目标

在前贴（qiantie）平台中新增一级功能“水货生产”。它完整覆盖 `/Users/ming/Downloads/ai-video` 的业务能力，但不复制其 Vue、Python、独立登录、独立端口或旧项目数据。

水货生产以 `http://localhost:5175/` 已确认的生产台布局和操作顺序为界面基础。它与剧本生成、配音、历史、Agent 等平台功能互不干扰，只复用平台级账号、权限、模型目录、系统预设词、MySQL、Redis 和对象存储能力。

## 已确认范围

### 平台与导航

- 前贴是统一平台，水货生产是其中的独立一级功能。
- 平台导航新增“水货生产”。
- 水货生产内部保留现有 5175 原布局的二级结构：作品列表、分段生产台、人物场景预设。
- 不把生产台改造成通用标签页或卡片式后台；保留现有分段表格、素材库、提示词区和资产预设的工作区布局。
- 水货生产独立保存项目、分段、资产、提示词、素材、任务和导出记录；不得读写其他平台模块的业务数据。

### 原文与分段

- 创建项目支持上传或粘贴小说、分镜、字幕和音频。
- 支持三种分段入口：
  - 快速初分段：按固定行数拆分，兼容 ai-video 的手动分镜逻辑。
  - 人工分段：新增、拆分、合并、排序、删除和编辑原文分段。
  - 智能分段：用户选择管理员开放的文本模型和系统“分段”预设词；后端读取真实提示词并生成候选分段。
- 支持导入已分段文本，识别空行、编号、场景标题、段落标题和时间码。无法识别时保留全文为一个候选分段。
- 智能分段和导入识别都只能产生待确认结果。只有用户点击“确认分段”后，人物、场景、提示词、图片和视频阶段才可执行。

### 资产、分镜和提示词

- 覆盖 ai-video 的人物、场景、道具、角色类型、角色模板、模板图片、角色提取、角色与分段匹配、单条和批量重生成能力。
- 人物、场景和道具允许 AI 分析预填、手动新增、编辑、绑定到分段、上传参考图、生成参考图和选择主图。
- 分段保留原文、字幕、配音关联、绑定资产、图片提示词、视频提示词、图片素材、视频素材和操作区。
- 提供分镜增删改、单段调整、批量修改、单条 AI 重生成、前后缀批量套用和导入后的人工校正。
- 用户手动编辑的分段、资产、提示词和素材关系必须标记为人工内容；后续 AI 分析默认不覆盖，只有用户明确选择覆盖时才可替换。

### 系统预设词

- 所有系统真实提示词统一存放在 qiantie 服务端 `prompts/` 及对应数据库版本记录中。
- 前端只可获得预设名称、用途、适用模块、公开说明、可选参数和兼容关系；不得获取系统真实提示词正文。
- 水货生产调用模型时，Go 后端读取指定预设词版本，组合项目级补充词、前后缀和变量，再发送请求。
- 管理员可管理分段、人物提取、分镜、图片、视频、配音、导出等预设词；普通用户仅可选择系统预设词并编辑自己的项目补充词。
- 已提交任务保存预设词版本及最终提示词快照。后续预设词变更不得影响既有任务。

### 模型目录与管理员权限

- 管理员拥有绝对模型管理权，可新增、编辑、停用、删除、测试和授权模型。
- 用户只能从管理员已启用、已授权的文本、图片、视频、配音模型中选择；不能填写自己的 API 地址或密钥。
- 同时支持两种模型接入：
  - 标准适配器：选择服务商和适配器，配置模型名、密钥引用及可公开参数。
  - 通用 HTTP 接入：服务端配置 URL、请求方式、请求头模板、请求体模板、变量映射、异步查询或回调规则和结果解析规则。
- 密钥加密保存，仅在 Go 服务端解密使用。普通用户不能读取密钥、真实接口模板或完整请求日志。
- 通用 HTTP 接入必须拒绝访问内网、回环和云元数据地址，且有请求超时、大小限制和审计记录。
- 每个任务保存模型、适配器、参数和模型配置版本快照；修改默认模型不会改变已提交任务。

### 图片、视频、配音与导出

- 覆盖 ai-video 的单条和批量生图、图生视频、视频任务查询、素材上传、删除、主图选择、视频合并、下载和剪映草稿导出能力。
- 任务由 Redis 队列执行，支持供应商回调和后端轮询两种完成方式。
- 图片、视频、配音和导出文件通过统一对象存储接口管理：
  - 开发和测试：本地文件实现。
  - 线上：TOS 或 MinIO 实现，由部署配置选择。
- 存储对象按用户和项目隔离，键格式固定为：

```text
shuihuo-production/<user-id>/<project-id>/source/
shuihuo-production/<user-id>/<project-id>/images/
shuihuo-production/<user-id>/<project-id>/videos/
shuihuo-production/<user-id>/<project-id>/audio/
shuihuo-production/<user-id>/<project-id>/exports/
```

- MySQL 只保存对象键、公开访问或签名访问策略、素材元数据和业务关联，不保存图片或视频二进制。
- 生成完成后必须先写入对象存储、再写入 MySQL 素材记录；两步均成功才可将任务标为成功。

### 任务状态与保护

任务统一状态为：

```text
draft -> queued -> running -> succeeded
                         -> failed
                         -> cancelled
```

- `draft`：参数尚未提交。
- `queued`：已保存任务并进入 Redis 队列。
- `running`：Worker 已取得锁并调用或等待上游模型。
- `succeeded`：对象存储和 MySQL 素材记录均已成功写入。
- `failed`：保存结构化错误码、可见失败原因和上游请求标识，允许重试。
- `cancelled`：仅允许在尚未终态时取消；已保存素材不删除。
- Redis 锁防止同一任务重复执行；回调和轮询按供应商任务标识幂等处理。
- 网络中断、重复回调、超时和 Worker 重启不得造成重复素材、重复状态转换或重复扣减。
- 前端只能根据真实状态展示结果，不能把“已提交”显示为“已生成”。

## 技术架构

```text
React + Ant Design 前端
  -> qiantie Go HTTP API
    -> 水货生产领域服务
      -> prompt 预设词服务
      -> 模型目录与模型适配器
      -> Redis 队列 / 锁 / 进度
      -> MySQL 仓储
      -> 对象存储接口（本地 / TOS / MinIO）
```

### Go 模块边界

```text
backend/internal/shuihuo/
  projects/       项目、原文和版本
  segmentation/   快速、人工、智能分段与确认门禁
  assets/         人物、场景、道具、角色模板和参考图
  storyboard/     分镜及提示词编辑、批量套用
  media/          图片、视频、音频与导出素材关系
  tasks/          任务创建、状态机、重试、回调和轮询
  modelcatalog/   管理员模型目录与适配器配置
  prompts/        系统预设词组合、版本和变量替换
  storage/        本地、TOS、MinIO 对象存储实现
  exports/        合并、下载和剪映草稿
```

模块只经由明确接口依赖：领域服务不直接读取 HTTP 请求、不直接访问某个供应商 SDK；模型调用和存储调用都通过适配器接口完成。

### MySQL 核心数据

- `shuihuo_projects`：用户、名称、原文、当前阶段、分段确认版本、模型选择。
- `shuihuo_segments`：项目、顺序、原文、字幕、人工锁、图片和视频提示词。
- `shuihuo_assets`：人物、场景、道具、视觉设定、人工锁和参考图关系。
- `shuihuo_segment_assets`：分段与资产绑定。
- `shuihuo_asset_types`、`shuihuo_asset_templates`：角色类型和模板。
- `shuihuo_media`：对象键、媒体类型、来源、尺寸、主图标志和分段关联。
- `shuihuo_tasks`、`shuihuo_task_events`：任务快照、状态转换、重试、上游 ID 和错误。
- `model_definitions`、`model_versions`：管理员模型目录、适配器和参数规则。
- `prompt_definitions`、`prompt_versions`：系统预设词及版本。
- `audit_logs`：模型、预设词、权限、任务和管理员操作审计。

所有水货生产业务表必须具备用户归属或能经项目追溯到用户归属。每个查询均以当前登录用户范围过滤；管理员跨用户操作需要明确审计。

## 非目标

- 不迁移 ai-video 的历史项目、旧角色模板、旧图片、旧视频或旧用户数据。
- 不运行 ai-video 的 Vue 或 Python 服务作为水货生产运行依赖。
- 不向普通用户暴露模型密钥、系统真实提示词、通用 HTTP 接口模板或管理员审计明细。
- 不在未确认分段前自动生成人物、场景、提示词、图片或视频。

## 验收原则

- 每一项迁入能力都必须有 React 页面入口、Go API、MySQL 持久化、权限检查和实际交互验证。
- 有异步行为的能力还必须验证 Redis 队列、任务状态、对象存储结果和失败重试。
- 静态检查、单元测试、接口测试和真实浏览器点击验证分别记录，不以其中之一替代其他验证。
- 未接入的模型或外部服务必须显示未配置/不可用，不能伪造生成成功。
