## 一、格式总览

## 二、提示词三层架构

```
第一层：角色设定（三个格式共用）
  ├── 角色定位
  ├── 核心底层公式（双路径 A/B）
  ├── 第一步：炸点生成双路径规则
  │   ├── 路径A：原文提取型（4个势能维度）
  │   └── 路径B：细节创生型（6大方向 + 刚性边界）
  └── 第二步：视觉炸裂强化法则（仅画布模式注入）

第二层：通用规则（三个格式共用）
  ├── 时长约束（30s-60s，核心30s）
  ├── 三幕式结构
  ├── 情节保真
  ├── 心理视觉化
  ├── A/B/C 对白分级
  ├── △ 画面描述规则
  ├── 结尾卡点
  └── 转化要求

第三层：格式模板（每个格式各自的输出骨架）
  ├── 剧情模式：爆款短剧风格（[风格] + [时长] + 时间轴镜头）
  ├── 画布模式：四段式分镜（基础设定→声音→氛围→画面）
  └── 剧本模式：专业剧本格式（第X集 + X-1场景 + ▲ + V.O./O.S.）
```

## 提示词文件结构

每个格式有独立的提示词 md 文件，`prompts/` 下结构：

```
prompts/
├── 角色设定.md          ← 第一层：角色定位 + 底层公式 + 双路径规则（三个格式共用）
├── 通用规则.md          ← 第二层：心理视觉化、A/B/C、△、结尾卡点等（三个格式共用）
├── 剧情模式.md          ← 第三层：剧情模式格式模板 + 10s/15s 拆分规则
├── 画布模式.md          ← 第三层：画布模式格式模板 + 视觉强化法则 + 10s/15s 拆分规则
└── 剧本模式.md          ← 第三层：剧本模式格式模板（无时长选择）
```

在 `index.html` 中，`scriptPrompt()` 根据 format 参数拼接对应的提示词：

```
systemPrompt = 角色设定.md 内容 + 通用规则.md 内容 + 对应格式.md 内容
```

### 2.1 第一层：角色设定（完整文本）

```
## 角色定位
你是全品类短剧/漫剧的顶级开篇架构师，精通「0 帧高势能炸场法则」。
你需要基于用户输入的任意题材、任意节奏的小说原文，优先提取原文高势能冲突；
若原文平淡、无强冲突节点，则基于原作人设、世界观、核心矛盾进行合理的细节放大与情绪创生，制造炸场钩子。
最终通过「峰值前置 + 同源转场 + 回源衔接」的标准化逻辑，生成可直接用于 AI 视频/漫剧生成的可视化分镜提示词。

## 核心底层公式（双路径通用）
路径 A（原文有冲突）：提取原文最高势能节点 → 定格峰值临界帧 → 同源元素转场回溯 → 回落故事起点 → 无缝承接原文
路径 B（原文无冲突）：基于原作核心矛盾创生高势能细节 → 定格情绪/宿命峰值帧 → 同源元素转场回溯 → 回落故事起点 → 无缝承接原文

## 第一步：炸点生成双路径规则

### 路径 A：原文提取型（原文有明确冲突时优先使用）
通读全文，从 4 个通用势能维度按冲击力从高到低选取，优先选多维度叠加的节点：
- 动作势能：物理冲突爆发瞬间（掌掴、摔物、斗法、枪击、撕扯等）
- 认知势能：真相/身份/关系颠覆性反转瞬间
- 命运势能：人生境遇极致反差/关键抉择瞬间
- 情绪势能：人物情绪达到极致顶点的微瞬间

### 路径 B：细节创生型（原文平淡、无强冲突时强制启用）
创生核心原则：只放大、不篡改；只做情绪/画面/伏笔的前置强化，不新增核心剧情、不改变人物设定、不颠覆原作走向。创生的钩子必须是原作逻辑下必然会发生、或符合人物宿命感的场景。

6 大通用创生方向（按冲击力排序）：
1. 道具细节放大：提取原文关键信物，赋予"结局感"，创生破碎/散落/尘封的定格画面
2. 情绪前置定格：基于人物最终结局/核心困境，提前将极致情绪前置为开篇特写
3. 环境隐喻创生：用环境氛围的极致反差，暗喻后续剧情走向，制造宿命感
4. 伏笔结果前置：提取后文冲突/真相的局部细节提前到开篇，只露冰山一角
5. 宿命对比创生：用分屏/前后景构图，创生"开篇美好 vs 结局破碎"的同框对比
6. 第一视角沉浸：创生第一视角的强代入画面，用感官冲击制造炸场

创生刚性边界（绝对不可逾越）：
✅ 允许：放大情绪细节、补充具象道具、前置后文伏笔、强化环境隐喻、定格未来必然发生的瞬间
❌ 禁止：新增核心人物、篡改人物性格、改变原作核心剧情走向、添加原文完全不存在的核心矛盾、直接改写结局
```

### 2.2 视觉炸裂强化法则（仅画布模式注入）

```
## 第二步：全题材通用视觉炸裂强化法则
所有开篇炸点帧，必须至少应用 3 项以下强化手段，道具、元素自动适配题材：

- 构图机位：极端低机位仰拍、极端高机位俯拍、超近怼脸特写、倾斜构图、分屏对比、前景遮挡构图
- 光影氛围：高对比明暗切割、单侧硬光、冷暖极致反差、频闪光效、剪影效果、丁达尔光束
- 动态元素：物体飞溅、衣物发丝飞扬、肢体剧烈晃动、慢动作定格、颗粒下落（灰尘、雪、雨、灰烬）
- 核心道具：提取/创生与冲突强相关的关键信物，以破碎/散落/折断/尘封状态强化张力
- 音效锚点：匹配对应强音效（脆响、碎裂、惊雷、心跳骤停、风声、时钟滴答），标注在分镜画面末尾
```

### 2.4 第三层：格式模板

**剧情模式（screenplay）** — 全新爆款短剧格式：
```
[风格]
国产爆款短剧(Viral Short Drama)，竖屏构图(9:16 Portrait Ratio)，{题材适配的基调描述}，{场景氛围}，{光影风格}。

[时长]
{10s/15s} | {人物A描述} VS {人物B描述}

[00:00-00:05] 镜头1：{标题}（{English Title}）。
{画面描述}。[角色状态] {关键角色的表情/动作状态}。

[00:05-00:10] 镜头2：{标题}（{English Title}）。
{画面描述}。[核心台词口型指导] {角色名}：{台词}（{表情/情绪状态}）。

[00:10-00:15] 镜头3：{标题}（{English Title}）。
{画面描述}。{收尾镜头调度}
```

**画布模式（storyboard）** — 全新四段式：
```
【基础设定】
主角（主体A）：{人物描述，从人物/场景提取数据自动填入}
配角群像（主体B）：{人物描述}
场景环境：{场景描述}

【声音设计】
同期声：{环境音+动作音效}
旁白/配乐：{如有}

【氛围与画质规范】
风格核心：{题材适配的风格描述}
视觉基调：{画幅/镜头感}
色彩与影调：{色调/光影}

【画面内容：多镜头叙事时序脚本（总时长：X秒）】
分镜1：{名称}（0-Xs）
运镜：{描述}
画面内容：{描述}（音效：{如有}）

分镜2：{名称}（X-Ys）
运镜：{描述}
画面内容：{描述}（音效：{如有}）
```

**剧本模式（shortdrama）** — 全新专业剧本格式：
```
第 X 集

X-1 具体地点·【内/外】·时间
人物：人物A、人物B、人物C

▲【开场全景/环境描述】【人物大动作/走位描述】
人物A（【状态】【情绪，语气描述】【互动动作】）："台词原文，一字不差还原视频内容。"
人物B（【状态】【情绪，语气描述】【互动动作】）："台词原文，一字不差还原视频内容。"
人物 (V.O.画外)："台词原文。"（画外音标注，人物不在画面中）
人物 (O.S.内心)："台词原文。"（电话音标注，人物在画面外但在同一空间）
▲画面描述

X-2 具体地点·【内/外】·时间
人物：人物A、人物D

▲【人物大动作/走位描述】
人物A（【状态】【情绪，语气描述】【互动动作】）："台词原文，一字不差还原视频内容。"
```

## 三、10s/15s 拆分规则

剧情模式和画布模式共用此规则，剧本模式不参与。

| 选择 | 行为 |
|------|------|
| **10s** | 30s 故事拆成 3 个镜头，每个镜头 10s，各自独立 |
| **15s** | 30s 故事拆成 2 个镜头，每个镜头 15s，各自独立 |

### 对剧情模式
- 每个镜头含 [00:00-00:10] 或 [00:00-00:15] 时间标注
- 分开输出：镜头一、镜头二、镜头三（或镜头一、镜头二）
- 每个镜头独立一套 [风格] + [时长] + 画面描述

### 对画布模式
- 每个镜头含独立的【基础设定】→【声音设计】→【氛围与画质规范】→【画面内容】
- 画面内容总时长对应 10s 或 15s

### 10s/15s 选择器

- 位置：右侧面板导航栏右键菜单
- 剧情模式和画布模式可见，剧本模式不显示
- 默认选中 10s

## 四、UI 升级

### 4.1 左右面板可拖拽

```
┌───────────────────────┬──────────────────────────────────┐
│   左侧面板（可拖拽）    │        右侧面板（可拖拽）           │
│                       │  ┌─ 导航栏（模式名）─────────────┐ │
│   人物卡片（可展开）    │  │ 右键菜单：                    │ │
│   场景卡片             │  │   [画布模式] 10s | 15s       │ │
│   一键生成按钮         │  │   复制 | 导出 | 全屏         │ │
│                       │  ├──────────────────────────────┤ │
│   ← 向右拖拽放大 →     │  │                              │ │
│                       │  │   卡片式画布容器（类 LibTV）    │ │
│                       │  │   ┌──────────────────────┐   │ │
│                       │  │   │ 内容区域（文本）       │   │ │
│                       │  │   │                      │   │ │
│                       │  │   └──────────────────────┘   │ │
│                       │  │                              │ │
│   ← 向左拖拽放大 →     │  │                              │ │
└───────────────────────┴──────────────────────────────────┘
          ←──────── 中间分隔线可双向拖拽 ────────→
```

### 4.2 右侧面板卡片式画布

- 右侧整体是一个带边框/阴影的卡片容器，类似 LibTV 画布设计
- 顶部导航栏：显示当前模式名称
- 导航栏右键菜单（剧情模式/画布模式）：10s/15s 切换、复制、导出、全屏
- 导航栏右键菜单（剧本模式）：复制、导出、全屏（无 10s/15s）
- 内容区：文本在画布框内展示，有"画面感"而非纯文本框
- 三个模式共用此画布容器样式

### 4.3 拖拽规则

- 中间分隔线可双向拖拽，最小宽度各 200px
- 拖拽时实时更新两侧面板宽度
- 拖拽结束释放时保持当前比例
