## 1. 目标与边界

在既有 `qiantie` 水货生产模块中实现独立的“漫剧解说工作台”。该工作台面向小说和字幕内容的分镜、素材、配音与视频生产，沿用现有项目、模型目录、任务、素材和存储后端。

工作台参考已分析产品的业务流程和密集生产表信息架构，但不复制其源码、品牌、账号数据、素材、密钥、授权校验或受保护资源。所有界面、数据结构和逻辑均在本项目中独立实现。

不在本次范围内：绕过第三方授权、伪造模型生成结果、保证未配置模型时的真实媒体产出、剪辑软件私有工程格式兼容。

## 2. 信息架构

### 2.1 项目库与编辑器

- 项目库继续独立展示项目卡片或列表；不在编辑器内显示项目侧栏。
- 用户进入项目后，页面切换为全宽、纵向滚动的漫剧解说工作台。
- 顶栏显示项目名称、完成度及分镜、图片、视频、音频数量。
- 顶部工具栏固定提供：`分镜调整`、`人物场景预设`、`引擎配置`、`AI 推理`、`批量操作`、`取消操作`、`任务/日志`、`导出`。

### 2.2 输入入口

新建项目时两种入口写入同一份源文本：

1. 上传文档：第一期支持 `TXT`、`SRT`、`DOCX`。`PDF` 作为后续可选扩展，必须先完成正文提取和用户核对。
2. 粘贴内容：用户直接粘贴小说原文或字幕文本。

导入完成后，系统创建有顺序和来源信息的源文本单元。用户可选择直接由 `SRT` 建立分镜，或由 AI/手动分段建立分镜；两条路径都进入同一编辑器和同一数据结构。

## 3. 分镜与源文本模型

### 3.1 核心实体

- `Project`：归属账号、输入来源、项目状态和统计数据。
- `SourceUnit`：原始文本的最小可追溯单位，保留顺序、文本和来源位置。
- `Storyboard`：用户编辑和生产的分镜行。
- `StoryboardSourceMapping`：分镜与一个或多个源文本单元的顺序映射。
- `PresetAsset`：角色、场景、道具或音色预设。
- `AssetCandidateMedia`：预设资产的候选参考图和已选主参考图。
- `DubbingLine`：每个分镜的音色、语速、情绪、台词和音频结果。
- `InferenceJob`：AI 分段或提示词推理任务。
- `MediaTask`：图片、视频、配音等异步生成任务。
- `ExportJob`：素材和字幕导出任务。

### 3.2 非破坏性调整

- 分镜序号下的向上合并按钮，把当前分镜关联的源文本单元追加到上一分镜；不只做不可恢复的字符串拼接。
- 拆分按源文本映射恢复为可编辑分镜，使用户能回退错误的合并。
- 删除分镜只移除该分镜及其映射，不删除项目中的源文本、资产或已产生的媒体；媒体清理仅在明确的后续清理策略中执行。
- 新增分镜插入当前行后，创建空白分镜并重排显示顺序。

## 4. 生产表与行内能力

工作台主区域是一张全宽分镜生产表，列顺序固定为：

`序号 | 字幕 | 配音 | 预设 | 提示词 | 片段库 | 操作`

每行是独立生产单元：

- `序号`：显示顺序、向上合并、拆分入口。
- `字幕`：可编辑旁白或台词。
- `配音`：选择音色、语速和情绪；支持单行试听与重生成。
- `预设`：绑定项目级角色、场景、道具和音色资产。
- `提示词`：维护独立的生图和视频提示词；支持 AI 推理、手动编辑和锁定已确认内容。
- `片段库`：显示主图、最多四张候选图、视频和音频。选中候选图会更新主参考但保留其他候选。
- `操作`：重生图、生成视频、删除分镜、在当前行后新增分镜。

## 5. 资产预设流程

预设资产按项目维护，分镜只绑定引用。流程固定为：

1. 选择文本 AI 模型和预设提示词。
2. 使用“智能预设”生成可编辑的角色、场景、道具或音色卡片。
3. 选择图片模型、画幅和风格参考图；三视图模式可选。
4. 提交生成后保留多个候选参考图。
5. 用户选定主参考图，并将资产绑定到一个或多个分镜。
6. 资产文字描述和主参考图作为分镜图片/视频提示词推理的上下文。

预设中心包含 `AI角色`、`AI场景`、`AI道具`、`AI音色`、`角色库`、`场景库`、`音色库` 标签；用户可编辑自己的项目资产，公共系统资产仍由管理员管理。

## 6. 任务、模型与导出

### 6.1 推理和批量范围

- `AI 推理` 可选全部分镜、未完成分镜或指定编号范围。
- `批量操作` 按图片、视频、配音、翻译分类提交任务。
- 图片任务可生成候选图；视频任务根据有无主图选择图生视频或文生视频；配音任务根据每行配置生成。
- 每个任务显示排队、运行、成功、失败、取消状态。失败允许重试，取消只停止未完成任务，不删除成功结果。

### 6.2 模型配置与故障表现

- 前端只调用正式后端 API 创建、查询、取消或重试任务，不模拟“生成完成”。
- 模型目录由后台配置。缺失文本、图片、视频或语音模型时，在提交前说明缺少的模型类型并阻止请求。
- 上游鉴权、网络、超时和模型输出不合法须保留真实错误状态，提供可理解的错误信息和重试入口。
- 管理后台继续负责模型、系统预设和公共技能管理；用户页面不暴露密钥、内部技能指令或开发实现细节。

### 6.3 导出

第一期导出：分镜表、原始或合成字幕、配音音频、图片/视频素材清单与可下载的项目素材。

剪辑工程格式导出作为独立后续适配项，不在第一期承诺与第三方私有格式完全兼容。

## 7. 保存、权限与错误处理

- 分镜编辑、资产绑定、候选图选中状态和任务结果均按登录账号及项目保存。
- 刷新、导航切换、返回项目库后恢复同一项目的已保存状态。
- 项目、素材、任务和导出结果必须按账号隔离；管理员不得通过普通用户工作台直接查看他人内容。
- 文档上传校验扩展名、大小和正文提取结果；解析失败不得创建空项目，须返回可见原因。
- API 错误沿用现有统一错误提示与错误日志机制，记录实际 HTTP 状态和后端错误码，不提供手动伪造反馈表单。

## 8. 验收与测试

实施完成前必须覆盖：

1. `TXT`、`SRT`、`DOCX` 上传和粘贴内容进入同一源文本流程。
2. AI 分段和手动分段生成可编辑分镜。
3. 非破坏性合并、拆分、插入和删除分镜。
4. 预设资产生成、候选图选择、分镜资产绑定与提示词上下文。
5. 单行及批量图片、视频、配音任务的提交、状态、取消和重试。
6. 缺少模型、上游超时、鉴权失败和无效模型输出的错误表现。
7. 刷新及导航后的数据恢复、账号隔离和导出。
8. 页面构建、关键 API 合同测试以及浏览器实际渲染检查。

真实图片、视频和配音结果的验收以前提条件为准：对应模型服务、鉴权、队列、数据库和存储服务均已配置并健康。测试不能把缺失外部服务误判为前端完成或失败。
