# 小说面板统一主题设计

## 目标

小说面板是“一战晟铭”平台内功能。它必须跟随平台的唯一主题状态，不保留独立主题选择、独立主题存储或系统主题判断。

## 已确认边界

- 平台主题唯一来源为主站 `localStorage['yizhan-theme']` 与根元素 `data-theme`。
- 主题值只允许 `dark` 和 `light`；缺失或非法值按 `dark` 处理。
- 小说面板保留现有 iframe、Bearer API 桥接、项目数据、人物、分镜、弹窗和生成流程。
- iframe 不接收 Token、账号、项目内容或 API Key；主题消息仅包含固定类型和主题值。
- 小说面板不新增主题按钮，不写入主题偏好。

## 架构

主站的 `UserLayout` 继续负责读取、持久化和切换主题。`NovelPanelPage` 从主站根元素读取已生效的主题，并在以下时机向 iframe `contentWindow` 发送消息：

1. iframe 每次 `load` 完成后。
2. 主站的主题状态变化后。

主题消息格式固定为：

```js
{ type: 'qiantie-theme-sync', theme: 'dark' | 'light' }
```

工作台 iframe 保持现有不含 `allow-same-origin` 的 sandbox，因此它是 opaque origin。父站向该主题消息使用 `'*'` 作为 `targetOrigin`，这是为使消息能投递给 opaque-origin 子文档的必要例外；消息只含固定类型和 `dark`/`light` 枚举值，绝不含 Token、账号、项目内容、API Key 或其他业务数据。

小说面板工作台只接受来自其父窗口的此类消息，校验消息类型与主题白名单后设置 `document.documentElement.dataset.theme`。页面首次加载时默认深色，等待父站同步；这样在消息尚未送达时不会产生浅色闪烁。

## 视觉令牌

工作台 CSS 使用与主站一致的语义层级，不复制页面结构：

- 背景：深色 `#0a0a14`，浅色 `#f4f6fa`。
- 表面：深色半透明面板，浅色白色面板。
- 文字：深色模式浅文字，浅色模式深文字。
- 边框、输入框、阴影与悬浮态均使用成组 CSS 变量。
- 强调色沿用平台珊瑚色，不因主题切换改为另一套品牌色。

工作台现有选择器继续引用这些变量或新增最小覆盖规则；不调整分镜、项目、人物、设置或对话框的 DOM 结构。

## 故障与回退

- 无效消息、非父窗口消息和非法主题值一律忽略。
- iframe 尚未加载时，主题状态不会被保存到 iframe；加载事件会补发当前主题。
- iframe 刷新、后退缓存恢复或重建后，父页面会在下一次加载时重新同步。
- 父站主题功能失效时，小说面板保持深色默认，不能自行写入另一个主题状态。

## 验收

1. 主站切换主题时，小说面板无需刷新即可同步。
2. 在浅色主题进入或刷新小说面板，加载后为浅色；深色同理。
3. 工作台无主题开关、无主题 `localStorage` 写入、无系统主题探测。
4. 主题消息不包含身份、鉴权或项目数据。
5. 静态契约测试覆盖消息发送、消息接收、浅深色变量和安全边界。
6. 既有小说面板测试、全量 Node 测试与前端构建继续通过。
