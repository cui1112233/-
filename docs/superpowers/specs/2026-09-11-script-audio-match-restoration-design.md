# 剧本生成音频匹配恢复设计

## 目标

恢复此前已实现的“匹配音频”功能，并将它放回剧本输入区第四个工具按钮。第三个按钮继续生成并播放原文配音。

## 行为

- 用户先点击“配音原文”生成当前小说配音。
- 点击第四个“匹配音频”按钮，在设置窗口开启或关闭匹配。
- 开启后，生成剧本前读取实际音频时长；没有有效时长时阻止本次匹配生成并提示先生成配音。
- 普通“生成剧本”请求携带 `matchAudio` 和 `audioTotalSeconds`，由服务端现有提示词链决定分镜总时长。
- 不改变视频模型、人物场景图片、数据库和视频生成流程。

## 兼容与错误处理

音频时长限制为大于 0 且不超过 600 秒，读取失败只影响音频匹配，不影响普通剧本生成。按钮保留场记板图标，但无障碍标签和提示改为“匹配音频”。

## 验证

新增契约测试验证第四个按钮、时长状态和请求参数；前端构建后检查公网资源包含恢复后的行为。
