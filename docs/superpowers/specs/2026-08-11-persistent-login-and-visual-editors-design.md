# 持久登录与可视化编辑器设计

## 目标

前贴提供不保存明文密码的 30 天保持登录；剧本输出、人物和场景均可在工作台中直接编辑。

## 登录

- 登录框增加“30 天保持登录”开关，默认开启。
- 服务端为该开关创建随机会话令牌，持久化令牌摘要和到期时间；浏览器只保存令牌，不保存密码。
- 退出登录撤销当前会话并清除浏览器令牌。

## 剧本工作台

- “复制”旁提供“编辑/完成”命令；完成后的内容仍可复制。
- 人物与场景放入同一个可调整左侧对象面板，拖动分隔线时两组卡片同步缩放。
- 点击卡片在右侧打开可视化字段编辑器；表单显示中文字段，未知数据归入“设定/描述”，不显示 JSON。
- 编辑器有全屏命令，关闭后把字段修改同步回当前工作区数据。

## 导航

- React 工作区移除侧栏主导航中的“设置”，把主题与设置放在侧栏左下工具区。
- 旧版页面同样把设置与主题放到左下工具区。

## 验证

- 单元测试覆盖会话到期、实体字段可视化和编辑状态切换。
- 前端构建、后端语法、认证接口及工作页资源响应通过。
