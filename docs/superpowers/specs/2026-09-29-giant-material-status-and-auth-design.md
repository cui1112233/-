# 巨量素材状态条与青语授权设计

## 目标

让巨量素材读取过程在独立测试页和批量工厂中都可观察、可解释，并为公网部署准备安全的青语素材查询边界：用户只输入巨量素材 ID，不需要打开开发者工具复制请求头。

本次范围只覆盖本地产品代码和接口设计，不发布公网，不把青语授权令牌写入前端或提交到仓库。

## 现状与约束

- 巨量素材测试页为 `/giant-material-test`，批量工厂通过书城选项“巨量获取”进入同一条提取链路。
- 当前提取链路包含青语素材解析、视频读取、滚屏 OCR、正文清理和登记；未来可能增加音频识别。
- 本地 OCR/音频处理优先走本机能力，不因状态展示额外调用大模型。
- 青语请求需要已授权的 `N8-Admin-Token`。令牌属于服务端凭据，不能由浏览器持久保存、硬编码或通过 F12 作为正常用户流程交给公网用户。
- 现有本地工作区有用户未提交改动；本功能只增加必要文件和代码，不重置或覆盖其他改动。

## 方案比较

### 方案 A：两个页面各自实现状态条

改动最少，但测试页和批量工厂会产生两套状态文字、颜色和错误处理，后续接入音频时容易漂移。放弃。

### 方案 B：共享状态卡组件（采用）

抽出一个无业务依赖的 `OCRStatusCard`（名称可按现有目录规范调整），由页面传入阶段、进度、统计和错误信息。测试页显示完整卡片，批量工厂使用紧凑模式。两个入口共享状态枚举、颜色语义和可访问文本，后续音频识别可以复用。

### 方案 C：只显示百分比进度条

实现简单，但不能解释“正在连接青语、下载视频、OCR 还是整理正文”，用户遇到等待或失败时无法判断原因。放弃。

## 用户界面设计

状态卡放在“滚屏 OCR”区域内，视觉沿用现有深色面板和截图中的横向状态条：

- 标题：`滚屏 OCR`。
- 副标题：当前阶段说明，例如“正在启动 Mac 本地 OCR，无需付费模型 API…”。
- 右上角状态徽标：`待执行`、`连接中`、`读取中`、`识别中`、`整理中`、`已完成`、`失败`、`已取消`。
- 横向进度条：无可计算总量时使用不确定进度；拿到视频时长后按已处理秒数/总秒数计算。
- 统计行：已处理秒数、帧数、识别字数；完成后保留最终值。
- 错误状态：显示可读的原因和下一步，例如“青语授权已失效，请管理员重新配置”，不展示令牌内容。

状态阶段映射：

```text
idle       待执行
resolving  连接青语 / 获取素材
reading    读取视频或音频
ocr        滚屏 OCR / 音频识别
cleaning   整理正文
success    已完成
error      失败
cancelled  已取消
```

批量工厂弹窗使用同一组件的紧凑模式，保留阶段、进度和一行错误；测试页显示完整统计和诊断信息。状态组件不负责发请求，只负责展示传入状态。

## 青语授权与数据流

### 本地单机

服务端从环境变量或本机密钥配置读取青语令牌。前端只发送素材 ID，服务端调用青语素材接口并返回规范化结果：平台书名、平台书 ID、素材类型、视频/音频地址和必要的元数据。令牌不进入浏览器响应、不写入日志。

### 公网多用户

增加服务端授权配置边界，优先采用管理员配置的服务端密钥；如果未来需要按账号隔离，则按账号保存加密凭据并在服务端解密使用。前端提供“已配置/未配置/已失效”的状态，不提供粘贴 F12 请求头的操作。公网发布前再根据青语服务条款确认凭据使用范围和缓存策略。

### 规范化接口

```text
POST /api/batch-factory/giant-material/resolve
请求：{ materialId }
成功：{ materialId, books: [{ platformId, platformName, bookId, bookName }], media: { type, url, duration } }
失败：{ code: QINGYU_AUTH_NOT_CONFIGURED | QINGYU_AUTH_FAILED | ... , message }
```

接口层负责鉴权、超时、重试上限和字段规范化；提取层只消费规范化结果。媒体 URL 只在服务端需要时短时传递，不把青语令牌或原始请求头下发给前端。

## 错误与恢复

- 未配置令牌：状态为 `失败`，提示管理员配置授权。
- 401/403：状态为 `失败`，提示授权失效；不自动无限重试。
- 素材不存在或缺少平台书名/ID：状态为 `失败`，提示检查素材 ID。
- 视频读取失败：保留青语查询成功结果，允许仅重试读取阶段。
- OCR/音频识别失败：保留素材和媒体信息，允许只重跑识别阶段。
- 用户取消：停止读取和 OCR，状态为 `已取消`，不登记半成品正文。

## 测试与验收

1. 组件状态测试：八种状态均有正确标题、说明、徽标和进度语义。
2. 进度测试：无总时长显示不确定进度；有总时长时进度限制在 0–100%。
3. 两入口测试：测试页和批量工厂使用相同阶段数据，紧凑模式不丢失失败原因。
4. 授权契约测试：未配置、401、成功响应、字段不完整四类响应均转换为稳定错误码或规范化结果。
5. 安全检查：前端 bundle、浏览器响应、日志和错误消息中不出现 `N8-Admin-Token` 的值。
6. 运行验收：本地输入合法素材 ID 后，能看到“连接青语 → 读取 → OCR/整理 → 完成”的连续状态；公网发布前单独验证服务端密钥配置和真实青语账号授权。

## 非目标

- 本次不把巨量功能发布到公网。
- 本次不绕过青语登录或提取他人未授权的凭据。
- 本次不把完整视频长期保存到本地；媒体缓存策略另行设计。
- 本次不强制引入付费大模型；OCR/音频识别的具体本地引擎保持现有能力边界。
