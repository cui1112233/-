# 批量工厂定时全自动生产与视频管理系统上传

## 目标

批量工厂的新建批量与小说获取定时任务使用相同的持久化定时语义：保存任务后，即使页面关闭或本地 Node 服务重启，仍在设定时间继续执行。任务按书独立执行、记录状态、可暂停、继续和只重试失败书。

## 开关与执行语义

新建批量提供两个独立开关：

1. **自动生产**：启用后，立即或在 `scheduledAt` 到时，依次执行缺失的资产、H3 导演、画面提示词、VIDEO 与合成。关闭时，定时标记只保存批次元数据，不创建自动化任务。
2. **自动上传视频管理系统**：只有自动生产已启用时可开启。启用后，每本书在合成成功且视频管理系统配置已验证时提交上传；关闭时自动化在 `ready_for_upload` 停止。

两个开关都开启时，定时任务走完整链路：`资产 -> H3 导演 -> VIDEO -> 合成 -> 视频管理系统上传`。

## 状态、幂等与错误处理

- 自动化任务持久化 `scheduledAt`、并发度、自动上传意图及每书阶段状态；服务重启时重新载入并恢复尚未终止的任务。
- 每书只执行缺失或失败阶段。已有有效资产、导演数据、VIDEO、合成成片和已确认上传回执不得重复创建或提交。
- 上传成功必须保存远端回执和实际视频附件证据；仅有本地“已提交”不能标记为上传成功。
- 任一书失败只使该书进入失败或待处理，不中断其他书。重试只从该书最后失败阶段继续。
- 上传前若配置未验证，任务标记为阻塞并说明原因；不发送请求。

## 前端交互

- “定时标记”改为“定时自动执行”，只有自动生产开启时显示并生效。
- 自动上传开关置于自动生产之后；关闭自动生产时自动上传不可启用并保留已选值，重新开启后恢复。
- 创建成功后显示“已定时／已启动”的真实状态；工作台“自动生产”和任务日志同时显示生产、合成、上传阶段及远端回执。

## 验收

1. 自动生产关闭时，保存定时信息不调用自动化启动接口。
2. 自动生产开启、自动上传关闭时，到时完成合成并停在待上传。
3. 两个开关开启时，到时完成合成并执行一次上传；同一书重试不重复上传已确认版本。
4. 服务重启后，未来的定时任务和运行中的任务恢复。
5. 配置未验证、上游失败和上传回执缺失均保持可见失败／阻塞状态，不能虚报成功。
