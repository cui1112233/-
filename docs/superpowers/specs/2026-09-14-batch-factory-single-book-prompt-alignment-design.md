# 批量工厂 V11 单书配置与剧本提示词对标设计

## 目标

批量工厂是水货生产的“小说前贴”版本，外层一行是一部小说。每部小说必须拥有可独立编辑、可实际执行的“人物场景预设、引擎配置、AI 推理”配置，并遵守 V11 的继承规则。

本次以剧本生成人物场景提取链路为权威对标：系统只使用个人中心已发布的真实预设版本，执行时由服务端读取预设正文并保存可追溯快照；浏览器不接收或拼接受保护的系统 Prompt 正文。

## 当前缺口

1. AI 推理的资产设置将所有批量工厂预设混在一个下拉框，人物、场景、视频、画面与约束没有按用途过滤。
2. 前端当前仅保存 `presetId/presetName/presetVersion`。V11 导演服务读取旧的 `prompt` 字段，未按 ID 解析真实正文，因此选择预设不会可靠影响执行。
3. 单书“人物场景预设”只保存草稿文本，未回写单书资产，也未参与后续分镜、图片或 VIDEO 输入。
4. 单书资产图片的生成、上传、替换、选择主图、手动添加与风格选择没有真实接口，当前功能被禁用。
5. 单书引擎配置与 AI 推理没有可回读的 override；不能满足 `作品 → 单书 → 分镜/VIDEO` 的继承规则。

## 方案选择

采用“直接复用剧本生成预设”的方案。

- 直接引用：批量工厂单书选择个人中心 `script` 模块中已发布、带 `extractionPreset` 标识的提取方案，例如 `script-extract`。这是唯一人物/场景提取来源，避免维护两套同义 Prompt。
- 独立复制：在 `batch-factory` 模块中复制剧本预设。该方案会造成版本漂移和无法判断实际执行正文，因此不采用。
- 任意批量预设：维持现有通用下拉。它无法保证人物、场景和媒体 Prompt 语义正确，因此不采用。

视频、画面和约束仍使用个人中心 `batch-factory` 模块中与其固定槽位匹配的预设。它们不替代人物场景提取方案。

## 预设类型与槽位

| 批量工厂动作 | 允许预设来源 | 选择规则 | 实际用途 |
| --- | --- | --- | --- |
| 人物/场景提取 | `script` 已发布 `kind=base` 且 `extractionPreset=true` | 单书可选择一个提取方案；未选时继承作品默认 | 从该书 `workingFrontContent` 或保存正文中提取人物与场景 |
| 人物资产补充 | `batch-factory` 人物资产槽位 | 只能选择人物槽位 | 生成或完善人物资产 Prompt |
| 场景资产补充 | `batch-factory` 场景资产槽位 | 只能选择场景槽位 | 生成或完善场景资产 Prompt |
| 道具资产补充 | `batch-factory` 道具资产槽位 | 只能选择道具槽位 | 生成或完善道具资产 Prompt |
| 约束设置 | 复用剧本生成约束 UI 和已发布约束预设 | 只选择对应约束类别 | 参与导演、分镜和最终 Prompt 编译 |
| 视频提示词 | `batch-factory` 视频槽位 | 只能选择视频槽位 | 只作用于 `video_desc`、动作、运镜 |
| 画面提示词 | `batch-factory` 画面槽位 | 只能选择画面槽位 | 只生成画面图片，绝不进入视频 Prompt |

管理后台必须为批量工厂补齐并校验人物、场景、道具、视频、画面等固定槽位。所有接口按槽位筛选，并在服务端再次校验模块、发布状态、类型和槽位，不能相信浏览器提交的 ID。

## 配置层级

```text
作品统一配置
  ├─ 人物场景提取方案
  ├─ 资产 / 约束 / 视频 / 画面规则
  └─ 引擎配置
       ↓
单书 override（仅保存用户改动字段）
  ├─ 单书提取方案与资产规则
  ├─ 单书人物 / 场景 / 道具实际资产
  └─ 单书引擎配置
       ↓
分镜 / VIDEO override
  └─ 视频模型、时长、画幅与该 VIDEO 的提示词
```

单书未改动的字段必须继续继承作品配置。单书的改动不改变作品默认值，也不影响其他小说。

## 单书人物场景预设工作区

点击外层小说行的“人物场景预设”后打开居中弹窗，沿用水货生产的“左 Prompt、右图片库”结构：

1. 顶部选择文本模型、人物场景提取方案、图片模型、画幅和风格。模型仅显示账号已授权且可用的模型。
2. “智能预设”对当前书执行真实人物与场景提取，输出并保存该书的角色、场景和道具资产。
3. 左侧按人物、场景、道具显示实际资产 Prompt；编辑并保存后必须回读到该书资产。
4. 右侧按角色库、场景库、道具库显示真实图片；支持生成、上传、替换和设为主图。没有可用接口时应显示真实不可用原因，不得显示可点击的假成功入口。
5. 每个资产都保留 ID、名称、类型、Prompt、图片版本、主图、创建来源、所用预设 ID/版本与更新时间。

## 执行与快照

1. 单书 AI 推理开始时，解析有效配置：作品默认与单书 override 合并。
2. 服务端按有效的预设 ID 读取已发布的真实正文，检查其模块和槽位正确。
3. 执行请求保存预设 ID、版本、正文摘要/哈希与最终组合规则快照；预设后续发布新版本不改变已提交任务。
4. 人物/场景提取使用剧本生成的提取预设协议，保存结构化人物和场景；资产补充 Prompt 只作用于自身资产类型。
5. VIDEO 最终编译继续遵守 V11：有图优先传图；无图或因模型上限被挤出的资产才按规则补人物/场景/道具文字；画面提示词只进画面图生成，绝不进视频 Prompt。

## 接口与持久化

新增或补齐以下契约：

- 获取可选预设目录时支持按模块、发布状态、提取标识与槽位过滤。
- 保存作品或单书配置时保存选择元数据，并由服务端校验。
- 单书运行 AI 时，由服务端解析预设正文并创建冻结快照。
- 单书资产 CRUD、图片版本、主图和图片任务均以 `batchId + bookId + assetId` 归属并做账号隔离。
- 单书 override 只保存差异字段；读取时返回有效配置和显式 override，供界面区分“继承中”和“已覆盖”。

## 错误处理

- 预设不存在、未发布、模块不符或槽位不符：拒绝保存或执行，返回具体缺失项。
- 文本或图片模型未授权/不可用：禁止对应动作，说明去个人中心模型配置启用的位置。
- 资产图片生成、上传或替换失败：保留旧主图和历史版本，记录失败原因；不得将任务已提交写成生成成功。
- 单书配置冲突：使用 revision 检查，提示刷新后重试，不能静默覆盖其他编辑。

## 验证

- 前端测试：每类选择器只能收到合法槽位；单书 override 与继承展示正确；画面提示词不进入 VIDEO 请求。
- 后端测试：错误模块/槽位 ID 被拒绝；剧本提取预设正文被真实解析；预设更新后旧任务仍使用快照；账号无法读写其他账号的单书资产。
- 集成验证：创建一部小说，选择剧本提取方案，执行提取，编辑人物/场景 Prompt，生成并替换资产图，保存并重新进入后回读；生成 VIDEO 时检查真实请求的资产图片与文字回退规则。

## 范围

本设计先补齐 V11 第 5、6.2、7、11、12、13、14 节涉及的单书配置与 Prompt 执行闭环。121 发布、合并和定时生产沿用已有设计，不在本次重新定义。
