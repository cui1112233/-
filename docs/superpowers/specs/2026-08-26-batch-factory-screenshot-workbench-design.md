# 批量工厂截图式工作台设计

## 目标

将进入批次后的批量工厂工作台调整为用户截图所示的紧凑深色/浅色兼容布局。创建批次和待制作小说页面保持现有流程与接口不变。

## 结构

1. 页面标题栏：显示“批量工厂”、统一设置说明和“新建批次”。
2. 批次操作栏：显示批次名称、小说数量、编辑入口；左侧提供“生产统一设置”和“发布统一设置”两个切换按钮；中部显示生产/发布摘要；右侧提供高级设置、开始导演、生成待生成、合并待合并、上传待上传等动作。
3. 批次状态中心：保留状态筛选计数，并增加当前筛选结果的异常小说摘要列表。
4. 三栏工作区：
   - 左栏：搜索、状态筛选、小说列表、分页/总数。
   - 中栏：当前小说标题与状态、失败提示卡、原文/爆款开头/人物场景道具/VIDEO/合并/发布/操作记录折叠区。
   - 右栏：VIDEO 状态环形统计、活动任务提示、批量合并设置和主操作按钮。

## 视觉规则

- 所有颜色使用主题变量或 Ant Design token，不写死只适用于深色主题的文字颜色。
- 面板、边框、输入框、折叠项、按钮保持截图中的紧凑间距和 6-8px 圆角。
- 状态色语义固定：待生成使用橙色、排队/处理中使用蓝色、已完成使用绿色、异常/失败使用红色、待审核使用紫色或金色。
- 主题切换后，文字与边框必须满足可读对比度；浅色主题使用浅色面板和深色文字，深色主题使用深色面板和浅色文字。

## 交互与数据映射

- 现有导演、Prompt 编译、视频提交、刷新、重试、标记问题、合并接口和 handler 全部复用。
- 截图中的“发布统一设置”和“上传待上传”若暂无后端能力，显示为禁用并给出明确状态，不伪造完成结果。
- 状态中心筛选同步左侧小说列表；点击异常摘要直接选中对应小说。
- 右侧进度统计由当前批次所有 storyboard 和 production 状态实时计算。
- “新建批次”返回现有创建页，不改变当前批次数据。

## 响应式与验证

- 桌面宽度按截图保持三栏；中等宽度将右栏置于底部；移动端按左栏、中栏、右栏纵向排列。
- 增加 UI 契约测试，验证标题栏、操作栏、状态中心、异常摘要、三栏区域、VIDEO 统计和批量合并区域存在。
- 运行前端构建和现有批量工厂相关测试，并在深色/浅色主题下检查无文字溢出或遮挡。
