# 剧本生成：图片与视频画幅语义分离

## 目标

剧本生成的统一配置中，图片画幅只服务人物、场景和道具等参考图生成；视频画幅和视频分辨率只服务分镜视频任务。图片使用 `1:1` 时，任何视频任务不得变成方形。

## 配置语义

- 图片画幅：`16:9`、`9:16`、`1:1`。仅传递给参考图生成。
- 视频画幅：`16:9`、`9:16`。仅传递给视频提交。
- 视频分辨率：`480p`、`720p`、`1080p`。仅传递给视频提交，模型能力不足时由模型适配层明确降档。

已有的 `scriptDefaults` 保持三个独立字段：`imageAspectRatio`、`videoAspectRatio`、`videoResolution`。不从图片画幅推导视频画幅。

## 视频模型适配

| 模型通道 | 画幅 | 分辨率 |
| --- | --- | --- |
| Seedance 2.0 官方 | 直接传 `16:9` / `9:16` | 直接传 `480p` / `720p` / `1080p` |
| YD2.0 Mini | 直接传 `16:9` / `9:16` | 直接传 `480p` / `720p` / `1080p` |
| 本地执行器 | 直接传 `16:9` / `9:16` | 直接传 `480p` / `720p` / `1080p` |
| MiniMax H3 | `16:9` 映射横向工作流，`9:16` 映射竖向工作流 | `480p` 映射 480 档；`720p` 和 `1080p` 映射 H3 支持的 768 档 |

H3 的映射必须在提交前显式计算，不能继续固定为 `480p竖`。界面在选择 H3 且用户选 720p 或 1080p 时说明“该模型按 768p 档提交”。

## 提交流程

1. 参考图生成读取 `imageAspectRatio`。
2. 分镜视频生成读取 `videoAspectRatio` 与 `videoResolution`。
3. 前端将视频配置原样发送至 `/api/script-video`。
4. 服务端按模型键做最小映射；只对 H3 替换为受支持的横/竖分辨率字符串。
5. 历史任务与已有图片不被修改。

## 验证

- 单元测试：图片 `1:1`、视频 `16:9`、`1080p` 时，Seedance 请求仍为 `16:9` / `1080p`。
- 单元测试：H3 的 `9:16 + 480p` 映射 `480p竖`，`16:9 + 1080p` 映射 `768p横`。
- 前端源测试：H3 不再硬编码 `480p竖`，并显示其能力映射说明。
- 目标 Node 测试、前端构建、精确 `v88` SHA 公网验证通过后才发布。
