# 批量工厂单书分镜提示词叠卡设计

## 目标

批量工厂工作台外层保持“一行一本小说”。每本书的提示词列是其分镜卡查看器，沿用剧本生成的分镜 / VIDEO 语义，但以左右切换代替剧本生成的纵向卡片列表。

## 卡片范围与状态

- 左右箭头只切换当前小说的分镜。
- 当前分镜保持 `分镜 : VIDEO = 1 : 1` 数据关系，但界面不显示 `分镜01 → VIDEO01`、分镜编号或映射说明。
- 每个分镜独立读取视频提示词、画面提示词、候选版本和生成状态。
- 打开提示词卡时，默认进入视频提示词模式。
- 查看模式属于当前小说而不是单个分镜：用户切换为画面提示词后，左右切换始终展示分镜 1 / 2 / N 各自的画面提示词；用户切回视频提示词后，左右切换始终展示对应分镜的视频提示词。

## 右上角叠卡切换

右上角恒定渲染两张叠压的小卡：

- 视频提示词卡为淡蓝色，默认位于前景。
- 画面提示词卡为淡绿色，位于后景并露出可点击边缘。
- 当前分镜已有画面提示词时，点击任一卡会交换前后层级，并将当前小说的查看模式切换到对应提示词；随后左右切换读取同一模式下的其它分镜提示词。
- 当前分镜没有画面提示词时，仍渲染两张叠卡以保持版式一致；视频提示词卡固定在前景，绿色卡不可切换且不得展示空画面提示词内容。
- 当处于视频提示词模式但当前分镜尚未生成视频提示词时，正文显示“请生成视频提示词再查看”；视频提示词生成后才显示正文并允许视频相关操作。

## 内容与按需操作

默认提示词卡只展示当前前景类型的正文，不显示编辑或生产动作。

用户点击打开对应前景卡后，才显示该类型的操作区：

| 前景卡 | 操作 |
| --- | --- |
| 视频提示词（淡蓝） | 保存、重生文案图标、编辑、生成视频、查看视频候选版本 |
| 画面提示词（淡绿） | 保存、重生画面提示词图标、编辑、生成图片、查看画面候选版本 |

- 视频候选与画面候选必须按当前书、当前分镜、当前媒介分别读取，禁止打开其它分镜或另一种媒介的版本库。
- 两种“重生”均使用对应媒介的图标按钮；视频重生只走文案 / 视频提示词阶段，不修改画面提示词；画面重生只走画面提示词阶段，不改写视频提示词。
- 每个生成动作继续受当前书实际生效的模型与运行能力闸门控制；能力不可用时展示真实原因，不伪造成功。

## 视觉规则

- 叠卡使用圆角、小阴影与前后错位，模仿用户提供的叠压卡片感。
- 视频卡淡蓝，画面卡淡绿；不可切换的绿色卡保持弱化，但仍可辨认。
- 正文编辑区具有卡片内边距、清晰的标题层和足够的阅读高度。
- 操作区在展开后固定在正文下方，保存动作靠左，其余动作按媒介分组，避免与分镜导航混排。

## 验收

1. 打开卡片与左右切换时默认均处于视频提示词模式。
2. 切换到画面提示词模式后，左右切换始终展示分镜 1 / 2 / N 各自的画面提示词，直到用户切回视频模式。
3. 有画面提示词的分镜可在蓝 / 绿叠卡间切换；没有画面提示词的分镜仍显示两张叠卡，但绿色卡不可打开。
4. 视频提示词不存在时显示“请生成视频提示词再查看”，不展示空编辑器或伪造视频操作。
5. 左右切换后，操作仅作用于切换后的当前分镜及其对应媒介；两种重生均为图标按钮。
6. 画面与视频提示词、候选版本、生成任务互不串写。
7. 批量工厂保留一行一本小说和现有真实保存 / 模型能力检查逻辑。
