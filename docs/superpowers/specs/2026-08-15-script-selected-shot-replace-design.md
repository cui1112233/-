# 已选分镜卡片文字替换设计

## 目标

在剧本生成页的分镜卡片视图中，为用户已勾选的分镜卡片提供文字查找与替换能力。替换范围严格限定为已选卡片，不影响小说原文、人物、场景、生成约束或未选卡片。

## 交互

- 工具栏增加“查找替换”按钮。
- 未选中任何分镜卡片时，按钮禁用。
- 点击按钮后打开替换面板，并保持分镜卡片视图。
- 面板包含“查找内容”和“替换为”两个输入框，以及匹配状态，例如“2 / 8”。
- “上一个”“下一个”仅遍历已选卡片中的匹配项。
- “替换当前”仅替换当前定位匹配项。
- “全部替换”替换已选卡片中的全部匹配项。
- 查找内容为空或无匹配时，替换操作不可用并显示相应提示。

## 数据与更新流程

- 查找范围来自 `selectedShotIndexes`，内容源为 `getShotCards(selectedFormat, output)` 解析出的分镜卡片。
- 替换操作以卡片在原始 `output` 中的文本范围为准，仅修改选中卡片对应片段。
- 修改完成后通过 `updateOutputDraft(nextOutput)` 写入完整剧本文本，继续使用现有草稿保存逻辑。
- 替换只做本地字符串处理，不调用 AI 或后端接口。
- 替换后重新计算卡片内容，并保留原先已选卡片的索引；若文本结构变化导致卡片数量减少，则忽略越界索引。

## 边界

- 仅支持普通文本匹配，不支持正则表达式或大小写选项。
- 替换结果按已选卡片在原文中的位置执行，避免对未选卡片产生影响。
- 若当前输出不是可用的分镜卡片视图，则功能不可用。

## 验证

- 扩展剧本分镜输出 UI 契约测试，覆盖工具栏入口、已选范围和持久化更新路径。
- 添加纯函数测试，验证单卡片、多卡片、替换当前、全部替换、无匹配和空选择不会越界修改。
