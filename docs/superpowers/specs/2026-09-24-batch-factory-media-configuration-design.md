# 批量工厂图片与视频独立配置设计

## 目标

批量工厂在“统一配置 / 引擎配置”中分别保存图片画幅、视频画幅和视频分辨率。图片为参考资产，其画幅不得改变视频输出画幅。

## 配置字段

- `imageAspectRatio`：`16:9`、`9:16`、`1:1`；仅传递给人物、场景和道具的图片生成。
- `videoAspectRatio`：`16:9`、`9:16`；仅传递给分镜视频生成、视频预览和合成布局。
- `videoResolution`：`480p`、`720p`、`1080p`；仅传递给视频模型提交。

原有 `aspectRatio` 保留为历史兼容字段，不能再作为新视频任务的唯一画幅来源。

## 兼容规则

历史批次与书级覆盖不改写。未显式保存新字段时：图片画幅从旧 `aspectRatio` 读取；视频画幅从旧值读取，但旧值为 `1:1` 时使用 `9:16`，以避免生成方形视频；视频分辨率使用 `720p`。

新建或保存后的统一配置写入新字段。视频链路只读取 `videoAspectRatio` 与 `videoResolution`，不会因 1:1 参考图而改变输出比例。

## 界面与范围

在批量工厂已有的统一配置与批次/书级引擎配置中，将当前“画幅”拆为“图片画幅”和“视频画幅”，并新增“视频分辨率”。模型选择、预设、已有作品、批次、视频、自动化和发布配置均不重构。

## 验证

覆盖配置标准化、历史值回退、图片任务参数和视频任务参数的测试；构建前端；发布后确认精确 `v88` SHA、批量工厂页面可达，并以已认证账号检查统一配置字段可保存和回读。

## 后续一致性修复

完成批量工厂后，单独回查剧本生成：图片 1:1 仅作为资产参考画幅，视频选择只能为 `16:9` 或 `9:16`，且实际提交参数与配置一致。
