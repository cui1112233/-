# Q版模式设计

## 目标

在剧本生成的输出格式下新增与“分镜模式、剧本模式、剧情模式、画布模式”同级的“Q版模式”。用户选择该模式后，系统加载专用 Q 版画面转译提示词，并沿用现有的 10s/15s 时长拆分和镜头输出链路。

## 归属模型

- 模块：`script`
- 类型：`base`
- 输出格式：`q版`
- 系统预设 ID：`script-format-q版`
- 显示名称：`Q版模式`
- 提示词源文件：`prompts/Q版模式.md`
- protocol lock：`{ format: 'q版' }`

所有系统提示词继续通过 `lib/system-preset-catalog.js` 注册，前端不直接读取未注册的提示词文件。Q 版提示词作为正式输出格式归属在剧本生成模块，不作为约束附加项或画面工作台独立开关。

## 提示词行为

Q 版模式提示词包含用户提供的完整规则，要求模型：

1. 识别心理活动、内心 OS、吐槽、弹幕、脑补等非现实内容。
2. 在正常比例现实主体旁生成约三分之一身高、3-4 头身的 Q 版迷你主角。
3. 用迷你小人的动作、表情、道具和可选符号表达心理内容，禁止只堆砌文字。
4. 保留原文场景、环境、光影和氛围；心理层以光晕、虚影或魔法/霓虹等方式与现实层区分。
5. 根据国风古风、现代都市、西幻/玄幻语境选择对应 Q 版变体。
6. 输出采用“画面主体描述 + 迷你小人细节 + 环境光影”的结构，并按镜头一、镜头二顺序使用 `---` 分隔。
7. 严格执行 10s/15s 模式、空间切换强制拆分、时长上限、完整四段式镜头结构和总时长校验。
8. 只保留原文可确认的对白归属，不虚构对白。

系统会继续替换现有的 `{10s或15s}` 等时长占位符，使 Q 版模式与已有格式保持一致。

## 代码改动范围

- `prompts/Q版模式.md`：新增 Q 版模式完整提示词。
- `lib/system-preset-catalog.js`：注册 Q 版模式及其归属元数据。
- `routes/chat.js`：增加 `q版` 格式到预设映射、名称映射和格式规范化白名单。
- 剧本生成前端格式选择组件：新增“Q版模式”选项，并同步名称映射、默认值回退、历史记录展示和保存恢复字段。
- 系统预设目录与格式契约测试：增加 Q 版模式注册、可加载、可选择和时长占位符替换校验。

## 兼容性

- 不改变四种现有输出格式的 ID、显示名称、提示词和生成行为。
- 不改变约束设置附加项的归属规则。
- 未选择 Q 版模式时不会注入 Q 版规则。
- 历史记录读取旧格式时仍按原有回退逻辑处理。

## 验证标准

- 系统预设列表能返回 `script-format-q版`，且 `module`、`kind`、`protocolLock` 和源文件归属正确。
- 剧本生成页面下拉框显示“Q版模式”。
- 选择 Q 版模式并使用 10s 或 15s 时，请求使用 Q 版提示词且占位符被替换。
- 输出规则包含 Q 版心理层、三类画风变体、四段式镜头结构和拆分校验要求。
- 现有剧本格式相关测试继续通过。
