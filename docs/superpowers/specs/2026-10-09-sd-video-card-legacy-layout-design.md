# SD 视频提示词卡片兼容布局

## 背景

旧批次冻结了 SD 模板正文，卡片以“基础设定 → 画面质量提示词 → 视频提示词”展示。新批次在未冻结正文时解析到更新后的 SD 模板，并把智能统一作为独立“画面前缀”注入，造成同一 SD 通道的卡片布局变化。

## 决策

只为 `batch-video-sd` 的直出分镜恢复旧布局：

1. 基础设定优先，重复资产只出现一次。
2. 视觉前缀与画质约束合并为“画面质量提示词”。
3. SD 正文保持“视频提示词”，随后才是画面限制和负面提示词。
4. H3 编译、Trace、冻结编译记录和已提交的视频都不迁移、不重写。

## 验收

- SD 编译结果不再出现顶层“画面前缀”。
- 组件顺序与旧卡片一致，且提交给视频服务的文本与卡片一致。
- H3 现有编译顺序不变。
- 同名资产不会在基础设定中重复。
