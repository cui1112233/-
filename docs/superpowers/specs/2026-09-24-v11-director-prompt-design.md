# V11导演提示词设计

## 目标

在批量工厂“视频提示词”下拉中新增独立系统预设 `V11导演提示词`。它复用 H3 的逐行导演卡、真实配音时长、Canonical Timeline 和最终 VIDEO 编译链，仅将最终 VIDEO 文案改为中文可读格式。

## 预设边界

- 原 `H3 导演分镜视频提示词` 保持原名称、正文和选择行为不变。
- 新预设 ID 为 `batch-video-v11-director`，协议键为 `v11-director-normal`，仍归属 `batch.video-meta` 且格式为 `h3-structured-v1`。
- 新预设的导演规则继续要求输出相同的 H3 JSON 数据结构；仅最终 VIDEO Prompt 的渲染文字不同。

## V11 中文最终 Prompt

- `Total duration: 2.158 seconds.` 显示为 `总时长：2 秒`。
- 时间范围显示整数秒：起点向下取整、终点向上取整，例如 `00:03.740-00:05.682` 显示为 `00:03–00:06`。
- 人物 slot 在最终文案中解析为 `@角色名`，例如 `C002(我)` 显示为 `@我`；无名称或无法解析的 slot 保持原 slot ID，避免丢失引用。
- 音轨标题和字段使用中文：`音频`、`声音设计`、`模式`、`发声角色`、`对白`、`旁白`、`音效`、`环境声`。
- 不在新预设输出“按结构化时间线输出当前 VIDEO，保持人物、动作、机位和场景连续性。”；Node 调用 H3 编译时也不再向该预设传入这句兜底约束。

## 不变项

- `H3Audio` JSON 的内部字段、时间线毫秒、任务请求时长和合成精度保持不变。
- 智能统一、基础设定、画质约束和画面限制仍由已有开关决定是否注入。
- 已冻结的旧预设版本和已有 Director revision 不修改；只有新选择 `V11导演提示词` 后生成/编译的结果采用中文文案。

## 验收

1. 系统预设目录同时出现原 H3 预设和新的 `V11导演提示词`。
2. 选中后仍通过 H3 compile 接口生成任务。
3. 新预设的编译 Prompt 含中文时长、整数时间、`@角色` 和中文音频字段。
4. 原 H3 预设仍输出其原有英文标题格式。
