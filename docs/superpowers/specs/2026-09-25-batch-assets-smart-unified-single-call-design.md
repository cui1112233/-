# 批量工厂：资产与智能统一单次调用

## 目标

每本书进行“提取资产”时只调用一次文本模型。一次响应同时提供人物、场景、道具资产以及智能统一视觉基线；不再在资产提取后发起第二次智能统一模型请求。

## 输入与输出

资产阶段向当前选定文本模型发送处理正文、现有资产提取规则和智能统一规则。模型必须返回同一个 JSON 对象，包含：

- `assets`：现有资产提取契约中的人物、场景、道具数据；
- `smart_unified_analysis`：符合现有视觉基线字段契约的结构化结果。

资产保存路径保持不变。视觉基线保存到该书的导演/智能统一运行数据，并触发既有最终 VIDEO 提示词重编译。

## 容错与兼容

- 当智能统一未开启时，单次调用仍只返回和保存资产。
- 当智能统一开启但响应缺少或无法解析视觉基线时，资产照常保存；记录“未获取”原因，且不阻塞资产、导演、视频或合成。
- 保留“刷新智能统一”作为显式单独操作；它只在用户主动点击时发起一次独立刷新，不影响正常资产流程。
- 不修改已有导演卡、手工最终提示词、资产图片或视频记录。

## 验收

1. 开启智能统一后，执行一次资产提取仅产生一次文本模型请求。
2. 单次响应中的资产和视觉基线均保存，最终 VIDEO 提示词使用该视觉基线。
3. 视觉基线字段无效时，资产仍成功，流程继续且状态可见。
4. 关闭智能统一时不注入或保存新的视觉基线。
