# 批量工厂真实生产工作台设计规格

## 已确认目标

`/batch-factory` 是水货生产旁边的一级工作入口，用于把一批小说从导入、导演、视频生成、单书/批量合并统一放在一个真实工作台里。页面必须使用服务端批次数据，不能以示例书籍、示例状态或浏览器临时数据冒充任务结果。

## 本期可交付范围

1. 导航：在“水货生产”后增加“批量工厂”；水货生产内原有入口继续保留。
2. 工作区：标题、批次配置栏、状态中心、左侧小说清单、中间当前小说详情与 VIDEO 操作、右侧全批次进度和批量合并，按截图保持深色三栏工作台。
3. 真实生产闭环：调用现有批次、导演、钩子审核、最终 Prompt 编译、视频生成、重试和合并 API；失败必须显示失败原因与重试入口。
4. 真实状态：所有计数按书籍统计；右侧视频数量按 VIDEO 统计；刷新后保持当前状态定位与选中小说。
5. 发布边界：121/第三方发布接口未被验证接通前，页面只能展示“待接通发布后台”，不得写“上传成功”或“已发布”。

## 布局与交互

- 顶栏从左到右显示批次名、书数、生产摘要、生产统一设置、高级设置、启动导演、生成待生成 VIDEO、合并待合并。摘要在正常桌面宽度横向显示，不允许挤成纵向文字柱。
- 状态中心显示全部、待开始、待审核、AI 处理中、待生成、排队中、视频生成中、异常、待合并、已合并。单击定位首本，再击同状态轮换下一本，不能过滤掉其它书。
- 三栏主体：左侧为小说清单；中间为原文、爆款钩子、人物/场景/道具、VIDEO 卡片、最终 Prompt、单书操作记录；右侧为全批次视频进度环、单书成片入口、批量合并。VIDEO 操作不单独占第四栏。
- 布局宽度可持久化，但只保存当前用户浏览器偏好；在窄屏按“清单 → 当前小说 → 汇总”纵向收起，所有按钮仍可用。
- 色彩语义：紫色=选中/主操作，红色=异常，橙色=待执行，蓝色=队列/处理中，绿色=完成/已合并，灰色=未开始或尚未接通。

## 数据与安全边界

- 新增、更新的批次、书籍、配置快照、审核、操作记录应迁移至 MySQL；本期不得扩大 JSON 文件状态。
- 每个 API 必须按当前登录用户与团队权限隔离。
- 模型的 `maxVideoDuration` 是每张 VIDEO 的硬性上限；视频生成前后均不得产生超限单卡。
- 失败、上传或异步生产状态必须保存可诊断的阶段、原因、远端任务标识和重试条件；第三方外层 HTTP 成功不是业务成功。

## 后续独立子项目

“小说获取导入解析/个人生产模板/121 发布与远端回执”涉及独立持久化和外部服务契约。它们在本工作台中保留入口和真实不可用提示，待确认 121 的创建任务、轮询和素材参数接口后另行接通；不能用前端假状态代替。

## 本次验证记录

已验证批量工厂的页面契约测试、前端生产构建、Docker Compose 配置、现有 Go 后端健康检查和 Docker 平台的 `/batch-factory` 页面可达性。该验证仅表示页面与既有 API 的构建/连通性正常；不代表付费视频供应商已生成成品，也不代表 121 已创建或完成发布任务。
