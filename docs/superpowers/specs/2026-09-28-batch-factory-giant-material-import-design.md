# 巨量素材滚屏小说导入批量工厂 Design

## 已确认目标

在运行中的 `/shuihuo-production` 批量工厂中，以**巨量素材 ID**作为唯一导入键，将青语文已授权素材中的滚屏小说登记为现有小说列表的一本书；不建立新的书城页面或第二套小说表。

成功登记的书保留：

- 平台 Book ID（不是青语文内部素材 ID）；
- 平台书名和书城；
- OCR + 滚屏去重后的完整正文；
- `sourceMetadata.sourceMode = giant_material`，以及 `巨量素材 · <ID>` 的可展示来源；
- 仅用于追溯的巨量素材 ID、青语文素材 ID、视频 URL、处理时间和提取状态。

同一巨量素材 ID 再次提交必须返回已存在的书或可重试失败阶段，绝不新增重复书。MP4、帧图和 OCR 中间结果不持久化。

## 第一阶段：独立测试页

先在本地增加 `/giant-material-test` 测试页，用来证明完整读取链路，暂时不写入批量工厂正式小说数据。

测试页只有一个巨量素材 ID 输入框和“开始读取”按钮，依次展示：

1. 素材解析：青语文素材 ID、视频地址、平台书名、平台 Book ID、书城；
2. 视频读取：视频是否可访问、尺寸、时长；
3. 滚屏 OCR：当前进度、已确认字数、失败原因；
4. 提取结果：可复制的完整小说正文。

测试页不得提供“保存到批量工厂”或隐式登记行为。验证样本 `7689285397448523826` 的真实解析和 OCR 成功后，第二阶段才复用同一后端能力，在 `/shuihuo-production` 增加“巨量素材导入”和显式“保存到当前批量”操作。

测试页可独立于当前应用登录页打开，但只允许本机回环地址访问；对应测试 API 同样拒绝非回环来源，并且不返回、记录或持久化青语文授权令牌。

## 已验证样本

在已授权的青语文页面内，巨量素材 ID `7689285397448523826` 已解析到内部素材 `10122315`、作品 `事不过三，过三遭殃（七猫）` 和可读取的 720x1280、281 秒 MP4。该视频首帧为滚屏小说内容。该事实只说明“授权会话内解析和视频读取”可行，不替代服务端授权与全文 OCR 验收。

2026-09-28 本机服务端实测补充：接口使用 `N8-Admin-Token` 请求头、`ocean_material_ids: ["<ID>"]` 数组参数，成功返回 `code: SUCCESS` 与 `data.list`。视频地址来自素材 `path`，平台书籍来自 `works[].cp_work_id/name/cp_type`，`QM` 对应七猫。该样本关联 Book ID `748725` 和 `1240820` 两条记录；巨量素材 ID 唯一不代表平台书籍关联唯一。测试页必须展示所有关联记录，正式登记前必须确认其中一条，不得默认选第一条。

## 方案选择

采用“独立读取任务 + 后续复用 V12 intake”而非把 OCR 写进浏览器：

1. 第一阶段测试页提交巨量素材 ID 到本机回环专用测试路由；第二阶段由受认证的 V12 路由调用相同服务；
2. 服务端用显式配置的、仅本机进程可读的青语文授权令牌查询素材；不读取、不导出浏览器 Cookie；
3. 本地提取 runner 流式读取 MP4，抽帧、裁出文本区、调用本地中文 OCR，并按相邻帧重叠去重拼接；
4. runner 从青语文返回的元数据取平台 Book ID、书名、书城；缺一项即失败，不能把内部素材 ID 伪装成 Book ID；
5. 第一阶段只将结果返回测试页，不持久化正式书数据；
6. 第二阶段才把成功结果转成 V12 `novel-fetch` intake，追加到当前批量，并在详情展示来源 `巨量素材 · <ID>`。

## 安全、存储和失败边界

- 青语文令牌只从启动进程环境变量或系统密钥链读取，日志、数据库、浏览器响应和 Git 均不得出现令牌。
- 仅保存正文和小型 JSON 元数据；不保存原始视频、帧、OCR 模型缓存引用或浏览器 Cookie。
- 每个阶段记录 `resolve_material`、`extract_scroll_text`、`register_book`。失败保留错误和阶段，重试只重跑失败阶段；登记已完成时不得再次 OCR。
- 授权缺失、素材无书名/Book ID、视频不可读、OCR 无有效正文、滚屏重叠无法收敛，均为可见失败，不能创建“成功但正文为空”的书。

## 交付验收

1. `/giant-material-test` 可输入巨量素材 ID，并分阶段显示解析、视频读取、OCR 和正文结果；
2. 用授权测试夹具验证解析、滚屏去重和 metadata 映射；
3. 对真实样本（授权令牌存在时）验证页面显示平台书名、Book ID、书城和非空正文；
4. 第一阶段运行后，正式批量和小说记录数量不发生变化；
5. 验证运行目录和持久化记录没有 MP4 字节、帧图、Cookie 或令牌；
6. 第二阶段接入后，才验收登记、`巨量素材 · ID` 来源、幂等和失败阶段重试。
