# 剧本生成：分段开头、分镜模式与约束设置

## 目标

在现有“连续开头”和“爆款开头”之外新增“分段开头”，并将小说面板中人物/场景提取与分段分镜的核心规则以提示词形式接入剧本生成。

目标是保持现有剧本生成的两次 AI 请求模型：

1. 提取人物与场景：一次请求；
2. 生成剧本或分镜：一次请求。

不接入小说面板的 CharacterCore、多阶段分析、补镜、质量闸门或多轮生成流程。

## 用户流程

1. 用户上传或粘贴小说原文。
2. 用户点击原输入区右侧加号按钮；该按钮更名为“切换指令”。
3. 在指令选择面板中选择人物与场景提取方案：
   - 剧本标准提取：沿用现有剧本人物场景提取规则；
   - 小说面板提取：使用小说面板证据驱动的人物、场景、时代与关系分析规则。
4. 用户点击“提取”，得到当前页面可编辑的人物和场景。
5. 用户选择开头策略：连续开头、爆款开头或分段开头。
6. 用户选择输出模式：画布模式、剧本模式、剧情模式或分镜模式。
7. 用户通过现有 10s / 15s 按钮确定时长。分段开头中，该值决定每个自动分段单元的总时长。
8. 若当前输出模式不是剧本模式，用户可以打开约束设置并启用零个或多个约束类别。
9. 用户点击生成。系统将人物、场景、策略、格式、时长和已启用约束发往现有剧本生成接口。

## 外部 V77 提示词迁移来源

分段开头、小说面板提取、分镜模式与约束设置的规则来源，以以下外部工具为准：

`F:\脚本测试\chengming\视频画面提示词工具_CharacterCore2当前风格保留与人物卡非阻拦版_v77_Hotfix26_20260812`

迁移时提取该工具的全部业务提示词层，而非仅依据人工概括重写。来源分层为：

1. `static/app.js`：全局指令、整段分镜指令、导演硬规则、镜头节奏、场景与子场景、对白唯一、画面密度、自动视觉 Skill、风格与运镜路由、单镜重生成规则；
2. `static/character-core/character-core.js`：内容类型与十一项统一风格、人物事实与关系、别名、年龄阶段、人物外形、正式人物与临时人物选角规则；
3. `main.py`：最终请求的协议锁、人物/场景/分镜兜底规则和实际运行时追加规则；
4. `resources/cinematic_library_v3.json`：统一风格、画质、镜头、运镜、转场和连续性资料库；
5. `templates/index.html` 与 `DEFAULT_STYLE`：最终导出的画面限制、画质约束、负面提示词与输出区块顺序。

迁移要求是保留这些规则的完整语义分层：

- 内容类型、统一风格、人物事实、关系、别名和人物阶段归入“小说面板提取”方案；
- 整段分镜、场景连续、人物/临时人物可见性、镜头、对白、信息载体、密度、视觉安全和风格路由归入“分镜模式”；
- 原文忠实、剧情单元切分、跨段连续与卡点归入“分段开头”；
- 画面前缀、画质约束、画面限制、负面提示词和风格库归入“约束设置”；
- JSON 字段、槽位 ID、逐行卡片、补镜 API、前端状态修复等仅作为后端协议实现参考，不出现在剧本生成的最终文本提示词中。

## 分段开头策略

“分段开头”是与“连续开头”“爆款开头”并列的第三种叙事策略预设。

### 规则

分段开头的规则以小说面板真实使用的整段分镜提示词为来源，迁移其“剧情单元切分、镜头画面组织、人物场景连续性、对白与信息载体处理、时长预算”语义；不迁移小说面板的 JSON 字段、逐行卡片、角色槽位、补镜和质量闸门流程。

- 从原文开头开始，按原文时间线连续处理；禁止前置结局、闪回、重生回溯，以及新增关键人物、关键因果、核心情节、关键台词或结果。
- 在模型内部按可独立成立的剧情单元分段，不按自然段、字数、句号或标点机械切分。仅在地点或时间层变化、人物目标或行动对象变化、动作阶段完成、关键道具状态变化、信息揭示、对白推进后的直接反应、关系或情绪的明确可见转折时建立新单元。
- 每个单元必须能够独立用于短视频生成，内部具备建立、推进和卡点；卡点只能停在原文已有的动作、道具、信息、关系或情绪的新状态上，不得补造答案或后续反转。
- 当前单元以当前原文事实为最高优先级；只有明确承接同一空间时，才继承上一单元的地点、站位、朝向、手中道具及其状态、动作后状态、天气、光线和情绪。
- 下一单元首帧必须承接上一单元末帧的人物身份与阶段、服装逻辑、关键道具、空间、站位、动作方向或情绪状态。明确出现新地点、电话两端、室内外转换、回忆/梦境/监控/视频层或时间切换时，必须重新建立相应空间或叙事层。
- 原文仅描写环境、道具、规则、聊天、合同、名单、证据或屏幕时，可以输出空镜或物件镜，禁止为了凑画面擅自加入人物；原文明确可见但未建立人物卡的临时人物可出镜，并在连续场景中保持基础辨识和服装体系一致。
- 每条画面按“具体空间与站位 → 动作起始状态 → 连续动作链 → 道具或环境变化 → 可见反应 → 动作后新状态 → 镜头落点”组织；一个镜头只承担一个主要叙事任务，抽象心理、关系、规则和情绪必须转为可见证据。
- 仅在原文存在且可确认说话人的口语对白时输出对白；每句对白只出现一次且仅归属一个说话人。聊天、系统提示、合同、名单、表格、文件和旁白不转为人物口播，但原文明示的信息载体必须作为剧情道具视觉化。
- 不输出内部分析、分段依据、评分或判断过程，只输出所选格式的最终成品。
- 选择 10s 时，每个单元总时长为 10 秒；选择 15s 时，每个单元总时长为 15 秒。每单元时间轴从 00:00 开始，最后一个镜头必须恰好结束于所选时长；单镜通常为 1 至 4 秒。
- 不为凑时长复制镜头、动作、构图、台词或静止口型；信息不足时减少镜头数量，保留完整可拍摄画面。

## 分镜模式

新增“分镜模式”作为第四种输出格式。它沿用小说面板实际导出的文本结构，而不是 JSON 或额外的“第 N 段”包装。

在无约束设置或约束设置未启用任何项目时，一个单元的基本结构为：

```text
统一风格：{题材适配的统一风格}
统一人物：{本单元实际出场人物或关键主体}

镜头画面：
00:00-00:XX | 景别 - 机位/角度 - 运镜 - 转场 | 画面正文
...
```

- 时间轴从每个独立单元的 00:00 开始；末镜结束时间必须等于当前按钮选择的 10s 或 15s。
- 每条画面正文必须可拍摄，表达具体空间和站位、动作起点、连续动作链、道具或环境变化、可见反应与镜头落点。
- 只在原文存在可确认说话人的口语对白时输出对白；系统界面、弹幕、聊天记录、合同和文件文字不自动转为人物对白。
- 原文明确存在的聊天、系统、合同、名单、监控等信息载体应作为剧情道具视觉化。

## 约束设置

### 可用范围

- 画布模式：可用；
- 剧情模式：可用；
- 分镜模式：可用；
- 剧本模式：不可用。选择剧本模式时隐藏或禁用约束设置入口，且后端不得注入任何约束文本。

### 默认和持久化

- 系统默认关闭。
- 关闭时不改变现有任何输出。
- 保存并启用后，配置会保存到当前剧本草稿和项目；后续生成自动沿用。
- 只有用户关闭总开关、清除选择，或新建项目时才停止或重置注入。

### 类别

总开关开启后，以下四类独立选择，可只选其中一个，也可以全部不选：

1. 画面前缀词；
2. 画质约束；
3. 画面限制；
4. 负面提示词。

每类均支持：

- 不选择；
- 选择系统预设；
- 创建用户自定义内容；
- 编辑当前使用内容。

编辑系统预设时必须生成当前项目的自定义副本，不得修改全局系统预设。

### 初始系统预设

画面前缀词至少提供：真人实拍、3D、2D、国漫。系统预设由管理后台维护，可继续添加、编辑、发布或下线。

画质约束、画面限制、负面提示词也由管理后台维护系统预设，并允许用户创建项目级副本。

### 输出注入顺序

约束只包裹所选格式的主体内容，不改变格式自身的结构。

对于启用了约束且当前模式允许的每个输出单元：

```text
【画面前缀】：{仅当已选择画面前缀时输出}

【画质约束】：{已选画质约束和已选画面限制；两者都为空时不输出}

{当前模式原有主体内容}

负面提示词：{仅当已选择负面提示词时输出}
```

具体主体格式保持如下：

- 画布模式：保持基础设定、声音设计、氛围与画质规范、多镜头叙事时序脚本；
- 剧情模式：保持基础设定、风格、时长和既有时间轴镜头格式；
- 分镜模式：保持统一风格、统一人物、镜头画面格式；
- 剧本模式：不注入约束，保持现有场次、人物、▲画面和对白格式。

## 提示词和预设结构

新增或扩展以下系统预设：

- `script-extract-novel-panel`：小说面板人物与场景提取规则；
- `script-segmented`：分段开头策略；
- `script-format-shotlist`：分镜模式输出格式；
- 约束词预设：按 `prefix`、`quality`、`restriction`、`negative` 四类维护。

提取方案、策略和格式必须使用明确白名单映射。任何不在白名单内的值回退到既有默认值，不能静默映射为其他新功能。

## 前端设计

### 切换指令

原“扩展工具暂未接入”的按钮替换为“切换指令”。弹窗第一版展示两项完整提取方案，选中后写入草稿表单状态。页面需展示当前选中的方案名称。

### 模式选择

- 开头策略：连续开头、爆款开头、分段开头；
- 输出模式：画布模式、剧本模式、剧情模式、分镜模式。

### 约束设置

约束设置按钮位于输出模式选择区域、画布模式控件附近。选择剧本模式时不可操作且不显示为可用状态。弹窗包含总开关和四个独立类别，每项有预设选择、新建和编辑入口。

## 后端和数据

- 现有 `/api/chat` 继续作为提取和剧本生成入口；不新增模型调用接口。
- 提取请求新增提取方案字段，后端按白名单选择对应人物场景提取预设。
- 生成请求新增 `mode: segmented`、`format: shotlist` 和约束对象。
- 后端根据输出模式决定是否向系统提示词或生成指令注入约束规则。剧本模式强制忽略约束对象。
- 历史记录和历史导出必须使用三种策略与四种格式的正确中文名称。
- 系统预设目录、持久化预设库、审计记录、管理后台预设库和提示词策略展示必须同步新增项目。

## 验证

必须覆盖：

1. 新提取方案正确解析并使用小说面板提取预设；
2. `segmented` 正确使用分段开头预设；
3. `shotlist` 正确使用分镜模式预设；
4. 连续开头、爆款开头及三个现有输出格式不发生回归；
5. 10s 与 15s 被传入分段开头和分镜模式；
6. 允许模式中约束按前缀、主体、负面词的顺序注入；
7. 剧本模式不显示或禁用约束设置，且服务端强制不注入约束；
8. 约束设置可不选择任意类别，且不产生空标签；
9. 约束配置在草稿和项目中保存、恢复；
10. 系统预设编辑不会被普通用户直接覆盖，用户编辑生成项目级副本；
11. 管理后台可以维护四类系统约束预设。
