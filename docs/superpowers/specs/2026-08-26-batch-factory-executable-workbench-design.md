# 批量工厂可用工作台设计规格

## 背景与目标

`/batch-factory` 必须保持用户确认的截图式三栏工作台布局，并从静态展示升级为真实的批量生产闭环。页面不是主导航项：用户从水货生产的“批量工厂”入口进入，标题栏提供“返回水货生产”。

本期目标止于“合并产物可下载”：不实现外部短视频平台的上传、发布和账号授权，也不得把这些能力伪装成可用操作。

## 不变的视觉结构

1. 标题栏：返回水货生产、批量工厂标题、批次说明、新建批次。
2. 顶部批次栏：批次名称与编辑、批次书籍数、生产统一设置、生产摘要、高级设置、启动导演、生成、合并等批次动作。
3. 状态中心：按书籍计数；状态筛选同步左侧列表。
4. 三栏工作区：左侧小说列表，中部当前小说详情，右侧视频进度和批量合并。
5. 单书详情：以弹层展示任务详情、导入编辑、钩子审核和单书细调；不得导航离开批次工作台。

发布统一设置、上传待上传和发布折叠区在本期从可操作界面移除，或显示为不可用的后续能力，不能显示成功状态或可点击主操作。

## 数据来源与导入

### 小说获取交接

- 小说获取页允许勾选已完成任务并执行“进入批量工厂”。
- 交接接口建立新批次后直接打开该批次的小说列表，不经过导入预览。
- 每项保留：`sourceTaskId`、Book ID、书名、平台、正文、原始 TXT 文件名、原始元数据。
- 新批次使用用户个人默认生产配置；无个人默认配置时使用系统默认配置。

### 手动粘贴

- 支持同次导入与文件上传混合使用。
- 每部小说可以用独占一行的 `1`、`1.`、`1、`、`一`、`二`、`三` 等编号分隔；编号不属于正文。
- 独占一行的较长纯数字可作为该书 Book ID，随后的文本是正文。例如 `10001` 后为第一本正文，`10002` 后为第二本正文。
- 默认书名取每本正文第一行；该行保留在正文中，且允许在预览内编辑。
- Book ID 可留空，留空时列表标题下不显示 ID；填写时仅允许数字。

### TXT/MD 文件

- 只接受 `TXT`、`MD`；一份文件始终对应一本小说，不进行正文二次拆分。
- 去除扩展名后的纯数字文件名作为 Book ID，书名取正文第一行。
- 中文、英文、中文数字混合、带符号的文件名默认作为书名。
- 所有自动识别出的书名和 Book ID 均可在导入预览修改。

### 校验与重复处理

- 空文件、或分隔编号后无正文的条目禁止加入，并提示“正文不能为空”。
- 同一批次中 Book ID 相同或书名相同都标记为重复。
- 发现重复时先阻止确认，提供“返回修改”和“继续上传”。继续上传不得篡改或自动补充 Book ID，只在小说列表标记重复项。
- 每部书在独立内部任务目录保存，目录以系统任务 ID 隔离，避免重复 ID 或同名书覆盖产物。用户可见的下载文件名仍为 `BookID.mp4` / `BookID.txt`，无 Book ID 时为书名。

## 批次与配置

- 批次按导入时间自动命名，用户可在详情中改名。
- 导入确认后立即创建或写入批次，并显示在任务列表，不保留仅浏览器可见的草稿。
- 启动前，用户可编辑书名、Book ID、全文正文或删除单书；任务进入 AI 处理后以上内容锁定。
- 系统默认与公共模板只由获授权的开发者/管理员维护；普通用户可保存、编辑和删除多套个人配置，并可选定一套为个人默认。
- 每本小说保存独立的配置快照。批次全局配置变更不会静默更新任何已存在小说；用户必须勾选书籍，执行“批量应用设置”。
- 单书或多选启动默认使用各自快照，可在启动前覆盖模式、模型、画幅和时长；配置过的任务在列表中标记。

## 生产状态和动作

### 启动范围

导演、导演结果和视频生产都支持：单本、勾选多本、全批次。批次状态按书籍而非按视频卡计数。

### 模式

- 原著直出：直接进入导演与后续生成。
- 爆款钩子：先生成钩子，状态进入待审核；审核通过才进入后续生成。
- 钩子审核支持手动编辑后通过，以及要求 AI 重新生成。审核在当前工作台的单书详情弹层内完成。

### 视频提示词

- 每条 VIDEO 提示词的时长受所选模型的单段最大时长硬性限制。超限必须自动拆分，禁止出现如 100 秒的单卡。
- 拆分优先采用用户设置的目标时长；剧情不足时允许尾卡较短，不得为了凑时长新增原文没有的剧情。
- 跨卡须重复必要的角色、场景、服装和承接动作；禁止使用“同上”“继续”等脱离本卡上下文的描述。
- 单书详情允许编辑单张卡并只重新生成该卡；手工修改的卡标记“已编辑”，用户可明确选择重新生成来替换该卡内容。

### 视频、异常与合并

- 视频生成支持单卡、勾选卡、单书、整批次。
- 失败卡可直接重试；任何卡失败时所属书籍进入“异常”筛选，异常统计按书计数。
- 一本书所有视频完成后自动进入待合并，支持单书、勾选多书和全批次合并。
- 合并完成后提供 MP4 与 TXT 下载。发布/上传不在本期范围。

## 后端与持久化要求

- 复用既有批次 API、导演、提示词编译、视频生产、状态轮询与合并能力，避免第二套状态机。
- 补齐小说获取页面的交接调用，并使截图工作台消费交接结果及批次数据。
- 批次、书籍、配置快照、个人预设、审核和操作记录必须持久化到 MySQL；不得继续为新增或改造后的核心批次状态使用 JSON 文件存储。
- API 必须按当前登录用户和团队权限隔离。管理员维护公共模板，普通用户不能修改系统默认或公共模板。
- 模型能力是单段时长的唯一上限来源，前后端均需校验。

## 验收标准

1. `/batch-factory` 保持截图式标题栏、批次栏、状态中心和三栏工作台，在浅色/深色主题均可读。
2. 小说获取可选中完成任务后直接创建批次并进入小说列表；手动粘贴和 TXT/MD 上传按本规格进入预览与校验。
3. 导入、编辑锁定、重复标记、个人配置、显式批量应用配置、权限边界均有 API 与 UI 测试。
4. 原著直出、钩子审核、时长分卡、跨卡上下文、单卡编辑重生、失败重试和单书/批量合并通过端到端契约测试。
5. 前端构建、定向 Node/Go 测试、Docker 健康检查和实际页面/API 访问验证通过后，才允许发布。
