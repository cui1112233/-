# 批量工厂工作台设计规格

## 目标

将批量工厂放到“水货生成 / 创作漫剧”旁边作为并列创作入口，并把页面改造成参考图所示的批次工作台：批次总览、状态中心、小说列表、单书工作区、视频进度和批量合并。

## 范围

- 保留 `/batch-factory` 路由、现有批次接口、状态轮询、导演审核、提示词编译、视频生产和合并逻辑。
- 调整用户侧导航和水货生产入口的并列关系。
- 重组 `BatchFactoryPage` 的可见布局与交互状态，不迁移或覆盖账号中心、模型服务和团队授权逻辑。
- 仅使用现有 Ant Design、Lucide 和项目主题变量，不新增 UI 依赖。

## 工作台结构

1. 顶部批次栏：批次名称、数量、生产摘要、统一设置、批次动作。
2. 状态中心：按状态统计全部、待开始、待审核、AI 处理中、待生成、排队中、视频生成中、异常、待合并、已合并；点击状态筛选左侧小说列表。
3. 左侧小说栏：搜索、状态筛选、可滚动小说列表、当前项高亮、分页/数量提示。
4. 中央工作区：当前小说标题、异常提示、原文、爆款开头、人物/场景/道具、VIDEO 时间轴和单书生产控件；折叠面板保持可扫描密度。
5. 右侧栏：视频生成环形/条形统计、刷新说明、批量合并范围、成品时长倍率、文件命名规则和合并按钮。

## 交互规则

- 左侧切换小说只改变当前中央详情，不销毁批次上下文。
- 后端批次存在活动任务时继续按现有 2.5 秒轮询；轮询结果同步状态中心、左侧列表和右栏进度。
- 失败项在左侧和中央同时标红，中央提供重试、详情、查看 Prompt、标记问题。
- 批量合并只提交已满足服务端条件的项目，前端显示范围、倍率和预计文件数量。
- 单书设置/编辑只作用于当前小说，并显示“单书已调整”标识。
- 无活动批次时显示导入/创建工作台；已有批次时默认进入工作台详情。
- 视口宽度不足时改为：小说列表抽屉/折叠、中央详情、右栏折叠面板，禁止页面级横向滚动。

## 视觉约束

- 深色主题采用现有主题 token，文字对比度满足当前项目可读性；浅色主题保持同一结构和语义颜色。
- 页面区块使用平面工作台分区；重复小说和 VIDEO 项可使用小卡片，禁止卡片套卡片。
- 关键动作使用图标加文字，刷新、设置、重试、合并等按钮保持现有组件风格。
- 稳定列表、状态块和右侧面板尺寸，避免轮询或错误文案导致布局跳动。

## 验收标准

- 从水货生产页面可直接进入批量工厂，入口与创作漫剧并列可见。
- 批量工厂在桌面宽屏呈现四区工作台；单书切换、状态筛选和批量合并可用。
- 现有批次 API 调用和状态更新测试继续通过。
- 前端生产构建通过，浅色/深色主题无明显文字对比度问题。
