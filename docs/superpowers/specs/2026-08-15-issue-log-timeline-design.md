# 问题日志时间线设计

## 目标

将用户侧只读“问题日志”从普通列表改为按发生时间排列的运维时间线，方便用户识别最近故障，也方便管理员根据同一记录修复。

## 范围

- 保留现有自动日志来源：API、网络、页面异常和小说面板 AI 诊断。
- 顶部显示最近 24 小时异常、接口失败和配置/认证问题的数量。
- 按时间倒序显示时间线卡片；每条包含可读错误名称、状态码、请求方法、接口或功能页面。
- 401 使用提示色；4xx/5xx 和网络错误使用错误色。
- 空状态继续使用现有 Ant Design 空状态。

## 不在范围内

- 不新增用户手动反馈、筛选、删除或修改日志。
- 不改变日志采集、权限过滤或管理员完整诊断数据。

## 验证

- 添加 UI 契约测试，验证时间线、概览和状态映射存在。
- 构建 React 前端并在浏览器检查深色/浅色主题下文字可读、时间线不溢出。
