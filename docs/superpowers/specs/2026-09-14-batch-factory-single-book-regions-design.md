# 批量工厂 V11：单书配置分区入口设计

## 目标

批量工厂“单书配置”位于每本小说行的“小说正文”和“预设”之间。它不是一个笼统的跳转按钮，而是该书所有独立选择的分区控制面板，使用户能直接配置单本书并清楚看到是否覆盖作品统一配置。

## 页面与交互

每行的单书配置单元固定显示五个分区按钮：

1. 引擎配置
2. 资产设置
3. 约束设置
4. 视频设置
5. 画面设置

点击任意按钮打开居中的单书配置弹窗，并直接落在对应区域。五个入口都以同一 `batchId + bookId` 读取和保存，关闭后回到当前小说行。操作列不再放重复的“单书配置”入口。

每个入口显示简短状态：

- `继承作品配置`：当前书没有该区域的 override。
- `已单书覆盖`：当前书保存过该区域的实际选择。
- `未启用`：AI 推理模块关闭，不能参与最终编译。
- 资产设置额外显示该书已保存的人物、场景、道具数量。

## 五个区域的职责

| 区域 | 单书可配置内容 | 保存目标 |
| --- | --- | --- |
| 引擎配置 | 视频引擎、视频模型、VIDEO 时长/上限、固定单视频与时长、画幅、图片模型、文本模型 | 当前书引擎 override |
| 资产设置 | 当前书实际人物、场景、道具的 Prompt、图片版本、主图、替换与重新生成；人物场景提取规则从个人中心已发布预设词选择 | 当前书资产记录与 `aiPromptConfig.assets` override |
| 约束设置 | 复用剧本生成的五层约束：基础设定、画面前缀词、画质约束、画面限制、负面提示词 | `aiPromptConfig.constraints` override |
| 视频设置 | 视频提示词预设、固定开头（单个/多个 VIDEO）、范围 | `aiPromptConfig.video` override |
| 画面设置 | 画面提示词预设、范围；默认不启用，不写入视频提示词 | `aiPromptConfig.visual` override |

所有 Prompt 选择都只读取个人中心已发布、槽位匹配的预设词；浏览器只保存预设 ID、名称、槽位、版本和约束分类，不读取预设正文。

## 继承与保存

生效顺序固定为：作品统一配置 → 单书 override → 单分镜/单 VIDEO override。未改动的字段不写入单书配置；用户恢复与作品相同的值时删除该字段的 override。分镜或 VIDEO 的修改不能反向改动该书或作品统一配置。

“保存当前书覆盖”只影响所选 `bookId`，使用当前书 revision 并发控制；保存成功后刷新该行状态。模型或预设目录不可用时显示真实错误并禁止对应选择，不用本地默认项伪装可用。

## 验收与测试

- 每行列顺序为：序号、小说正文、单书配置、预设、提示词、片段库、操作。
- 单书配置列能独立打开五个区域，且入口状态与当前书保存数据一致。
- 在任意区域保存后，只改该书；另一书与作品统一配置保持不变。
- 约束区域显示剧本生成同一套五层开关和对应预设。
- 资产区域可查看和维护该书真实资产及图片版本，不用占位图片表示已生成。
- 已有的单书 override、视频/画面提示词、资产记录和发布逻辑继续回读。
- 覆盖入口、单书保存以及取消恢复继承分别有源代码测试；前端构建通过。
