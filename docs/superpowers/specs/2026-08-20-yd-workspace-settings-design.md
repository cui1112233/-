# 中转亚迪工作设置设计

## 目标

让每个登录账号在“工作台设置”中填写自己的中转亚迪 API Key，并使
YD2.0 Mini 视频任务在提交和异步轮询时都使用该账号的密钥。密钥不能回显
给浏览器，也不再要求用户编辑 launchd 环境变量。

## 范围

本次只调整工作台设置中的模型服务布局，并增加中转亚迪的视频凭据配置。
YD2.0 Mini 的固定请求规则保持不变：`yd2.0-mini`、720p、1 秒、9:16 或
16:9、固定空白图在第一张、场景图在最后一张。

不修改水货生产的分段、提示词、资产、视频任务界面或管理员模型目录的
业务能力。管理员仍决定 YD2.0 Mini 模型是否启用；账号设置只提供调用凭据。

## 设置页布局

“工作台设置”中的模型相关字段合并到“模型服务”区域。桌面端依次纵向显示
三个服务行，窄屏自动堆叠。服务行之间使用分隔线，而不是嵌套卡片。

1. **文本推理**：保留现有 API 提供商、Base URL、模型名称和 API Key。
   已保存的服务商名称（例如“小米 MiMo”）显示在该行，且只用于文本分析。
2. **图片生成**：保留现有供应商名称、Base URL、生图模型和 API Key，且只
   用于水货生产的图片生成。
3. **视频生成**：新增固定名称“中转亚迪”，显示“YD2.0 Mini / 720p / 1 秒”
   的能力说明、已配置状态和一个 API Key 密码输入框。该行不显示可编辑的
   Base URL、模型名、时长、分辨率或图片规则。

模型服务区域底部保留一个统一的“保存设置”命令。输入框为空时不覆盖已有
密钥；保存成功后输入框清空并将状态更新为“已配置”。

## 凭据与数据边界

新增每用户的视频凭据记录，逻辑名称为 `yd_video`。公共读取接口仅返回：

```json
{
  "video": {
    "provider": "yd_video",
    "displayName": "中转亚迪",
    "hasApiKey": true
  }
}
```

请求、响应、审计日志和任务错误文本不得包含 API Key。保存时，后端使用服务端
主密钥进行加密后再写入 MySQL；读取时仅在服务端解密，并仅供当前任务的 YD
适配器使用。主密钥由部署环境提供，缺失时保存接口返回明确的“视频凭据加密
服务未配置”错误，不降级保存明文。

## 任务调用

YD 提交请求已经携带任务的 `OwnerID`。适配器解析凭据时按以下顺序处理：

1. 对 `yd_video` 适配器，按任务 `OwnerID` 查询并解密该账号的中转亚迪密钥。
2. 仅在管理员明确保留服务器凭据引用时，读取服务器环境凭据，供受控共享模型
   使用；账号密钥不会写回模型目录。
3. 未配置账号密钥时，在创建任务阶段拒绝提交并提示前往“工作台设置 - 中转亚迪”。

异步任务轮询同样传入任务所属账号，不能在提交成功后改用另一个账号或全局密钥。
已创建任务的访问仍受原项目和账号权限约束。

## 错误处理

- 未配置视频密钥：创建任务返回可操作的设置提示，不创建队列任务。
- 服务端主密钥缺失或解密失败：返回通用配置错误，不泄露密钥内容。
- YD 返回鉴权失败：任务记录“中转亚迪鉴权失败，请检查工作台设置中的 API Key”。
- 上游网络、任务失败和公共 HTTPS 图片限制维持现有错误映射。

不提供“测试视频连接”按钮，因为 YD 的创建接口会生成并可能计费。实际任务提交
仍显示现有任务状态和错误信息。

## 验收

1. 设置页能显示三个清晰分区，且“中转亚迪”不与文本或生图密钥混用。
2. 保存后刷新页面，视频服务仅显示“已配置”，不显示真实 API Key。
3. 用户 A 和用户 B 使用不同密钥时，提交和轮询均使用各自密钥。
4. 视频密钥或主密钥缺失时，任务不会进入队列，错误提示能引导到正确设置。
5. API 返回、浏览器状态、错误日志与任务详情均不存在 API Key。
