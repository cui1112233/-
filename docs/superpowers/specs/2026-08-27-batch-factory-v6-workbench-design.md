# 批量工厂 V6 工作台设计规格

## 目标

将 `/batch-factory` 完整改造为 V6 四区工作台，同时复用当前真实批次、小说导入、导演生成、视频生产、合并与状态 API。`/batch-factory-preview` 仅作为开发验收入口，不承担正式用户流程。

## 已确认的产品规则

- 正式入口只有 `/batch-factory`；批量工厂不加入全局导航，入口仍位于水货生产的“创作漫剧”旁。
- 默认布局为 V6 四区：小说列表、当前小说生产区、视频操作/统一播放器区、全批次进度区。
- 状态中心只提供数量和定位入口；点击状态更新右侧“当前筛选”，不在状态中心下方展开列表，也不改变左侧小说列表。
- 当前筛选使用连续定位：重复点击同一状态依次跳到下一本命中小说，循环回到第一本。
- 默认渐进展开：资产、单 VIDEO 设置和详细提示词默认折叠；点击后在工作区展开或使用 Drawer。
- 正常生产模式锁定布局；显式进入“编辑布局”后才允许拖动列宽、折叠区域和保存布局。
- 所有 VIDEO 和最终合并结果共用一个播放器；播放器默认展示最终合并结果，可切换到任一 VIDEO。
- 系统 Prompt 只在管理后台维护；生产页只显示预设名称，不恢复“提示词工作室”。
- 画面提示词、动态编译提示词和提交快照必须分离：`visualPrompt` 可编辑，`compiledPrompt` 在点击生成时编译，`productionSnapshot` 保存实际提交内容。
- 单 VIDEO 配置遵循 `system < batch < book < video`；未覆盖项继续继承，文本和开关支持“跟随批次/开启/关闭/单独设置”。
- 失败状态优先展示红色，手动修改展示紫色；只有发布成功才进入最终完成状态。

## 页面结构

### 顶部

标题“批量工厂”、返回水货生产按钮、当前批次选择/创建、编辑布局与保存/恢复默认操作。顶部不显示系统 Prompt 正文。

### 区域一：状态中心与当前筛选

状态中心显示全部、待开始、待审核、AI 处理中、待生成、排队中、视频生成中、异常、待合并、已合并数量。点击状态只更新当前筛选区域；当前筛选展示状态名、命中数量和命中的小说摘要。连续定位由前端维护每个状态的游标，并调用 `scrollIntoView` 定位左侧列表中的对应小说。

### 区域二：小说列表

显示当前批次的全部小说、主状态、异常标记、手动修改标记和生产进度。点击小说只切换当前小说，不把完整 Prompt 塞进列表。列表必须保留所有小说，不能用当前筛选结果替换数据源。

### 区域三：当前小说生产区

展示小说来源、生产方式、资产折叠组、导演结果和 VIDEO 卡列表。人物/场景/道具卡支持直接编辑、重新获取、保存，并保留稳定资产引用。VIDEO 卡展示本段剧情、资产引用、`visualPrompt`、镜头时间轴、当前状态和生成动作；详细单 VIDEO 设置使用 Drawer 或折叠面板。

### 区域四：视频操作、播放器与全局进度

视频操作包含生产统一设置、发布统一设置、批量/单本生成与合并。右侧只保留一个播放器，选择最终合并或任一 VIDEO 后更新同一播放区域。全局进度按所有小说的 VIDEO 汇总，异常优先，并显示队列、生成中、成功、失败和待合并计数。

## 数据流

1. 页面加载批次列表；若 URL 有批次或小说获取交接单，加载对应批次。
2. 批次设置通过现有 `updateBatchFactorySettings` 持久化；单本设置通过 `updateBatchFactoryItem` 持久化。
3. 导演、视频生成、合并动作继续调用现有批量工厂 API，成功后刷新当前批次与项目状态。
4. VIDEO 展示层从 `directorResult.storyboard` 读取结构化内容；生成前调用编译接口得到 `compiledPrompt` 预览，实际提交时保存 `productionSnapshot`。
5. 状态中心根据批次项目状态归一化为工作台状态，不修改后端主状态；当前筛选和连续定位完全由前端维护。
6. 布局偏好以用户维度持久化，默认使用 V6 列宽；异常或损坏的布局数据回退默认值。

## 错误与边界

- 无批次或批次为空时，显示空状态和导入入口，不展示静态示例数据。
- 模型能力缺失、模型绑定冲突、没有可生成 VIDEO、合并能力不可用时，使用现有 API 错误文案并保留当前页面状态。
- 单 VIDEO 时长修改必须触发当前 VIDEO 重新导演/重排提示，禁止只替换时长数字。
- 更换模型前校验最大时长与图生/文生能力，冲突时阻止提交。
- 生产/合并请求失败只更新对应小说活动日志和错误状态，不影响其他小说任务。
- 用户刷新页面后恢复当前批次、当前小说、布局偏好和已保存的设置覆盖。

## 验收标准

- `/batch-factory` 首屏符合 V6 四区结构，返回按钮回到 `/shuihuo-production`。
- 全局导航不出现批量工厂；水货生产页仍保留批量工厂入口。
- 状态中心点击不会过滤左侧列表；重复点击同一状态会连续定位命中的小说。
- 统一播放器可在最终合并和任一 VIDEO 间切换，页面不存在多个常驻播放器。
- 生产统一设置和单 VIDEO 覆盖真实持久化，刷新后仍能恢复。
- VIDEO 卡可区分和编辑 `visualPrompt`，生成前可查看 `compiledPrompt`，提交记录保存快照。
- 导演、生成、合并和失败重试继续走现有 API；无静态样例数据兜底。
- 相关契约测试、前端构建和生产 Docker 健康检查通过。
