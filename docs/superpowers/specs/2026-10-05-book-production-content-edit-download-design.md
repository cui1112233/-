# 小说生产正文编辑与下载设计

## 目标

让“小说详情”中的正文区域可直接进入编辑流程，并可下载当前生产正文，方便人工修订和留存。

## 边界

- 编辑对象是当前书的生产内容；保存沿用既有 `working-front-content` 草稿与 `productionContentMode` 标记。
- 不修改 `sourceText`、书城原文、原始抓取记录或已提交的 121 内容。
- 显示与下载统一使用当前有效生产正文：存在已保存生产内容时使用它，否则使用当前原文摘录。

## 交互

在“小说正文”标题右侧提供：

1. **编辑正文**：打开现有“编辑生产内容”弹窗，预填当前有效生产正文；保存后回读并刷新详情。
2. **下载 TXT**：在浏览器本地生成 UTF-8 文本文件，文件名为“书名-生产正文.txt”。无可下载文本时按钮禁用并说明原因。

## 验收

- 已编辑内容保存后，详情区域和下载文件均为新内容。
- 未编辑时，下载内容等于详情显示的原文摘录。
- 编辑和下载不产生原文写入或 121 上传请求。
