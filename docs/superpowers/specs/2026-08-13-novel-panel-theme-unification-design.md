# 小说面板主题统一设计

## 目标

小说面板跟随主软件向 iframe 同步的 `data-theme` 属性，在浅色和深色主题下保持一致的页面、卡片、表单、状态和功能子页面配色。

## 范围

- 为工作台样式补充完整的浅色与深色主题令牌。
- 将基础面板、AI 指令中心、历史记录和人物关系图改为只使用主题令牌。
- 将人物相关的动态内联颜色改为语义 CSS 类。
- 不调整页面布局、交互、业务逻辑或主软件到 iframe 的主题同步机制。

## 样式架构

`style.css` 保留现有的 `:root` 作为浅色默认值，并为 `[data-theme='dark']` 覆盖相同的令牌集合。令牌覆盖页面背景、表面、弱表面、字段、文字、辅助文字、边框、主色、警告/成功/危险状态和阴影。

所有组件均使用语义令牌，不再直接依赖白色、浅蓝灰或固定黄褐色。浅色主题保留当前视觉基调；深色主题使用相同语义层级的深色值。

## 组件处理

- 基础工作台：按钮、输入框、卡片、弹窗、空状态和项目列表改用表面、边框和文字令牌。
- AI 指令中心与历史记录：页面背景、顶栏、导航、编辑器和记录卡统一使用全局令牌。
- 人物关系图：移除未定义的 `--border` 回退值，改用标准边框和弱表面令牌。
- 动态提示：人物旧结果、人物隔离和选角来源标签由 `app.js` 设置语义 class；颜色、边框和背景全部由 CSS 提供。

## 数据流

主软件已通过 bridge 向小说面板写入 `html[data-theme]`。CSS 根据该属性选择令牌值，所有组件通过令牌自动响应。无需新增接口、存储或事件。

## 异常与兼容

未收到主题同步时，`:root` 提供浅色默认主题。已有浏览器或历史页面不会因缺少 `data-theme` 而失去样式。

## 验证

- 在浅色与深色主题下分别检查工作台、AI 指令中心、历史记录和人物关系图。
- 验证输入框、次级按钮、警告横幅及选角来源标签均随主题改变。
- 运行 JavaScript 语法检查，并确认服务启动后工作台资源可访问。
