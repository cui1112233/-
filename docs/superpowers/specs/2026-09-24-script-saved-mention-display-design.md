# 剧本保存态提及展示

## 目标

剧本生成页在编辑完成后进入分镜卡展示态时，已识别的 `@人物` 和 `@场景` 继续以与编辑器一致的视觉卡片显示，避免保存前后出现两种不同的表达。

## 展示规则

- 有主图的唯一匹配资产：显示主图缩略图和 `@名称`。
- 没有主图的唯一匹配资产：显示普通的 `@名称` 视觉标签。
- 未匹配或重名的提及：保留原始纯文本，不能错误绑定资产。
- 人物定义、画面描述及每张分镜卡均采用同一规则。

## 数据与生成边界

- 保存的剧本正文、复制内容和视频生成请求保持原始纯文本 `@名称`。
- 展示组件只在浏览器中将正文投影为视觉标签，绝不把图片或 HTML 写回剧本正文。
- 资产主图变化后，保存态再次渲染时使用当前主图；不修改历史提示词。

## 实现边界

- 在 `ShotOutputCards` 的分镜内容渲染层复用已有的提及分段规则。
- 保持查找高亮、复制、编辑分镜、参考图选择和视频生成的现有行为。
- 为有图、无图和未匹配三类提及添加回归测试。

## 验收

1. 编辑态插入 `@妻子` 并保存后，分镜卡仍显示妻子主图和名称。
2. `@老公` 没有主图时显示普通 `@老公` 标签。
3. 复制分镜及生成视频接收的文本仍包含 `@妻子`、`@老公`，不包含图片标记。
