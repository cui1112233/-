# 本地存储文件夹 设计文档

- 日期：2026-08-17
- 状态：已确认
- 关联功能：剧本生成、小说获取、改编小说、小说面板、水火制作、配音（TTS）

## 1. 目标与定位

用户在「设置」页配置一个**本地存储文件夹**（后端可读写的绝对路径），各功能产生的**最终输出结果文件**按功能写入该文件夹下的子目录；其余内容（索引、草稿、中间状态、配置）仍留在系统 `data/users` 下。

未配置该文件夹时，所有现有行为保持不变（写回 `data/users` 与 `data/shuihuo-objects`）。

## 2. 存储结构

每个用户独立一份，按账号隔离：

```
<storageRoot>/
├── 剧本生成/                  # 剧本生成结果 .md
├── 小说获取/                  # 小说获取 .txt（点「下载」时缓存）
├── 改编小说/                  # 改编后 .txt（点「下载」时缓存）
└── 制作工程/
    └── <项目名>/              # 水火制作 / 小说面板项目
        ├── 输出结果.md
        ├── 图片/
        ├── 视频/
        ├── 剪映/
        └── 配音/              # 该项目下载的 mp3
```

- `<项目名>` 取水火项目名或小说面板项目名，做非法字符清洗（`\ / : * ? " < > |` 替换为 `_`，去首尾空白，空名回退为 `未命名项目`）。
- 同名项目存在时沿用已有目录（追加写入），不覆盖历史文件。
- 所有目录在首次写入时按需创建（`fs.mkdirSync(..., { recursive: true })`）。

## 3. 配置项

- 配置字段：`storageRoot`（字符串，绝对路径），存入 `data/users/<username>/api-config.json`。
- API：`GET /api/config` 返回含 `storageRoot`（非密钥，直接透传）；`POST /api/config` 接受并校验。
- 校验规则：
  - 仅接受绝对路径（POSIX 以 `/` 开头，Windows 以盘符 `X:\` 开头）。
  - 保存时尝试创建根目录；失败则返回错误信息（如无权限、非法路径）。
  - 允许清空（置空 = 关闭本地存储，恢复旧行为）。
- 前端设置页新增「本地存储文件夹」输入框 + 「保存」按钮 + 「恢复」按钮。

## 4. 存储路径解析（后端 helper）

新增 `lib/storage-root.js`，提供：

- `getStorageRoot(username)`：读取配置，返回绝对路径或 `null`。
- `featureDir(root, feature)`：返回 `<root>/<feature>`，feature 取自固定常量。
- `projectDir(root, projectName)`：返回 `<root>/制作工程/<清洗后项目名>`。
- 功能子目录常量：
  - `SCRIPT_RESULTS = '剧本生成'`
  - `NOVEL_FETCH = '小说获取'`
  - `NOVEL_ADAPT = '改编小说'`
  - `PRODUCTION = '制作工程'`
- 路径安全：项目名清洗后再拼路径，防止路径穿越；feature 只用固定常量。

## 5. 各功能落盘规则

| 功能 | 触发时机 | 目标文件 |
|---|---|---|
| 剧本生成 | 保存历史（POST /api/history）时 | `<root>/剧本生成/<historyId>.md` |
| 小说获取 | 点「下载」 | `<root>/小说获取/<bookId>.txt` |
| 改编小说 | 点「下载」 | `<root>/改编小说/<bookId>.txt` |
| 小说面板输出 | 工作台「导出结果」 | `<root>/制作工程/<项目>/输出结果.md` |
| 水火图片/视频 | 生成成功后复制 | `<root>/制作工程/<项目>/图片\|视频/` |
| 剪映文件夹 | — | 建 `剪映/` 目录（占位，现无工程生成逻辑） |
| 配音 | 点「下载配音」 | `<root>/制作工程/<项目>/配音/<名>.mp3` |

### 5.1 剧本生成

- `routes/history.js` 保存历史时，若配置了 `storageRoot`，将输出正文生成一份友好 md 写入 `<root>/剧本生成/<historyId>.md`（含标题、格式/模式/时长/生成时间头部 + 正文）。
- 原始 `.txt` 与索引仍照旧写 `data/users`（本地文件夹只是结果副本）。

### 5.2 小说获取 / 改编小说

- 扩展现有 `POST /api/novel-fetch` 与 `/api/novel-fetch/process`，增加可选 `saveToFolder`（布尔）与 `bookId`/文件名参数：
  - 前端「下载」按钮改为调用后端保存（携带 `saveToFolder: true` 与文件名/书号），后端把正文写入对应子目录并返回保存结果。
  - 保留原有浏览器下载能力（`saveToFolder` 缺省为 false 时行为不变）。
- 文件名：`<bookId>.txt`；同一书号重复下载时覆盖。

### 5.3 小说面板输出

- 新增导出端点（如 `POST /api/novel-panel/:id/export`）：从项目 JSON 汇总 `final_segments` / 分段文本，生成 `输出结果.md` 写入 `<root>/制作工程/<项目名>/输出结果.md`。
- 工作台「导出结果」入口调用该端点（保留原浏览器 TXT 导出）。

### 5.4 水火图片/视频

- 生成成功后（或下载时）将 `data/shuihuo-objects/shuihuo-production/<userId>/<projectId>/images|videos/<file>` 复制到 `<root>/制作工程/<项目名>/图片|视频/<file>`。
- 本期按**同机共享文件系统**处理（Express 可直接读 Go 落盘的本地目录）；水火部署在其它服务器时需后续走 Go 侧（不在本期）。
- 复制时机：下载媒体时复制（与「仅点下载才缓存」语义一致）。为避免遗漏，也可在项目文件列表接口返回时同步复制；本期采用「下载时复制」。

### 5.5 剪映

- 仅在创建项目目录时创建 `剪映/` 空目录占位；无真实工程生成逻辑（系统当前无 CapCut 工程导出）。

### 5.6 配音

- `POST /api/tts` 增加可选 `projectName` 参数（前端配音页 / 小说面板工作台把项目名随请求传入）。
- 当配置了 `storageRoot` 且带 `projectName` 时，把音频字节写入 `<root>/制作工程/<项目名>/配音/<时间戳或id>.mp3`，同时仍透传回浏览器。
- 无 `projectName` 时不写盘（保持现状）。

## 6. 恢复机制

- 设置页「恢复」按钮 → `POST /api/storage/restore`。
- 后端扫描 `<root>` 下各功能目录：
  - `剧本生成/`：读取所有 `.md`，与现有 `data/users` 历史索引比对（按文件名 id），把缺失项并入索引（不覆盖已有记录），正文指向本地文件。
  - `小说获取/`、`改编小说/`：列出 `.txt` 清单，通过新接口 `GET /api/storage/list` 供前端浏览/查看/下载。
  - `制作工程/`：列出项目文件夹与其中的文件，供前端浏览。
- 返回恢复报告：每个目录找到多少文件、新增多少条记录、是否有错误。
- 幂等：重复恢复不产生重复记录（按文件名去重）。

## 7. 错误处理

- 目录创建失败 / 写入失败：单个文件失败不阻断其它文件，记录错误并汇总返回。
- 路径校验失败：设置页保存时给出明确错误。
- 恢复过程中遇到不可读文件：跳过并计入报告错误数。
- 所有写入使用同步或 Promise 化的 `fs`，并在事务/锁之外进行（不占用账号锁）。

## 8. 测试

- 配置：`storageRoot` 校验（绝对路径、非法字符、清空）、保存/读取、publicConfig 透传。
- 存储 helper：功能目录解析、项目名清洗（含路径穿越防护）。
- 剧本生成：配置后保存历史 → md 出现在 `<root>/剧本生成/`；未配置 → 无副作用。
- 小说获取/改编：`saveToFolder` 保存成功；缺省时行为不变。
- 小说面板导出：导出端点生成 `输出结果.md`。
- 配音：带 `projectName` 写盘、不带不写盘。
- 恢复：扫描各目录、去重、返回报告；幂等。
- 回归：现有 novel-fetch / history / tts / novel-panel 相关测试保持通过。

## 9. 范围与边界（本期不做）

- 剪映（CapCut）真实工程生成/导出（系统当前无此逻辑，仅建目录占位）。
- 水火图片/视频跨机复制（水火部署在不同服务器时，需 Go 侧实现，不在本期）。
- 旧数据迁移（只对新输出生效，已确认）。
- 浏览器直写本地磁盘（已确认后端读写）。
