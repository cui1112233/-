# H3 分镜提示词展示设计

## 目标

批量工厂的 H3 导演卡在未编译 VIDEO 时，也使用统一的分镜视频提示词窗口：用户看到可读的中文导演卡和完整操作栏，而不是原始 JSON。

## 展示规则

1. 主编辑区按“人物定义、场景、事件、导演调度、总时长、Shot”输出中文文本。
2. 原始 H3 JSON 只通过“查看 H3 Trace”提供，不进入主编辑区。
3. 未编译 VIDEO 时，完整操作栏保持可见：保存、编辑、生成视频、查看候选版本置灰；重新生成导演分镜、查看 H3 Trace、重试可用。
4. 已编译 VIDEO 后继续使用现有完整编辑、候选版本和视频生成逻辑。

## 边界

- 本次不修改 H3 导演数据、时长测量、编译、视频任务或历史作品。
- 文本格式只派生自已保存的 H3 导演卡，不能捏造人物、时长或镜头。
