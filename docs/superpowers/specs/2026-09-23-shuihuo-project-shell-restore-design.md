# 水货生产作品库外壳恢复

## 目标

恢复 `/shuihuo-production` 为用户的作品库入口：展示“创作漫剧”和“批量工厂”两个入口，以及带封面的个人作品卡。批量工厂继续作为作品库内的工作台，不再替代根入口。

## 路由与界面

- `/shuihuo-production` 渲染 `ShuihuoProductionPage`，即作品库外壳。
- 作品库保留“创作漫剧”与“批量工厂”并列入口。
- 打开批量工程后进入既有的批量工厂单书工作台；返回动作回到作品库。
- `/shuihuo-production/creative` 保留为兼容别名，避免已有书签失效。

## 封面规则

批量工程的作品卡按下列优先级显示封面：

1. 用户明确选择的首分镜成功视频；
2. 第一部书中首个成功、可播放的视频；
3. 该书资产中的主图；
4. 默认占位卡。

视频封面使用静音内联视频预览，首个可渲染画面作为卡片首帧。不会生成、复制或删除媒体。

## 保留边界

- 保留 V11/V12 批次、单书配置、资产、H3 导演数据、自动化预设、Trace、视频与上传记录。
- 不修改 MySQL 数据、对象存储、账号、凭据和系统预设词。
- 不把历史 `13102` 容器或其独立数据卷部署到公网。

## 验证

- 路由回归测试验证根路径渲染作品库而不是直接渲染批量工厂。
- 覆盖封面优先级：指定首视频、可播放视频、主图、占位。
- 前端 API 测试与构建通过。
- 浏览器验收：作品库可见两个入口；已有批量工程显示封面；打开和返回不丢失当前批次。
