# 设置页提示音音量控制设计

## 目标

让用户能按账号调节剧本工作流提示音的音量，同时保持现有提示音开关、成功音、警示音和静默降级行为不变。

## 设置页

在“提示音”说明下方增加“提示音音量”滑块：

- 范围为 0% 至 100%，步长为 1%。
- 默认值为 60%。
- 右侧显示当前整数百分比，例如 `60%`。
- 当“提示音”关闭时，音量滑块置灰，但保留当前保存值，不重置。
- 调节滑块不自动播放测试声音。

## 配置

账号配置的 `notifications` 扩展为：

```json
{
  "soundEnabled": true,
  "soundVolume": 60,
  "petVisible": true
}
```

服务端将非数字、缺失或超出范围的 `soundVolume` 规范化到 0 至 100；旧配置缺失该字段时回退到 60。

设置保存和现有 `qiantie:notifications-updated` 事件均携带 `soundVolume`，使已打开的剧本页面即时使用新音量。

## 声音行为

`playTaskSound` 增加音量参数，接受 0 至 100 的整数百分比。播放增益在现有基准最大增益 `0.12` 上按百分比线性缩放：

```text
实际增益 = 0.12 × soundVolume / 100
```

- 音量为 0 时不创建或播放声音。
- 提示音开关关闭、浏览器不支持 Web Audio、浏览器阻止播放或创建节点失败时继续静默返回。
- 成功音和警示音共同使用该音量。

## 验证

- 配置接口对旧账号返回 `soundVolume: 60`，并保存 0、60、100 等合法值；越界或无效值被规范化。
- 设置页显示滑块、百分比和关闭状态；保存请求与事件带上音量。
- 声音模块验证 100% 使用增益 0.12、50% 使用 0.06、0% 不播放。
- 剧本页加载与设置更新事件后将当前音量传给成功音和警示音。
- 定向 Node 测试与前端生产构建通过。
