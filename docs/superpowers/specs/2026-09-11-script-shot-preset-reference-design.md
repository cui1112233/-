# 剧本分镜预设参考图设计

日期：2026-09-11

## 目标

将剧本生成中的分镜参考图改为水货生产的“预设绑定”表现：分镜第一行显示人物/场景名称标签；自动匹配当前分镜文本中实际出现、且已经选择主图的对象；所有支持参考图的视频模型统一使用这些主图；不支持参考图的模型必须明确提示并由用户确认是否无参考图生成。

## 非目标

- 不在分镜卡片显示人物或场景图片缩略图。
- 不使用星标控件。
- 不增加分镜级参考图总开关。
- 不使用“匹配不到时带入全部有图对象”的兜底逻辑。

## 自动绑定规则

1. 分镜生成完成后，对每一条分镜分别计算绑定对象。
2. 人物按名称、别名及现有兼容字段匹配；场景按名称及现有兼容字段匹配。
3. 只保留文本中实际出现的对象。
4. 对象必须存在明确的 `mainImageUrl`；候选图但未选主图的对象不绑定、不显示、不发送。
5. 人物排序在前，场景排序在后；同一主图去重；最多 9 个参考图。
6. 每条分镜独立计算，不把其他分镜的绑定结果复用到当前分镜。

## 分镜卡片 UI

标签显示在分镜卡片第一行，位于“分镜 N · 时长”和操作按钮之间：

```text
☐ 分镜 1 · 10s   [张高] [林悦] [医院走廊]       复制本分镜  生成视频
```

标签复用水货生产预设标签的名称展示语义，不显示图片、不显示星标、不显示“亮/灭”按钮。没有可用绑定对象时，不渲染空参考图区域。

## 视频生成数据流

1. 用户点击当前分镜“生成视频”。
2. 根据当前分镜自动绑定对象读取主图 URL。
3. 所有视频模型统一接收参考图列表参数。
4. 支持参考图的模型使用该列表生成。
5. 当前分镜没有主图时传空列表，仍允许正常生成。
6. 视频模型明确声明不支持参考图时，不静默丢弃图片，返回可识别状态并弹出：

   ```text
   当前视频模型不支持参考图，是否允许无参考图生成
   ```

   用户选择“允许无参考图生成”后才以空列表创建任务；选择“取消生成”则不创建任务。

## 数据与兼容

- 自动绑定结果可由当前 `extractInfo`、分镜文本和实体主图确定，不新增用户手动维护的总开关状态。
- 草稿和历史记录继续保存必要的剧本、实体、主图及视频任务信息；恢复后重新计算标签，避免旧的星标/总开关状态继续影响生成。
- 后端/provider 层必须保留“不支持参考图”的明确状态，前端据此确认是否降级。

## 实现边界

- 恢复并改造 Git 中已有的 `scriptVideoReferences` 参考图收集能力。
- 修改 `ShotOutputCards` 为预设名称标签布局。
- 修改 `ScriptPage` 的分镜生成参数和不支持参考图的确认流程。
- 删除旧星标、分镜总开关和全量图片兜底分支。
- 保留人物/场景编辑器的图片预览、上传、AI 生图、主图选择和删除能力。

## 验证标准

- 分镜第一行能显示匹配到的有主图人物/场景名称标签。
- 卡片中不存在星标、总开关和图片缩略图参考控件。
- 名称未出现在当前分镜或没有主图时，不显示、不传图。
- 支持参考图的不同视频模型都能收到当前分镜的主图列表。
- 不支持参考图时准确弹出确认文案；取消不创建任务，允许后空参考图创建任务。
- 人物优先、场景其次、URL 去重、最多 9 张规则通过测试。
