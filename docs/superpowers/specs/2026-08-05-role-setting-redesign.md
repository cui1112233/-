# 角色设定.md 重构设计

> 日期：2026-08-05
> 状态：待实施
> 关联文件：`prompts/角色设定.md`、`prompts/通用规则.md`、`prompts/人物场景提取.md`

---

## 一、问题诊断

### 1.1 当前架构

`角色设定.md` 定义了一套固定的剧本生成流水线：

```
双路径判定（有冲突/无冲突）
  → 四势能分类（动作/认知/命运/情绪）
    → 峰值前置
      → 同源元素转场回溯
        → 回落故事起点
          → 三幕式结构输出
```

### 1.2 四个系统性问题

| 问题 | 症状 | 根因 |
|------|------|------|
| **套路化** | 不同品类小说生成结果结构雷同 | 单一流程不区分品类，所有故事走同一个管道 |
| **钩子不够炸** | 开场冲击力不足 | 四势能只做"分类"不做"筛选排序"，AI 选最明显的而非最有冲击力的 |
| **创生偏离** | 创生内容不符合人物/世界观 | 刚性边界只有"禁止"列表（❌），缺少"怎么做才对"的正向引导，无自查机制 |
| **衔接生硬** | 峰值→回落过渡不自然 | "同源元素转场回溯"过于抽象，缺少操作级定义 |

### 1.3 根因总结

**公式驱动而非决策驱动。** AI 在机械执行公式，而不是像一个编剧那样做出判断——品类判断、独特性判断、冲击力判断、衔接方式判断。

---

## 二、新架构：分层决策

### 2.1 总体流程

```
原文输入
    ↓
【第一层：品类识别与策略匹配】
    ↓
【第二层：炸点发现与冲击力排序】
    ↓
【场景分配】
    ↓
【第三层：创生与衔接执行】
    ↓
输出分镜提示词
```

每一层都是一个"做判断"的步骤，而非机械执行。

---

## 三、第一层：品类识别与策略匹配

### 3.1 判别信号

AI 从原文提取三个信号判断品类：

1. **世界观信号**：古代/现代/未来/架空
2. **核心关系信号**：爱情/友情/敌对/权力/生存/成长/探索
3. **情绪基调信号**：甜/虐/紧张/压抑/燃/治愈/讽刺

### 3.2 六大品类策略表

| 品类 | 开篇核心策略 | 优先势能（权重x2） | 适配情绪基调 |
|------|-------------|-------------------|-------------|
| **情感/甜宠/虐恋** | 关系张力前置 | 情绪势能 | 极致情感瞬间 |
| **悬疑/惊悚/推理** | 谜面/威胁前置 | 认知势能 | 不安/压迫/未知 |
| **都市/职场/现实** | 身份反差前置 | 命运势能 | 讽刺/落差/压抑 |
| **古装/仙侠/玄幻** | 世界观奇观前置 | 动作势能 | 宏大/宿命/破碎 |
| **科幻/末世/架空** | 规则冲突前置 | 认知势能 | 异化/孤独/震撼 |
| **校园/青春/成长** | 情绪微妙前置 | 情绪势能 | 细腻/酸涩/悸动 |

## 四、第二层：炸点发现与冲击力排序

### 4.1 流程

```
全量扫描 → 五维打分排序 → 独特性验证 → 定格策略选择
```

### 4.2 五维冲击力打分

每个候选炸点在五个维度上 1-5 打分，品类权重不同（见 3.2）：

| 维度 | 衡量内容 | 高分标准 |
|------|---------|---------|
| **视觉冲击力** | 画面本身的可视化张力 | 动作激烈、构图张力强、有破坏/碰撞/对比 |
| **情感浓度** | 人物情绪的极致程度 | 爱恨/绝望/狂喜/崩溃的顶点 |
| **信息密度** | 瞬间传递的故事信息量 | 同时揭示人物关系+冲突+悬念 |
| **反转力度** | 颠覆预期的程度 | 身份/真相/关系反转 |
| **故事特异性** | 是否只有这个故事才有 | 与角色特质/世界观/核心设定强绑定 |

### 4.3 独特性验证（通用钩子测试）

强制测试：**删掉角色名字后，这个钩子还能认出是哪个故事吗？**

如果能套到同品类任何一本小说上 → 不合格，重新选。

通过的钩子必须包含至少一个**故事指纹**：独特的人物关系瞬间、独属于这个世界的规则展示、不可替代的道具/场景、角色标志性行为。

### 4.4 开篇装置库（22种，5大类）

选定的炸点通过以下装置类型来呈现。先选大类，再选具体装置，并匹配品类策略表。

#### 大类一：叙事装置（决定"故事怎么开始"）

| 类型 | 操作 | 适用场景 |
|------|------|---------|
| 噩梦惊醒型 | 噩梦→惊醒→现实 | 角色内心恐惧的外化 |
| 濒死闪回型 | 死亡瞬间→闪回起点 | 高张力事件后的回溯 |
| 重生回溯型 | 死亡/终结→重生起点 | 重生/穿越类故事 |
| 结局前置型 | 炸裂结局开篇→倒推起因 | 强反转故事 |
| 预知警告型 | 看见未来→回到现在 | 宿命感强的故事 |
| 幻觉/心魔型 | 心魔具象化→拉回现实 | 心理惊悚/内心挣扎 |

#### 大类二：冲突驱动（决定"哪里最炸"）

| 类型 | 操作 | 适用场景 |
|------|------|---------|
| 直接冲突型 | 争吵/打脸/对峙/撕扯 | 情感/都市/职场 |
| 背叛揭露型 | 撞破/发现颠覆性真相 | 情感/虐恋 |
| 生死危机型 | 倒计时+致命后果 | 悬疑/末世/古装 |
| 身份错位型 | 身份/地位极速反转 | 都市/职场/赘婿 |
| 误会引爆型 | 观众比角色知道得多 | 情感/喜剧 |

#### 大类三：情绪钩子（决定"什么感受"）

| 类型 | 操作 | 核心理念 |
|------|------|---------|
| 委屈钩子 | 角色有苦说不出 | "明明没错却被辜负" |
| 心动钩子 | 意料之外的温柔 | 克制——偷偷看一眼又移开 |
| 遗憾钩子 | "差一点" | 差一点表白、差一点挽回 |
| 失落钩子 | 先给希望再打碎 | 落差越大越抓人 |
| 恐惧/焦虑 | 直接威胁角色的生存 | 压迫感拉满 |

#### 大类四：信息差装置（决定"观众比角色多知道或少知道什么"）

| 类型 | 操作 | 适用场景 |
|------|------|---------|
| 绝密泄露型 | 主角知道一个颠覆性的秘密 | 悬疑/情感 |
| 信息差反转型 | 角色不知情但观众知道 | 都市/复仇 |
| 反常识颠覆型 | 打破大众认知 | 所有品类 |
| 对峙反转型 | 同一句台词语境完全相反 | 情感/虐恋 |

#### 大类五：视觉冲击（决定"画面怎么炸"）

| 类型 | 操作 | 适用场景 |
|------|------|---------|
| 视觉炸裂型 | 极限特写/破坏性动作/强对比 | 所有品类的基础要求 |
| 对比蒙太奇 | 两个极端状态硬切 | 宿命/反差强的故事 |
| 时间错位型 | 同一空间不同时间并置 | 回忆/穿越 |
| 第一视角冲击 | 第一视角体验暴力/坠落 | 动作/惊悚 |
| 道具引爆型 | 一个道具触发情绪雪崩 | 情感/悬疑 |

#### 视觉强度原则（基础约束）

无论选用哪种装置，**每个镜头描述必须包含至少一个抓眼要素**：破坏性动作、极致表情、构图张力、光线反差、道具冲击。不允许出现"平平的画面"。

## 五、场景分配

### 5.1 场景配额制

| 时长 | 场景上限 |
|------|---------|
| 15s | 2 |
| 30s | 3 |
| 45-60s | 4 |

超过配额 → 强制触发场景合并逻辑。

### 5.2 场景精简三原则

**原则一：单场景承载力最大化**

不通过"换场景"推进剧情，用场景内调度解决——人物走位、道具变化、光线变化、画幅内人物进出。一个场景能承载的信息量远大于直觉判断。

**原则二：场景合并规则**

- 两个场景的功能是否可以在同一个空间完成？→ 合并
- 两个场景的情绪基调是否一致？→ 考虑合并
- 换场景是否提供了"只有换场景才能提供"的信息？→ 不是就留在原地

**原则三：场景缩减优先**

优先删减场景而非压缩内容。宁可在一个场景里做深，不要在两个场景里做浅。

## 六、第三层：创生与衔接执行

### 6.1 创生流程（路径 B 改造）

```
原文无强冲突
    ↓
Step 1: 锚点定位
  从原文找到至少3个锚点：关键道具、核心关系瞬间、角色标志性口头禅/行为
    ↓
Step 2: 基于锚点创生
  只围绕锚点放大，不凭空编造。每个创生必须可溯源到原文
    ↓
Step 3: 5问自查（任一答"否"→ 重做）
  ① 这个画面删掉角色名字后，还能认出是她的故事吗？
  ② 这个画面的人物反应方式，符合TA的性格关键词吗？
  ③ 如果原文作者看到这个画面，会觉得"是我写的"还是"你编的"？
     【例外条款】如果画面以梦境/幻觉/闪前恐惧/心魔具象化等主观心理外化形式呈现，
     且画面结束后有明确的"惊醒/回到现实"标记，则本条不判定为偏离。
  ④ 这个创生是否改变了任何人的核心动机？
  ⑤ 这个画面在逻辑上，能不能从原文自然推导出来？
```

### 6.2 四种衔接技法

| 技法 | 适用场景 | 操作方式 |
|------|---------|---------|
| **声音转场** | 对白型钩子 | 钩子最后一句台词的回声/变奏切入故事起点 |
| **道具转场** | 具象型钩子 | 关键道具特写过渡到同一道具在不同时间的状态 |
| **情绪转场** | 情绪型钩子 | 同一张脸的表情从崩溃→期待，暗示时间回溯 |
| **对白钩子转场** | 反转型钩子 | 一句话切成两个截然不同的语境 |

### 6.3 路径 A/B 衔接区分

- **路径 A**（原文有冲突）：钩子即原文高潮片段。衔接关键是"时间倒流"的自然感——从高潮闪回故事起点。
- **路径 B**（原文需创生）：钩子是创生的。衔接关键是创生场景与原文第一个场景之间的逻辑连续性，不能跳戏。

## 七、与原版的对比

| 维度 | 原版 | 新版 |
|------|------|------|
| 品类处理 | 不区分，一套流程 | 6品类×可调权重策略表 |
| 炸点发现 | 四势能分类（无排序） | 五维打分+品类加权+独特性验证 |
| 场景控制 | 无 | 配额制+三原则 |
| 创生保真 | "禁止"列表约束 | 锚点驱动+5问自查闭环 |
| 转场衔接 | "同源元素转场回溯" | 四种具名技法+路径A/B区分 |
| 核心范式 | 公式驱动 | 决策驱动 |
