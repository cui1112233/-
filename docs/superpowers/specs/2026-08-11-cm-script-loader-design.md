# 剧本生成 CM Loader 设计

## 目标

在 React 剧本页的 AI 生成期间，以用户提供的 CM SVG 动效替换右侧输出区的静态空状态，给出清晰、集中且不干扰操作的进行中反馈。

## 范围

- 仅修改 `frontend/src/user/pages/ScriptPage.jsx` 和 `frontend/src/shared/styles/global.css`。
- 仅在点击“提取人物与场景并生成”后、生成请求尚未结束时显示。
- 不修改旧 HTML 页面、后端 API、生成请求、历史保存、配音、登录或全局按钮加载状态。

## 组件行为

- 新建一个仅由 SVG 和样式组成的 `CmLoader` 组件，放在 `ScriptPage.jsx` 内部，避免为单一页面引入新依赖。
- `loading === true` 且尚无输出时，右侧 `.script-output` 显示 CM Loader、标题“正在生成剧本”和说明“正在提取人物、场景并组织剧情”。
- 请求成功后优先显示生成文本；请求失败后恢复原有空状态。
- 生成按钮继续使用现有 `loading` 状态，避免并发提交。

## 视觉与无障碍

- 复用用户提供的三段 SVG 路径与描边动画，尺寸为 64px。
- 深色主题使用青绿、蓝紫和暖色渐变；浅色主题沿用同一动画，不依赖页面背景色。
- 为装饰性 SVG 设置 `aria-hidden="true"`；外层加载状态使用 `role="status"` 和 `aria-live="polite"`。
- 在用户启用“减少动态效果”时，停止描边和旋转动画。

## 验收标准

1. 生成过程中，右侧输出区显示 CM SVG、标题和说明，而不是旧空状态。
2. 生成完成时显示剧本文本；失败时显示原始空状态。
3. 深色与浅色主题下 CM SVG 都可辨识。
4. 生成按钮在请求期间不可重复提交。
5. React 架构检查和前端构建通过。
