# 剧本分镜卡片输出设计

## 目标

将画布模式、剧情模式和分镜模式的多分镜结果展示为独立卡片。用户可复制单个分镜、勾选多个分镜批量复制或全选复制。剧本模式继续使用完整可编辑的单一输出框。

## 输出识别

- 仅当当前格式不是 `shortdrama` 时尝试拆分。
- 优先解析合法 JSON：支持顶层数组，或 `shots`、`scenes`、`storyboard`、`分镜` 等数组字段；数组每个元素序列化为一张卡片内容。
- JSON 不可用时识别行首编号标题：`分镜 1`、`镜头 1`、`场景 1` 及对应中英文冒号、顿号和序号形式。
- 至少识别出两条才进入卡片模式；一条、空内容或无法可靠拆分时保留完整文本框。
- 原始输出仍作为草稿和历史的唯一保存值；卡片仅是显示与复制视图，不改写模型输出。

## 卡片交互

- 每张卡显示“分镜 N”序号、复选框和“复制本分镜”按钮。
- 单条复制仅复制该卡正文；不自动添加额外标题。
- 选中状态保存在页面内存中，生成新结果、切换格式、编辑完整输出或实体变化时清空。
- 顶部工具栏在卡片模式提供“已选 N 条”“全选 / 取消全选”“复制已选”。
- 批量复制按原始顺序组合已选卡片，卡片之间以两个换行分隔，不添加编号标题。
- 没有选中项时“复制已选”禁用。

## 编辑与降级

- 卡片模式下主“复制”按钮复制全部卡片内容。
- 为避免卡片编辑后无法精确维持边界，点击“编辑”进入原始完整文本框；完成编辑后重新解析并决定是否回到卡片模式。
- 剧本模式始终展示完整可编辑文本框，沿用现有复制、编辑、重新生成、导出行为。

## 组件边界

- 新增 `scriptShotOutput.js`：纯函数负责判断格式、解析 JSON、按编号标题拆分与批量复制文本组合。
- 新增 `ShotOutputCards.jsx`：渲染卡片、单选、全选和复制操作，不处理生成或持久化。
- `ScriptPage.jsx` 保留生成、历史保存和草稿持久化，向卡片组件传入解析结果和事件。

## 测试

- JSON 多分镜、编号文本多分镜、单段文本和剧本模式均有解析测试。
- 单条复制和多选复制组合顺序测试。
- 页面契约测试确认卡片模式使用独立组件，剧本模式保留完整文本框。
- 前端生产构建与现有剧本草稿测试通过。
