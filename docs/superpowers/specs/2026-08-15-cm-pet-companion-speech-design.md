# CM 灵动陪伴台词设计

**日期：** 2026-08-15  
**状态：** 已确认，待实施计划

## 目标

将 CM 从固定的任务提示工具改为有时间感、状态感和轻微随机性的陪伴宠物。它应像 QQ 企鹅一样可爱、有点懒、有点嘴硬，但不频繁打断剧本创作。

本设计只调整 CM 的主动台词与气泡调度；不修改现有动画精灵、聊天、剧本协作、Agent 请求或设置页面布局。

## 体验原则

- 不再固定显示“我在，随时开工。”。
- 语气轻松、简短、拟人化；避免客服话术、强制催促和重复文案。
- 用户正在输入、聊天、生成、拖拽宠物时，不主动打扰。
- 主动台词是可关闭的；关闭后仍保留生成成功、失败和配置错误等任务反馈。
- 高优先级任务反馈可以覆盖普通闲聊，但普通闲聊绝不覆盖用户对话内容。

## 台词类别

### 首次进入

每次页面会话首次加载时，随机展示一句欢迎语：

- “哟，来写故事啦？我先找个舒服的位置。”
- “今天的灵感归我巡逻，你负责写。”
- “我到啦。先看看今天谁要在剧本里受苦。”

### 时段问候

同一自然日、同一问候时段至多展示一次；页面刷新不重复。

| 时段 | 时间 | 示例 |
| --- | --- | --- |
| 早间 | 08:00–10:30 | “好烦呀~又是上班的一天。”、“早呀，脑袋开机了没？” |
| 午间 | 11:30–13:30 | “该吃饭啦，灵感也要补充能量。”、“先歇一会儿，故事不会跑掉。” |
| 下午 | 14:00–17:30 | “下午有点困……要不要让角色先吵一架？”、“咖啡呢？我的灵感电量快见底啦。” |
| 晚间 | 18:00–22:30 | “晚上的灵感比较调皮，我帮你盯着。”、“夜班编剧上线，我也不摸鱼了。” |

不在以上时段时，不补发问候。

### 空闲随机台词

仅在允许主动互动时，以 45–90 分钟的随机间隔展示一句。候选文案：

- “摸鱼中……啊不，我是在观察故事。”
- “这段台词好像在偷偷长大。”
- “角色们在后台排队等你写他们呢。”
- “我刚路过你的灵感，它说还想再睡五分钟。”
- “别急，好的故事都要偷偷酝酿一下。”

同一条台词不能连续两次被选中。

### 点击互动

用户点击宠物且没有触发拖拽时，随机展示一句，不计入主动互动冷却：

- “戳我干嘛，我有在认真陪你。”
- “再摸一下也不是不行。”
- “哼，注意力被你拿走啦。”

### 任务反馈

保留并改写现有任务反馈。它们优先级高于欢迎、问候和空闲随机台词：

| 事件 | 示例 |
| --- | --- |
| 生成 / AI 请求中 | “我去把灵感捞回来，别走开。” |
| 成功 | “完成！这次故事有点意思。” |
| 网络超时或网络错误 | “网好像在摸鱼……当前剧本我帮你守住了。” |
| API Key、模型或接口配置错误 | “我找不到模型啦，检查一下设置好不好？” |
| 模型响应异常 | “这次灵感没接住，剧本还在，咱们再试试。” |

## 调度与优先级

新增独立的宠物台词调度模块，负责选择台词、判定时段、去重、冷却和持久化。`StackyPet` 只订阅调度结果并负责气泡显示。

台词优先级从高到低：

1. 任务错误
2. 任务成功 / 请求中
3. 用户点击互动
4. 首次进入欢迎
5. 时段问候
6. 空闲随机台词

高优先级台词可以替换正在显示的低优先级台词。低优先级台词不得替换聊天回复、任务反馈或正在打开的聊天面板。

每条普通气泡显示 6–8 秒后自动收起。任务错误气泡停留时间沿用当前错误反馈的可读时长，且保留现有重试、打开设置等操作入口。

## 主动互动资格

主动欢迎、问候和空闲随机台词仅在以下条件同时满足时显示：

- 当前浏览器标签页可见；
- 未打开聊天面板；
- 未在发送或等待 AI 请求；
- 宠物未处于拖拽状态；
- “宠物主动说话”设置已开启。

若到点时不满足资格，调度器不立即打断用户；在后续恢复空闲时只允许补发仍在当前时段内的问候。空闲随机台词则重新计算下一次随机时间。

## 本地持久化与设置

使用浏览器本地存储保存以下非敏感数据，并按当前用户名隔离：

- 主动说话开关，默认开启；
- 当天已展示的时段问候标记；
- 上一条空闲随机台词标识；
- 下次随机台词时间。

不保存聊天内容、剧本正文、模型密钥或任何 Agent 上下文到该调度器。

设置中新增“宠物主动说话”开关。关闭后：

- 不显示欢迎、问候、空闲随机和点击互动台词；
- 仍显示请求中、成功、失败和配置错误等任务反馈；
- 重新开启后，从当前时刻重新安排随机台词，不补发关闭期间错过的内容。

## 错误处理

- 本地存储不可用时，仅在当前页面会话内维持状态；宠物仍可显示台词，不抛出错误。
- 计时器在组件卸载、账号切换或页面隐藏后必须清理或暂停，避免重复气泡与内存泄漏。
- 不依赖服务端、模型接口或网络请求；台词调度失败不得影响剧本生成和宠物聊天。

## 测试

- 调度器单元测试：时段识别、每日仅一次问候、随机间隔范围、同句不连续、优先级覆盖、主动开关和本地存储降级。
- 组件测试：符合资格时显示气泡；聊天、请求、拖拽或页面不可见时不显示主动台词；任务错误仍覆盖主动开关。
- 现有宠物、剧本协作与 Agent 测试继续通过。
