# 剧本当前匹配项高亮设计

## 目标

在剧本生成页的“查找替换”功能中，将当前定位到的匹配文字直接标记在分镜卡片正文内，帮助用户确认当前操作位置。

## 交互范围

- 只高亮当前匹配项，不高亮其他匹配项。
- 点击“上一个”或“下一个”后，高亮移动到对应匹配项。
- 查找替换弹窗关闭后，卡片恢复原始文本样式。
- 查找内容为空或没有匹配时，不显示高亮。
- 替换当前或全部替换后，匹配结果重新计算，高亮跟随新的当前匹配项。

## 显示规则

- 高亮仅作用于已选择分镜卡片中的当前匹配项。
- 高亮不修改剧本文本，不影响复制结果、卡片勾选状态或替换范围。
- 当前匹配所在卡片在定位变化后自动滚动到可见区域。
- 分镜正文保持现有等宽字体、换行和滚动行为。
- 高亮使用醒目的黄色背景与深色文字，确保在现有主题下可读。

## 实现边界

- `ScriptPage.jsx` 继续负责当前匹配状态和弹窗开关，并将当前匹配信息传给 `ShotOutputCards`。
- `ShotOutputCards.jsx` 负责将当前卡片正文拆分为普通文本和高亮片段，使用 React 元素渲染高亮。
- 高亮定位使用当前匹配的卡片索引及卡片内起止位置；不根据显示文本重新搜索，避免 JSON 分镜格式化差异造成错位。
- 高亮元素使用稳定的 DOM 标识，卡片视图在当前匹配变化后调用滚动定位。
- 新增样式只服务于当前匹配高亮，不改变现有卡片布局。

## 测试

- 组件契约测试确认页面向卡片组件传递当前匹配信息。
- 纯函数测试确认当前匹配可被拆分为普通文本、高亮文本和普通文本。
- 测试查找内容为空、没有匹配、当前匹配位于文本开头/结尾的情况。
- 前端生产构建必须通过。

## 不在范围内

- 不高亮未选择分镜中的匹配项。
- 不同时高亮全部匹配项。
- 不改变查找替换的普通文本匹配、替换或保存逻辑。
- 不增加正则搜索、大小写选项或新的编辑器依赖。
