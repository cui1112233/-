# 一战晟铭 — 30s 爆量前贴改造设计

## 定位变更

| 维度 | 改造前 | 改造后 |
|------|--------|--------|
| 工具定位 | 小说转影视剧本 | 小说前贴 / 爆量开头 |
| 目标 | 给剧组拍 | 用镜头吸引观众点进小说 |
| 时长 | 不限 | 30s-60s，核心 30s |
| 输入 | 小说章节 | 单章微小说（≤1000字） |
| 格式数量 | 4 种（影视/分镜/短视频/四合一） | 3 种（去掉四合一） |

---

## 核心规则层（三个格式共用）

### 1. 时长约束
- 目标 30s，上限 60s
- 30s 对应约 8-12 个镜头/画面单元
- 宁可少写一镜，不要超时堆砌

### 2. 炸雷前置（Hook First）

30s 前贴的叙事顺序不必遵循小说原文时间线。优先从全章中选取最爆炸、最痛、最反转的画面作为开场第 0-5s，然后通过时间标注桥接回正常叙事。

**方式一：场景跳切**
开场直接切到全章最炸裂的画面（如：对峙、崩溃、打脸），用一个镜头建立冲突，然后通过【字幕：X小时前/X天前】回到故事起点。

**方式二：人物冲突前置**
从全章中选取一段冲突最强的对话作为开场。不交代前因后果，直接用对话把观众扔进冲突中心，后续再补原因。

**前提条件：**
- 炸雷画面必须来自小说原文，不能编造
- 时间标注（字幕）必须准确，不能误导观众
- 回到正常叙事时，必须保证情节完整衔接

### 3. 三幕式结构（默认）
- **第一幕 0-5s：钩子**。最炸裂的画面、冲突、反转开场（优先使用炸雷前置）
- **第二幕 5-20s：冲突升级**。桥接回小说真实情节，推进情绪
- **第三幕 20-30s：反转卡点**。停在关键冲突点，不解决，吸引点进小说

特殊章节（情绪流强、无明显事件推进）AI 可自动选择单爆点一镜到底。

### 4. 情节保真
- 钩子可以适度强化（闪回、冲突前置），但必须能在小说里找到落点
- 禁止编造小说不存在的人物关系、核心事件
- 瞎编的镜头，最终要能用小说原文解释

### 5. 视觉化（已有规则，保留）
- 心理→中观动作，面向 AI 视频平台识别
- 对白 A/B/C 三级分级
- △ 只写镜头可见的，不写心理和环境

### 6. 结尾卡点
- 必须停在"观众想知道接下来发生什么"的位置
- 不能给答案，不能给完整结局

## 三种格式输出模板

### 影视剧本格式
```
【场景标题】

△动作描写 / 画面描述。

　　角色名（表情/动作/声音状态）：台词。

△动作描写。
```

### 分镜脚本格式
```
【镜号1】景别：XXX | 运镜：XXX | 时长：Xs
画面：XXX
对白：XXX

【镜号2】景别：XXX | 运镜：XXX | 时长：Xs
画面：XXX
```

### 短视频脚本格式
```
X-1 场景名 时间/内/外
人物：xxx、xxx

△画面描述。

人物A（关键句写具体表情/动作；普通句可简写或省略）：台词。

【字幕：关键信息】

【本集结尾卡点】
△画面描述。
人物A（具体表情/动作）：最后一句卡点台词。
```

---

## 人物卡片

- 卡片默认显示：姓名 + 角色定位 + 身份标签 + 第一行外貌（体征），可展开查看完整四模块外貌
- 展开后显示：基本体征 / 五官与妆容 / 发型与发饰 / 服饰与配饰 / 说话风格 / 关系网络
