# 批量工厂 V6 功能闭环设计

## 目标

以 V6 原型及其产品记忆为唯一基准，使批量工厂的生产统一设置、发布统一设置和现有生产链路形成真实可验证的工作流；不伪造 121 发布成功。

## 已确认规则

- 主链路为：小说获取 -> 批量工厂 -> 人物/场景/道具 -> 导演 -> VIDEO -> 生成 -> 合并 -> 发布。
- `sourceTaskId`、`bookId`、标题、平台、TXT 和元数据必须从小说获取交接，批量工厂不重复抓取或要求再次输入。
- `bookId` 是业务主键，TXT 固定命名为 `{bookId}.txt`，不同小说的 VIDEO、合并结果和发布结果必须隔离。
- 生产方式只有原文直转和爆款开头；爆款开头必须保存 `sourceText`、`hookDraft`、`approvedHookScript`，导演不得重写已锁定的审核稿。
- 主生产页只显示提示词预设名称；完整系统提示词只在管理后台的系统预设词中管理。
- `visualPrompt` 只描述当前 VIDEO；前缀、资产 Prompt、画质、限制、字幕和负面词在提交时动态编译为 `compiledPrompt`。
- 批次设置遵循 `system < batch < book < video`；关闭注入只关闭注入，不删除资产引用。
- 状态中心只做筛选入口，结果显示在右侧当前筛选；同一本书只计一个主状态。
- 全工作台只有一个播放器，可切换最终合并和各个 VIDEO。
- TTS 只用于测量目标时长，不混入最终视频；TTS 比视频更长时标记异常，不偷偷慢放。

## 生产统一设置

右侧 Drawer 采用 V6 三张设置卡：

1. 基础生产设置：应用范围、生产方式、剧本提示词版本、人物场景提示词版本、视频模型、画幅、VIDEO 时长策略、固定时长。
2. 高级生产设置：画面前缀模式、统一追加要求、项目视觉风格、人物一致性、固定单 VIDEO。
3. 提示词与生成约束：前缀词、人物/场景/道具注入、画质要求、画面限制、字幕策略、负面提示词。

保存“全部”时，只更新没有书级覆盖的书；保存“个别”时，只更新选中的书级覆盖。底部固定显示影响数量、覆盖提示、取消和保存并应用到批次。保存后重新读取批次并更新顶部生产摘要。

## 发布统一设置

右侧 Drawer 采用 V6 三张设置卡：

1. 成品设置：上传合并成品或独立 VIDEO、倍率或跟随音频时长、合并倍率。
2. 发布参数：滚屏数量、生成数量、素材复用、水平翻转、解压倍速、解压音调、AI 头部、TXT 自动上传。
3. 预览：显示 `{bookId}.mp4` 与 `{bookId}.txt` 预览入口。

设置保存到批次 `settings.publishSettings`，顶部摘要从同一字段读取。没有经过验证的 121 任务创建和回执接口时，发布动作必须显示未接入，不得显示成功、完成或伪造任务 ID。

## 错误与验证

- API 保存失败时保留抽屉输入、显示错误消息，不更新顶部摘要。
- 不兼容视频模型、超过模型最大时长、无效 Book ID 或缺少合并能力时阻止对应动作并解释原因。
- 生成失败、队列失败和合并失败必须保留失败原因，支持重试，不清空其它书或 VIDEO 状态。
- 前端测试覆盖设置分组、保存 API、继承/覆盖规则和发布未接入边界。
- 构建、Docker 发布和远程浏览器验证必须通过后才可宣称完成。

## 非目标

- 本阶段不实现未经验证的 121 外部发布接口。
- 不恢复主生产页面的 Prompt Studio。
- 不引入新的提示词预设类别。
