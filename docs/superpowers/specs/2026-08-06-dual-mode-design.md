# 双模式生成设计文档

## 背景与目标

当前 Novel2Script 只有单一生成模式：`角色设定.md` 驱动的"爆款开头"模式。用户反馈实际生成时，有时希望 AI **完全按原文可视化**，不要自动找钩子、不要创生、不要改变故事结构；有时又希望 AI **自动爆款化**。

目标：在一键生成界面提供两种模式切换，分别对应两个独立的角色 prompt。

## 设计决策

### 模式定义

| 模式 | 名称 | 角色 prompt | 核心行为 |
|------|------|------------|---------|
| 模式 A | **爆款开头** | `prompts/角色设定.md`（现有） | 分层决策架构：品类识别→炸点发现→场景配额→创生衔接 |
| 模式 B | **连续开头** | `prompts/连续开头.md`（新建） | 按原文顺序连续可视化，允许画面强化，但不创生情节、不闪回前置、不改变结构 |

### 连续开头模式原则

- **不创生情节**：不写原文没有发生的事件
- **不强制钩子**：不要求开局炸场，按原文自然顺序连续展开
- **不闪回/不重生/不前置结局**：不跳时间线，原文给什么顺序就什么顺序
- **不硬约束场景数**：不执行场景配额制，按原文空间转换自然切场景
- **允许画面强化**：心理活动→动作、对白加括号、镜头感描述、结尾卡点
- **允许适度取舍**：次要描写可压缩，但保留核心情节和对话

### UI 设计

- 在输入区上方工具栏增加模式切换按钮/下拉
- 位置与格式 tab 同级，作为全局设置
- 两种模式都支持三种输出格式（剧本/剧情/画布）
- 默认模式：**连续开头**
- 不记住状态：每次打开页面恢复默认

### 数据流

```
用户选择模式 → 点击一键生成
    ↓
PromptTemplates.scriptPrompt(mode, novelText, charsJson, scenesJson, format, duration)
    ↓
mode === 'hook' → 加载 角色设定.md
mode === 'continuous' → 加载 连续开头.md
    ↓
拼接通用规则.md + 格式模板.md
    ↓
发送 /api/chat
```

## 文件变更

| 文件 | 操作 | 说明 |
|------|------|------|
| `prompts/连续开头.md` | 新建 | 连续开头模式的角色 prompt |
| `prompts/角色设定.md` | 不改核心内容 | 已定义为爆款开头模式 |
| `prompts/通用规则.md` | 微调 | 移除只适用于爆款模式的条款，两种模式通用 |
| `index.html` | 修改 | 加模式切换控件、改 scriptPrompt 参数、改 generate 调用 |
| `server.js` | 不改 | prompt 加载接口已支持任意 .md 文件 |

## 风险与兜底

- 如果 `连续开头.md` 加载失败，回退到现有 `角色设定.md`
- 模式切换控件在视觉上与格式 tab 区分，避免混淆

## 验收标准

- [ ] 模式切换控件在输入区上方工具栏可见
- [ ] 默认选中"连续开头"
- [ ] 切换到"爆款开头"后生成，system prompt 加载 `角色设定.md`
- [ ] 切换回"连续开头"后生成，system prompt 加载 `连续开头.md`
- [ ] 两种模式都支持三种格式输出
- [ ] 刷新页面后恢复默认"连续开头"
