# 批量工厂基础设定展示开关

## 目标

让“基础设定（人物 / 场景）”与剧本生成页面采用一致的展示语义：开启时在分镜工作台展示基础资产；关闭时不在分镜工作台展示基础资产，但不删除任何生产数据。

## 范围

该开关仅控制批量工厂工作台的展示层：

- **开启**：分镜提示词卡显示人物外形、场景环境、道具等基础设定注入块；分镜资产列显示人物、场景、道具计数与标签。
- **关闭**：分镜提示词卡隐藏上述基础设定注入块；分镜资产列隐藏人物、场景、道具计数与标签。
- 资产设置入口和“管理全部资产”仍可用，用户可以随时编辑或查看资产库。

## 不变项

关闭开关不会修改、删除或重算：

- H3 结构化导演卡、人物 slot、场景事件、动作、机位、运镜、连续性；
- 最终 VIDEO Prompt 中镜头自身的人物名称、剧情事件和导演调度；
- 资产库、资产修订、Trace、已生成图片或视频。

后端最终 Prompt 的资产长提示词注入仍由同一个基础设定开关决定；前端必须消费冻结配置，以免展示与实际提交文案不一致。

## 实现边界

在书级有效配置的 `basicSettingsEnabled`（或现有等价字段）上派生一个只读展示标志。资产列和最终 Prompt 卡共同使用该标志；不得按是否已有资产、是否 H3、是否自动化模式推断显示状态。

旧 V11/V12 数据缺失开关值时沿用现有默认行为，避免历史工作台出现空白或数据迁移。

## 验收

1. 同一本书切换该开关，资产列的人物/场景/道具计数和标签立即随之显示/隐藏。
2. 分镜卡的资产基础设定注入块随之显示/隐藏。
3. 无论开关状态，镜头卡仍显示人物名称、动作、机位、运镜和连续性。
4. 关闭后重新刷新或进入单书配置，状态与书级有效配置一致。
5. 切换开关不改变资产、导演、视频、Trace 或已上传成片。
