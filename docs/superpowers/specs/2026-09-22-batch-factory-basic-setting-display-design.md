# 批量工厂约束设置展示与注入开关

## 目标

让批量工厂“约束设置”与剧本生成页面采用一致的展示和注入语义：每项约束都可以独立启用或关闭。关闭时不在分镜工作台展示该约束，也不注入最终 VIDEO Prompt，但不删除任何生产数据。

## 生产链与智能统一

无论画面前缀词选择为何，`style.system` 都是固定生产步骤：

`视频原文 → style.system → 内容类型、时代、统一视觉风格 → 保存`

它不能因用户选择普通画面前缀词而跳过。画面前缀词下拉框只决定最终卡片显示和 Prompt 注入哪一种前缀：

- 选择“智能统一”：显示并注入已保存的 `style.system` 结果。
- 选择普通画面前缀词：显示并注入所选预设；`style.system` 结果仍保留，但不显示、不注入。
- 关闭画面前缀词：两者均不显示、不注入；`style.system` 结果继续保存，以便后续切换复用。

智能统一不是独立的约束开关，也不是另一条生产链。

### 原版 H3 `style.system` 的唯一来源

“智能统一”的系统预设正文以原版 H3 终端交付包中的
`server/prompts/style.system__v78.3.0.59.txt` 为准，而不是维护一份
语义相近的简写版本。该规则只负责：

- 按时代/世界观、主角目标、核心关系、核心冲突、叙事发动机、钩子与情绪曲线，输出唯一的 `XXXX短剧` 内容类型；
- 输出全片摄影/成像基线 `trailer_style`，覆盖采集、色彩管线、帧率/快门/EI、颗粒、综合色彩、镜头与光学质感、反差、饱和、肤色和通用布光；
- 输出 `negative_prompt`、`picture_limit_prompt` 与 `quality_constraint_prompt`；
- 严格只返回 `final_genre`、`genre`、`trailer_style`、`story_era` 和上述三个约束字段的 JSON。

批量工厂运行时必须将这个已发布的“智能统一”预设正文原样作为模型 system message，并继续用用户消息传入视频原文。原版 Go 模板中的 `{{.StyleAdvice}}` 和 `{{.SourceText}}` 是原 H3 模板渲染位；在批量工厂中由现有用户消息分别承载风格建议（如有）与视频原文，不得把未替换的 Go 占位符发送给模型。

升级系统默认预设时，只能替换系统自身遗留的简化默认正文；管理员已经保存、发布或选中的自定义“智能统一”正文属于用户预设，不得静默覆盖。无论系统默认还是自定义正文，`style.system` 的运行时机均固定为资产/导演前的后台分析步骤。

## 视频提示词与 H3

批量工厂只有一条导演生产链。视频提示词下拉框选择的是本次导演规则预设，H3 只是其中一个可选预设，不是独立流程、独立编译器模式或隐藏的固定文案格式。

所有视频提示词预设都经过同一顺序：

`视频原文 → style.system → 资产提取 → 视频提示词导演规则 → 配音实测（若开启）→ 确定性 10/15 秒分段 → 约束注入 → 最终 Prompt 冻结 → VIDEO 提交`

每个预设必须提供两部分可编辑内容：

1. **导演规则正文**：直接进入本次导演模型调用，决定镜头正文的表达、字段组织和导演侧重点；H3 预设在这里要求完整导演卡、人物 slot、微镜头与连续性。
2. **最终 Prompt 模板**：用已校验的通用导演结构、时间线和开关注入层填充，决定最终 VIDEO Prompt 的标题、字段顺序和展示格式。

后端只统一不可变生产事实：视频原文来源、结构字段校验、真实配音时长、10/15 秒切段、版本冻结与 Trace。它不得把 `Scene / Shot / Audio` 等具体文案格式写死为所有预设的输出。

切换视频提示词预设后，不重跑资产、风格分析或整书导演事实；系统用同一份已冻结的结构化导演数据、时间线及开关快照重新编译。若预设导演规则本身要求不同的结构字段，必须在选择时做兼容校验并明确提示是否需要重新导演，不能静默套用错误格式。

## 约束展示与注入范围

约束设置中的每项均使用相同的两层语义：启用时展示并注入，关闭时不展示也不注入。

| 约束项 | 启用时 | 关闭时 |
| --- | --- | --- |
| 画面前缀词 | 展示并注入当前所选普通前缀或智能统一结果 | 不展示、不注入 |
| 基础设定（人物 / 场景） | 展示并注入人物外形、场景环境、道具等资产长提示词 | 不展示、不注入 |
| 画质约束 | 展示并注入画质要求 | 不展示、不注入 |
| 画面限制 | 展示并注入限制项，例如无文字、H3 视觉限制 | 不展示、不注入 |
| 负面提示词 | 展示并注入负面约束 | 不展示、不注入 |

基础设定额外控制资产列：

- **开启**：分镜提示词卡显示人物外形、场景环境、道具等基础设定注入块；分镜资产列显示人物、场景、道具计数与标签。
- **关闭**：分镜提示词卡隐藏上述基础设定注入块；分镜资产列隐藏人物、场景、道具计数与标签。
- 资产设置入口和“管理全部资产”仍可用，用户可以随时编辑或查看资产库。

## 不变项

关闭开关不会修改、删除或重算：

- H3 结构化导演卡、人物 slot、场景事件、动作、机位、运镜、连续性；
- 最终 VIDEO Prompt 中镜头自身的人物名称、剧情事件和导演调度；
- 资产库、资产修订、Trace、已生成图片或视频。

后端最终 Prompt 的每一层注入仍由对应约束项决定；前端必须消费冻结配置，以免展示与实际提交文案不一致。

## 实现边界

在书级有效配置的约束项上分别派生只读展示标志。资产列、最终 Prompt 卡和实际提交编译共同使用同一份冻结配置；不得按是否已有资产、是否 H3、是否自动化模式推断显示状态。

旧 V11/V12 数据缺失开关值时沿用现有默认行为，避免历史工作台出现空白或数据迁移。

## 验收

1. `style.system` 在选择普通画面前缀、智能统一和关闭画面前缀三种情形均运行并保存结果。
2. 选择智能统一时显示、注入 `style.system` 结果；选择普通前缀时只显示、注入普通预设。
3. 逐项关闭画面前缀、基础设定、画质约束、画面限制和负面提示词时，只隐藏并移除对应注入层。
4. 同一本书切换基础设定，资产列的人物/场景/道具计数和标签立即随之显示/隐藏。
5. 无论开关状态，镜头卡仍显示人物名称、动作、机位、运镜和连续性。
6. 关闭后重新刷新或进入单书配置，状态与书级有效配置一致。
7. 切换开关不改变资产、风格分析、导演、视频、Trace 或已上传成片。
8. 选择不同视频提示词预设时，最终 Prompt 卡内格式按该预设模板改变；VIDEO 卡容器、时长、来源切片和 Trace 保持可追溯。
9. H3 与非 H3 视频提示词预设均走同一生产链；不存在根据 H3 选择写死 `Scene / Shot / Audio` 文案的分支。
