# 批量工厂约束设置展示与注入开关

## 目标

让批量工厂“约束设置”与剧本生成页面采用一致的展示和注入语义：每项约束都可以独立启用或关闭。关闭时不在分镜工作台展示该约束，也不注入最终 VIDEO Prompt，但不删除任何生产数据。

## 生产链与智能统一

无论画面前缀词选择为何，`style.system` 都是固定生产步骤：

`视频原文 → style.system → 内容类型、时代、统一视觉风格 → 保存`

它不能因用户选择普通画面前缀词而跳过。画面前缀词下拉框只决定最终卡片显示和 Prompt 注入哪一种前缀：

- 选择“智能统一”：显示并注入已保存的 `style.system` 结果。
- 选择普通画面前缀词：显示并注入所选预设；`style.system` 结果仍保留，但不显示、不注入。
- 关闭画面前缀词：两者均不显示、不注入；`style.system` 结果继续保存，以便后续切换复用。

智能统一不是独立的约束开关，也不是另一条生产链。

## 约束展示与注入范围

约束设置中的每项均使用相同的两层语义：启用时展示并注入，关闭时不展示也不注入。

| 约束项 | 启用时 | 关闭时 |
| --- | --- | --- |
| 画面前缀词 | 展示并注入当前所选普通前缀或智能统一结果 | 不展示、不注入 |
| 基础设定（人物 / 场景） | 展示并注入人物外形、场景环境、道具等资产长提示词 | 不展示、不注入 |
| 画质约束 | 展示并注入画质要求 | 不展示、不注入 |
| 画面限制 | 展示并注入限制项，例如无文字、H3 视觉限制 | 不展示、不注入 |
| 负面提示词 | 展示并注入负面约束 | 不展示、不注入 |

基础设定额外控制资产列：

- **开启**：分镜提示词卡显示人物外形、场景环境、道具等基础设定注入块；分镜资产列显示人物、场景、道具计数与标签。
- **关闭**：分镜提示词卡隐藏上述基础设定注入块；分镜资产列隐藏人物、场景、道具计数与标签。
- 资产设置入口和“管理全部资产”仍可用，用户可以随时编辑或查看资产库。

## 不变项

关闭开关不会修改、删除或重算：

- H3 结构化导演卡、人物 slot、场景事件、动作、机位、运镜、连续性；
- 最终 VIDEO Prompt 中镜头自身的人物名称、剧情事件和导演调度；
- 资产库、资产修订、Trace、已生成图片或视频。

后端最终 Prompt 的每一层注入仍由对应约束项决定；前端必须消费冻结配置，以免展示与实际提交文案不一致。

## 实现边界

在书级有效配置的约束项上分别派生只读展示标志。资产列、最终 Prompt 卡和实际提交编译共同使用同一份冻结配置；不得按是否已有资产、是否 H3、是否自动化模式推断显示状态。

旧 V11/V12 数据缺失开关值时沿用现有默认行为，避免历史工作台出现空白或数据迁移。

## 验收

1. `style.system` 在选择普通画面前缀、智能统一和关闭画面前缀三种情形均运行并保存结果。
2. 选择智能统一时显示、注入 `style.system` 结果；选择普通前缀时只显示、注入普通预设。
3. 逐项关闭画面前缀、基础设定、画质约束、画面限制和负面提示词时，只隐藏并移除对应注入层。
4. 同一本书切换基础设定，资产列的人物/场景/道具计数和标签立即随之显示/隐藏。
5. 无论开关状态，镜头卡仍显示人物名称、动作、机位、运镜和连续性。
6. 关闭后重新刷新或进入单书配置，状态与书级有效配置一致。
7. 切换开关不改变资产、风格分析、导演、视频、Trace 或已上传成片。
