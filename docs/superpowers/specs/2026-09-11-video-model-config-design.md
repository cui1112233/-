# 视频模型配置设计

## 目标

在个人中心 API 配置页明确显示并保存视频模型，使管理员可以选择 MiniMax H3，同时保持现有视频 API Key 配置和成员托管权限不变。

## 方案

- 视频配置增加 `modelKey` 字段，默认值为现有视频模型，H3 使用 `minimax-h3-video`。
- API 配置页在“视频生成服务”中增加模型选择器，显示 H3 的能力说明：最多 15 秒、支持参考图、无参考图也可生成。
- 服务端保存和读取配置时仅返回安全的模型标识与 `hasApiKey`，不返回密钥。
- 视频模型目录统一从当前账号配置解析；模型列表继续由现有鉴权接口提供，H3 的 `configured` 状态只由当前账号视频 Key 决定。
- `/script` 发送视频请求时继续使用现有 H3 适配器；模型选择与配置页采用同一 `modelKey`。

## 校验与边界

- 未配置视频 Key 时，H3 仍可显示为模型选项，但生成操作明确提示未配置凭据。
- 不改变数据库表结构，不触碰 MySQL、Redis、对象存储和既有数据。
- 覆盖配置 API 的保存/读取、模型目录和前端配置字段测试；构建后验证公网脚本包含新字段和 H3 标识。
