# Q版模式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在剧本生成的正式输出格式列表中新增可归属、可选择、可生成的 Q 版模式，并使用用户提供的 Q 版画面转译规则。

**Architecture:** 将 Q 版规则保存为 `prompts/Q版模式.md`，通过 `lib/system-preset-catalog.js` 作为 `script` 模块的 base 输出格式预设注册。后端 `routes/chat.js` 负责把 `q版` 格式规范化并加载对应预设；现有剧本生成前端和历史记录名称映射增加同一格式值，保持请求、保存和恢复一致。

**Tech Stack:** Node.js、Express、原生 JavaScript、HTML、Node test runner。

## Global Constraints

- Q 版模式与分镜模式、剧本模式、剧情模式、画布模式同级，归属 `script` 模块。
- 系统预设 ID 使用 `script-format-q版`，格式值使用 `q版`，显示名称使用 `Q版模式`。
- Q 版提示词必须保留用户提供的核心规则，并包含 10s/15s 拆分与四段式镜头输出要求。
- 不修改现有四种模式的 ID、名称、提示词正文和行为。
- 不把 Q 版规则注册为 constraint addon，也不把它做成视频画面工作台的独立开关。
- 不创建不必要的兼容层或额外配置项。
