# H3 单链路融合实施计划

依据：本任务中用户已确认的规则，替代旧设计中独立 editable_copy 与二次人物外形来源的产品语义。

## 已确认设计

- 保留现有工作台、配置、资产库与生产链，不建立第二套 H3 系统。
- 人物外形阶段一次模型请求返回全部人物；后台人物预设承载 H3 创作指令。逐人结果严格关联、完整校验后统一保存；截断、漏人、重复、未知人物报错，不隐式逐人补调。
- 单书资产为人物外形的权威来源；导演只绑定资产，历史快照不可覆盖。
- 分镜提示词就是最终提交 Prompt；手动编辑精确保存提交，重编译不静默覆盖。
- 智能统一和基础设定仅控制注入；关闭不删除故事事实。
