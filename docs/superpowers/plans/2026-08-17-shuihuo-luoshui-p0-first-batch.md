# 水货生产洛水对齐 P0 第一批实施计划

## 范围

把已经静态提取并确认可自研复刻的生产能力接入当前真实路径：

- 分镜增加 `negativePrompt` / `negativePromptLocked`，贯通读写、候选应用、任务修订指纹和导出 manifest。
- 当前 `CommentaryWorkbench` 挂载提示词候选弹窗，支持图片、视频、负面提示词三类候选生成和人工勾选应用。
- 行组件显示并放大编辑负面提示词，让它成为可见、可保存、可导出的生产字段。

## 明确不做

- 不复制洛水源码、接口、账号社区、密钥或私有模板。
- 不在本批实现完整配音持久表、剪映工程文件生成、第三方平台自动发布。
- 不改旧版未挂载 `StudioView` 的功能形态，除非测试合同需要识别当前真实路径。

## 验证

- Go：针对受影响的 `storage`、`store`、`httpapi` 包跑目标测试。
- Node：跑 `tests/shuihuo-production-ui-contract.test.js`，确认当前工作台暴露新能力且仍使用服务端导出。
- 如全量测试受既有脏工作树影响，记录未验证边界。
