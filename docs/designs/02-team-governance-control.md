# 02 · 团队治理控制台 / Team Governance Control

基于 `01 · 曜金会员中枢 / Aurum Member Hub` 的治理增强版本。

## 目标

把会员中心从“身份 + 团队用量”升级为可长期运营的团队资源控制台，重点解决账号运维、团队总额度、能力分权、费用估算和登录设备安全。

## 本版功能

### 1. 账号运维
- DEV 可管理全部非 Owner 账号。
- MANAGER 仅可管理自己 `boundTo` 的 MEMBER。
- 账号停用与 API 停用分离。
- 停用账号会立即撤销其运行时 Token 和持久化登录会话。
- 管理员可恢复账号、重置密码；重置密码后旧密码失效并撤销已有会话。
- Owner 不可被停用、重置或降权。

### 2. 团队总额度
- 每个 MANAGER 团队可设置自然月 Token 总额度。
- 70%：warning。
- 90%：critical。
- 100%：exhausted，服务端直接拒绝新的团队模型调用。
- MEMBER 个人额度与团队总额度同时生效，任一耗尽都会阻止调用。
- 历史用量按调用发生时的 `teamOwner` 归属，不会因成员转组而迁移。

### 3. API scope
MEMBER 的 API 权限拆为：
- `text`
- `image`
- `tts`

旧 `*` 授权兼容读取；治理页保存后会替换成显式 scope。
服务端按实际请求类型校验，不只依赖前端隐藏。

### 4. 费用估算
API 配置支持可选价格快照：
- 币种（USD / CNY / JPY）
- 输入每 100 万 Tokens 单价
- 输出每 100 万 Tokens 单价

每次 Chat / Agent 调用记录当时的价格快照与估算费用。后续修改价格不会改变历史记录。
费用仅为估算，不代表供应商最终账单。

### 5. 登录设备
登录会话记录：
- 浏览器类型
- 操作系统
- 模糊 IP 提示，例如 `203.0.*.*`

不保存精确地理位置，不在前端显示完整 IP。

## 仍不属于 02 的范围
- MFA / TOTP
- 邮箱/手机号验证码验证
- 邀请链接
- 独立 Team 实体与团队命名
- 站内通知中心
- 成员物理删除
- 供应商账单对账
