# 批量工厂独立生产线规范

## 产品边界

批量工厂是独立产品模块，不复用「剧本生成」的运行链路、提示词编译链、状态机或页面组件。

两者可以具有相似的用户能力，但必须分别实现、分别测试、分别演进。

- 剧本生成：单本创作工具。
- 批量工厂：批量稳定生产、视频生成、合并和 121 发布工具。

## 主流程

小说获取 → 转入批量工厂全部可用小说 → 小说列表 → 生产统一设置 → 开始导演 → 逐本从上到下执行 → 当前小说可单独检查/修改 → 生成视频 → VIDEO01/02/03… → 合并 → 发布统一设置 → 121 发布。

## 当前小说能力

当前小说必须提供独立的：

1. 小说正文查看、编辑、保存。
2. 原文直转 / 爆款开头生产方式。
3. 批量工厂专用剧本提示词选择。
4. 批量工厂专用人物场景提示词选择。
5. 人物、场景、道具查看与提示词编辑。
6. VIDEO 画面提示词 `visualPrompt` 编辑。
7. 单书重新导演。
8. 单书设置覆盖。
9. 单 VIDEO 设置覆盖。
10. 本次提交 Prompt `compiledPrompt` 只读预览。
11. 单 VIDEO 生成/重生成。
12. 当前小说全部 VIDEO 生成。

## 设置继承

优先级固定：

system < batch < book < video

批次统一设置修改后，仅更新仍然继承批次值的小说/VIDEO；已有单独覆盖不得被静默覆盖。

单书可覆盖：

- 剧本提示词
- 人物场景提示词
- 画幅
- 风格/摘要辅助信息
- 前缀模式与自定义前缀
- 人物/场景/道具注入开关
- 画质
- 画面限制
- 字幕/文字限制策略
- 负面提示词
- 固定单 VIDEO 策略（受已绑定视频模型最大时长约束）

视频模型在导演后保持绑定；如更换到最大时长能力不同的模型，应重新导演/重新拆分。

## Prompt 架构

用户可选择的批量工厂提示词只有两类：

1. 剧本提示词
2. 人物场景提示词

VIDEO 的画面提示词是导演输出，不是第三种用户预设。

### visualPrompt

只包含当前 VIDEO 自身的剧情、动作、镜头、画面和必要对白信息。可以直接编辑。

### generationSettings

包含前缀、人物一致性、场景一致性、道具一致性、画质、限制、字幕/文字限制、负面词等生成时设置。

### compiledPrompt

在预览或提交视频模型时动态生成。只读，不允许反写覆盖 `visualPrompt`。

编译顺序：

1. 前缀
2. 人物提示词
3. 场景提示词
4. 道具提示词
5. 当前 VIDEO visualPrompt
6. 画质
7. 画面限制
8. 文字与字幕限制
9. 负面提示词

## 批量执行

点击【开始导演】后按小说列表可见顺序串行执行，默认并发为 1。

全部小说导演完成后，主按钮切换为【生成视频】。

点击【生成视频】后同样按小说列表顺序逐本提交视频生产。

异常小说不得阻塞用户查看其他小说；状态中心应优先暴露异常。

## VIDEO

每本小说可产生一个或多个 VIDEO：

- VIDEO01
- VIDEO02
- VIDEO03
- …

第三块 VIDEO 始终跟随当前选中的小说。点击不同 VIDEO，在同一播放器中切换，不为每个 VIDEO 创建独立播放器。

## 合并

每本小说全部 VIDEO 完成后支持：

- 固定倍率
- 跟随音频时长

跟随音频时长使用项目已有 TTS 服务，批量工厂测时语速固定 1.7。TTS 只测量目标时长，不混入最终视频音轨。

最终输出：`${bookId}.mp4`。

## 发布

发布使用批量工厂自己的发布统一设置并接真实 121 后台。

每本书发布至少携带：

- `${bookId}.mp4`
- `${bookId}.txt`
- 小说获取阶段已有的平台、性别、风格及相关元数据
- 解压视频数量
- AI 头部：自定义AI头部
- 素材复用 / 不复用
- 水平翻转 / 不翻转

不得用假按钮冒充已发布。

## 提示词库

系统预设：管理后台 → 系统预设词 → 批量工厂。

个人覆盖：个人中心 → 提示词库 → 批量工厂。

导演读取优先级：个人覆盖版本 > 当前系统发布版本。

批量工厂提示词不得自动读取或复用「剧本生成」模块的提示词。

## 前端约束

批量工厂新/重构前端：

- React + Ant Design
- 不新增第三方前端依赖
- 新增样式使用 inline style / JS style object / antd props/theme
- 不新增 Batch Factory CSS/LESS/Tailwind
- 不引入 react-router

## 完成标准

完整烟测：

小说获取至少 3 本 → 全部转入 → 修改其中一本正文 → 统一设置 → 单书覆盖 → 开始导演 → 查看/编辑资产与 visualPrompt → 单 VIDEO 生成 → 整本生成 → 整批生成 → VIDEO 切换播放 → 合并 → 121 真发布。
