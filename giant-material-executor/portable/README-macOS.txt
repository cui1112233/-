巨量素材执行器 macOS 版

系统要求：macOS 13 或更新版本，支持 Apple Silicon 与 Intel。

1. 解压后双击 GiantMaterialExecutor.app。首次运行若 macOS 提示无法验证开发者，请在系统设置 → 隐私与安全性中选择“仍要打开”。
2. 执行器会打开本机 http://127.0.0.1:17861/setup。
3. 在公网设置页“巨量素材执行器”处生成配对码，并填入该页面。安装包已预填平台控制服务地址；只有平台迁移后才需要修改。
4. 绑定成功后，返回公网设置页点击“刷新状态”。执行器会在后台等待任务；关闭浏览器不会停止它。
5. 要停止执行器，请通过 macOS 活动监视器退出“GiantMaterialExecutor”进程。再次双击应用会使用 Keychain 中保存的凭证自动连接。

此版本使用 macOS 自带 Vision 中文 OCR，不下载额外 OCR 模型；视频只供远程读取，不长期保存在电脑。
